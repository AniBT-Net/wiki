AniBT is a BitTorrent distribution, indexing, and search platform designed for anime fans and fansub groups.

<Callout type="info">
  Browsing resources, copying magnet links, downloading `.torrent` files, and using public RSS feeds do not require an account. Registration is only needed if you want to follow anime, manage personal subscriptions, or publish releases as a fansub group member.
</Callout>

Whether you are a fansub team distributing releases, an anime fan looking for high-quality torrents, or a developer building ACG tools, you will find relevant guides here.

## Quick Navigation

<Tabs items={['Fansub Workflow', 'Anime Fans & Tracking', 'Developers & API']}>
  <Tab value="Fansub Workflow">
    Submit a release once on AniBT, and the system automatically dispatches it to major BT sites, with dedicated screenshot hosting and tracker communication.

    <Steps>
      <Step>
        ### Apply for Onboarding
        Register an account on AniBT, then submit your group details and release portfolio via email to obtain publisher permissions and a dedicated slug. See [Fansub Onboarding](/en/docs/apply).
      </Step>
      <Step>
        ### Configure Site Sync and Tracker
        Fill in credentials for connected BT platforms (Bangumi Moe, Mikan, DMHY, ACGNX, ACG.rip, Nyaa) in the group console. Include the [AniBT Tracker](/en/docs/tracker) when creating torrents. See [Site Sync](/en/docs/site-sync).
      </Step>
      <Step>
        ### Publish Releases
        Upload torrents directly via the web dashboard, or integrate your encoding pipelines using the [Release API](/en/docs/open-api/releases-publish). Supports pre-publish preview and dedicated image hosting.
      </Step>
    </Steps>
  </Tab>

  <Tab value="Anime Fans & Tracking">
    Enjoy seamless anime searching and automated episode tracking without registration hurdles.

    <Steps>
      <Step>
        ### Search and Download
        Search anime titles by Chinese, Japanese, Bangumi subject ID, or fansub group tags. Each release detail page offers magnet links and standard `.torrent` downloads.

        Release detail pages, `/magnets`, anime pages, and the release panel that opens when you click an anime poster fetch download addresses only when you click a button:

        - **Copy magnet link** and **Open magnet link** fetch the magnet link on click. If it cannot be fetched, you see "Download URL is unavailable". If the browser refuses to write to the clipboard, click **Copy again** in the notice. If the browser cannot open the magnet link directly, click **Open again** in the notice.
        - **Download torrent** downloads the `.torrent` file directly. On anime pages and in the release panel, the torrent button also downloads directly instead of opening the release detail page.
        - File list: on a release detail page, click **View file list** to load it. The file count appears after it loads.

        The **Releases** tab on an anime page has its own URL, `/anime/<id>?tab=releases`; the default **Release progress** tab is `/anime/<id>`. On `/magnets` and on a fansub group's **Releases** tab, previous and next are links that carry a `cursor` parameter, so you can open them in a new tab or share them. The group **Releases** tab also keeps its season filter in the URL (`season` and `year`, or `all`) and shows 20 releases per page. An expired page link returns to the first page for the same filters.
      </Step>
      <Step>
        ### Track via RSS
        Copy the anime-specific [RSS Feed URL](/en/docs/open-api/rss-anime) into your downloader (e.g., qBittorrent, Sonarr, FlexGet). New episodes will download automatically upon release.
      </Step>
      <Step>
        ### Manage Personal Subscriptions (Optional)
        Sign in and click "Subscribe" on an anime page. Filter by fansub group, subtitle language, resolution, file format, subtitle type, and tags, then click "Subscribe" to save. Leave a filter set to "All" to accept every value.

        To edit a subscription, open "Subscription" on the anime page or its card in "My Subscriptions". Your saved filters are filled in automatically and can be edited while more options load. If loading fails, retry without losing your edits. Click "Save" to apply changes or "Cancel" to discard them. Multiple selections within one filter match any selected value; different filters must all match.

        Copy the complete [personal subscription RSS](/en/docs/open-api/rss-subscriptions) link from "My Subscriptions" into your download tool to receive matching releases. Keep this link private: it contains an access credential. The public RSS link on an anime page does not use your personal filters.
      </Step>
    </Steps>
  </Tab>

  <Tab value="Developers & API">
    All public platform data is accessible through standard REST APIs and compliant RSS feeds.

    <Steps>
      <Step>
        ### Explore Public Endpoints
        Read-only endpoints require no API key or token, providing anime queries, search, fansub directories, and recent magnets. See [Open API Overview](/en/docs/open-api).
      </Step>
      <Step>
        ### Leverage HTTP 304 Caching
        All public feeds support weak ETags and `If-None-Match`. Include the previous ETag in polling loops to receive `304 Not Modified` when content is unchanged, saving bandwidth. See [HTTP Caching](/en/docs/open-api/caching).
      </Step>
      <Step>
        ### Automate Fansub Releases
        Developers with a Subtitle Group API Key can automate torrent uploads, metadata matching, external sync inspection, and release withdrawals via REST.
      </Step>
      <Step>
        ### Crawling and Sitemaps
        The main site's `robots.txt`, sitemap shards, and which pages are indexed are described in [LLM & Agent Integration](/en/docs/llm).
      </Step>
    </Steps>
  </Tab>
</Tabs>
