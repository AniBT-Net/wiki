**AniBT** is a public BitTorrent tracker focused on anime. It supports subtitle-group publishing and follow-show consumption. This Wiki covers on-site publishing, external site sync, public APIs, accounts, and adjacent tools. Pick a path by use case.

Two main tracks:

- **Subtitle groups**: apply for admission → configure site sync → use the official Tracker when packing torrents → publish via API or web UI.
- **Users / developers**: use RSS and JSON anonymously; register only when personal subscriptions or publishing rights are needed.
