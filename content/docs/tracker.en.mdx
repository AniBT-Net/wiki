---
title: Tracker
description: The AniBT announce URL to use when creating torrents.
---

Only torrents already published on AniBT are accepted.

```txt
https://tracker.anibt.net/announce
```

Add this URL when creating torrents. Publishing on this site writes it into the magnet. Torrents not published here receive `not whitelisted`.

Download `.torrent` files:

| Type | Path |
| --- | --- |
| Anime | `/api/torrent/{rel_*}.torrent` |
| Other | `/api/other-torrent/{orel_*}.torrent` |

Closed: `/scrape`, UDP, `/announce/v1/*`.
