---
title: Tracker
description: How AniBT's official hash-bound tracker announce capability works.
---

The AniBT tracker only serves torrents published on AniBT. The site now signs a
tracker URL for each torrent's `info_hash`; there is no longer a generic announce
URL that can be copied into arbitrary torrents.

<Callout type="warn">
  Do not add the old `https://tracker.anibt.net/announce` URL manually. That
  endpoint has been closed and Cloudflare returns 403.
</Callout>

## Current URL shape

Magnets and `.torrent` files generated by AniBT contain a URL shaped like this:

```txt title="Hash-bound tracker"
https://tracker.anibt.net/announce/v1/0000000000-<signed-capability>
```

The capability is bound to the torrent's v1 `info_hash` and cannot be reused for
another torrent. If an external publisher copies an AniBT URL, Cloudflare rejects
the request when the signature does not match the requested `info_hash`. Torrents
whose hashes are not in AniBT's whitelist are also rejected by the tracker.

## Publishing and downloading

- Publishing through the AniBT website or
  [`/api/releases/publish`](/docs/open-api/releases-publish) automatically writes
  the correct signed tracker into the magnet.
- AniBT's `.torrent` download endpoint removes stale AniBT tracker URLs and writes
  exactly one signed URL without changing the torrent's infohash.
- Other third-party trackers are preserved. Keeping one or two reliable public
  trackers is still recommended so the swarm does not depend on one service.
- The generic remote-torrent proxy does not mint an AniBT capability for external
  torrents; it returns the upstream torrent bytes unchanged.

Publishers therefore should not manually add an AniBT tracker in qBittorrent,
Transmission, mktorrent, or an API request. Upload the torrent or submit the magnet
normally and AniBT will sign and canonicalize it.

## Closed endpoints

- `https://tracker.anibt.net/announce`
- `https://tracker.anibt.net/scrape`
- Public `/api/*`
- UDP announce

Tracker statistics use the site's Tailscale-only management API and do not depend
on public scrape requests.
