Entry: `/groups/<slug>/image-host`. Members of that group only. 10 MiB per image.

After upload you can copy the direct link, BBCode, Markdown, and HTML. When dimensions are known, the HTML includes `width` and `height`.

Release notes reserve space for images with dimensions and recognized hosted images, reducing movement as they load. External images without dimensions can still shift the content.

## Delete

The uploader, group owner / administrators, or a site administrator can delete. The request returns `202`. Repeated deletes of the same image reuse the same operation.

| Status | Meaning |
| --- | --- |
| `queued` | Accepted |
| `complete` | On-site short links and `i.anibt.net` direct links return `404` / `410` |
| `failed` | Failed |

`complete` does not include browser caches or third-party reposts.
