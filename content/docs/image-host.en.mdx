---

Entry: `/groups/<slug>/image-host`. Members of that group only. 10 MiB per image.

After upload you can copy the accelerated link, BBCode, Markdown, and HTML.

## Delete

The uploader, group owner / administrators, or a site administrator can delete. The request returns `202`. Repeated deletes of the same image reuse the same operation.

| Status | Meaning |
| --- | --- |
| `queued` | Accepted |
| `complete` | On-site short links and `i.anibt.net` direct links return `404` / `410` |
| `failed` | Failed |

`complete` does not include separate accelerated CDNs, browser caches, or third-party reposts.
