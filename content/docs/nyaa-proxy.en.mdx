---
title: Nyaa proxy publishing
description: Allowlisted subtitle groups can ask AniBT to submit the same release to Nyaa when publishing on the site.
---

Nyaa proxy publishing is for allowlisted subtitle groups: when publishing a release on AniBT, the same release can also be submitted to Nyaa.

The platform Nyaa account is maintained by admins in the backend. Groups only need allowlist approval and must provide a compliant torrent plus publish parameters.

<Callout type="warn">
  <strong className="text-red-600 dark:text-red-400">Groups publishing supersampled or upscaled releases cannot apply for the allowlist.</strong>

  At least 10 cumulative releases on AniBT or other BT sites are required. With fewer than 10 releases, case-by-case applications are still possible, but the submitted release goes through manual review.

  (*Provide images proving the release is self-made, plus screenshots of the BT publishing record.)
</Callout>

<Callout type="warn">
  Proxy publishing does not modify the torrent. Add `http://nyaa.tracker.wf:7777/announce` when creating the torrent; otherwise AniBT rejects the Nyaa submission before it is queued.
</Callout>

Nyaa categories must use official Nyaa category codes. See [Nyaa proxy fields in Publish a release](/en/docs/open-api/releases-publish#nyaa-proxy-fields-and-categories) for the full category table, field aliases, and API parameter meanings.

## Publish methods

<Tabs items={['Web publish', 'API publish']}>
  <Tab value="Web publish">
    <Steps>
      <Step>
        ### Create a torrent with the Nyaa tracker

        Add this tracker to the torrent:

        ```txt title="Nyaa tracker"
        http://nyaa.tracker.wf:7777/announce
        ```
      </Step>

      <Step>
        ### Open the group publish page

        Go to `/groups/<slug>/publish`. If the group is allowlisted, the page shows the **Nyaa Publish** section.
      </Step>

      <Step>
        ### Enable proxy publishing and choose a category

        Turn on proxy publishing and select a Nyaa category. The description can inherit site notes or use custom Markdown.
      </Step>
    </Steps>
  </Tab>

  <Tab value="API publish">
    The API publish page is `/groups/<slug>/publish?tab=api`. Create API keys at `/groups/<slug>/api-keys`.

    ```bash title="Nyaa proxy multipart request"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'torrent=@release.torrent' \
      -F 'title=[Group] Show Title - 01 [1080p][CHS]' \
      -F 'animeIdType=mal' \
      -F 'animeId=58514' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=1_3' \
      -F 'nyaaComplete=false' \
      -F 'nyaaRemake=false' \
      -F 'nyaaDescription=Optional Markdown description for Nyaa'
    ```

    When `nyaaDescription` is omitted, the Nyaa description inherits AniBT `notes`. Custom and inherited descriptions are both limited to 20000 characters. AniBT `notes` may be longer, but a shorter `nyaaDescription` is required when inherited notes exceed the limit. See [Publish a release](/en/docs/open-api/releases-publish#nyaa-proxy-fields-and-categories) for all accepted `nyaaCategory` values.

    Other releases use the same parameters; only the endpoint and base fields differ:

    ```bash title="Other release Nyaa proxy publishing"
    curl -X POST 'https://anibt.net/api/other-releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'category=manga' \
      -F 'title=Example Manga Vol.01' \
      -F 'torrent=@release.torrent' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=3_2' \
      -F 'nyaaComplete=false' \
      -F 'nyaaRemake=false' \
      -F 'nyaaDescription=Optional Markdown description for Nyaa'
    ```

    See [Publish other releases](/en/docs/open-api/other-releases-publish#nyaa-proxy-publishing) for the full other-release parameter list.
  </Tab>
</Tabs>

## Common failures

| Error | Fix |
| --- | --- |
| Group is not allowlisted | Contact an admin and apply with publishing-record evidence. |
| Missing Nyaa tracker | Recreate the torrent with `http://nyaa.tracker.wf:7777/announce`. |
| Nyaa category is missing | Pass `nyaaCategory` in the web form or API request. |
| Nyaa description exceeds 20000 characters | Shorten the site notes, or send a shorter custom Nyaa description / `nyaaDescription`. Full MediaInfo dumps usually exceed the limit. |
| JSON request instead of torrent upload | Nyaa proxy publishing requires server-side validation of actual torrent bytes. Use multipart and upload the `.torrent`. |

For all API fields, see [Publish a release](/en/docs/open-api/releases-publish) and [Publish other releases](/en/docs/open-api/other-releases-publish). For own-account sync, see [Nyaa Sync](/en/docs/site-sync/nyaa).
