AniBT provides an official "Nyaa Platform Proxy" service for verified fansub groups to resolve regional network restrictions and account barriers when distributing anime releases overseas.

<Callout type="warn">
  **Strict Quality Standard**: AI-upscaled, visually degraded, or low-bitrate re-encoded releases are strictly prohibited from applying for or using this proxy service. Any abuse will result in permanent revocation of proxy privileges.
</Callout>

## Whitelist Application Criteria

Teams meeting either of the following criteria may apply by contacting [support@anibt.net](mailto:support@anibt.net):

1. **Standard Path**: At least 10 successful, compliant releases published on AniBT.
2. **Accelerated Path**: New fansub groups needing immediate international distribution can submit recent release links from other major BT trackers (e.g., DMHY, Mikan) alongside proof of original fansub production.

## Torrent Creation Requirements

Platform proxy submits your original `.torrent` file directly to Nyaa without altering any bytes. Therefore, your torrent file must adhere to these technical rules:

<Steps>
  <Step>
    ### Include the Official Nyaa Tracker
    When generating the `.torrent`, its `announce` or `announce-list` must include:

    ```txt title="Nyaa Official Tracker"
    http://nyaa.tracker.wf:7777/announce
    ```

    Torrents lacking this announce address will be rejected immediately by our ingestion guards.
  </Step>

  <Step>
    ### Specify Valid Nyaa Category
    You must provide an appropriate category code. For most non-English translated anime, choose `1_3` (Anime - Non-English-translated). See the table below for standard codes.
  </Step>

  <Step>
    ### Respect Release Notes Limits
    Nyaa limits release descriptions to 20,000 characters. By default, AniBT sends your release notes; if your notes exceed this length, enter a concise version in the designated Nyaa description field.
  </Step>
</Steps>

## Publishing Methods

<Tabs items={['Web Console', 'REST API']}>
  <Tab value="Web Console">
    Whitelisted group members opening `/groups/<slug>/publish` will see the "Proxy to Nyaa" toggle:

    1. Check **Proxy to Nyaa**.
    2. Select the category (e.g., `1_3 - Non-English-translated`).
    3. Optionally mark `Complete` (batch/series completion) or `Remake`.
    4. Submit your release.
  </Tab>

  <Tab value="REST API">
    Call `POST /api/releases/publish` using `multipart/form-data` with the `.torrent` file and proxy flags:

    ```bash title="REST API with Nyaa Proxy"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'torrent=@release.torrent' \
      -F 'title=[Fansub] Series Title - 01 [1080p][CHS]' \
      -F 'animeIdType=bgm' \
      -F 'animeId=12345' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=1_3'
    ```
  </Tab>
</Tabs>
