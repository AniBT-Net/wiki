
## Markdown on the main site

Public HTML pages on AniBT (anime pages, release details) support content negotiation. Send `Accept: text/markdown` to get cleaned Markdown.

```bash title="Request an anime page as Markdown"
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

JSON APIs, RSS feeds, and static files keep their own formats.

## Crawling and indexing the main site

Search engines and other crawlers find AniBT's public pages through `robots.txt` and the sitemaps. Every indexable page declares its own canonical URL. Page content never includes magnet links, torrent download URLs, or infohashes; download addresses are fetched only when you click a button.

    '/anime/<id>': {
      type: 'Indexed',

    },
    '/group/<slug>': {
      type: 'Indexed',
      description: 'Fansub group home. The Releases tab is /group/<slug>?tab=releases; its canonical keeps season and year (or all) and the cursor. The other tabs are canonical at /group/<slug>.',
    },
    '/api/torrent/, /api/other-torrent/': {
      type: 'Not indexed',
      description: 'Torrent downloads may be crawled; responses always carry X-Robots-Tag: noindex.',
    },
  }}
/>

On `/magnets` and the group Releases tab, previous and next are plain links that carry the position in the URL's `cursor` parameter, so every page can be reached without running JavaScript. An expired page link returns to the first page for the same filters.

### robots.txt

`https://anibt.net/robots.txt` does not block `/magnets` or `/search`. Under `/api/`, only `/api/torrent/` and `/api/other-torrent/` may be crawled; other API paths, `/rss/`, and the sign-in and admin paths are blocked.

### Sitemaps

`https://anibt.net/sitemap.xml` is a sitemap index that lists the URL sets below directly, without nesting another index.

      type: 'urlset',

    },

On release URLs, `lastmod` is when the release's content last changed; it is omitted when that time is unknown. A month the index does not list returns `404`. The old `/sitemap-anime.xml` still works, so a webmaster tool that already has it needs no change, but the root index no longer refers to it.
