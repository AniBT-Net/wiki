## Markdown Content Negotiation on HTML Pages

Public HTML pages on AniBT (such as anime overview and release detail pages) support HTTP content negotiation. Supplying `Accept: text/markdown` returns clean Markdown text directly:

```bash title="Request anime page as Markdown"
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

- **Note**: This content negotiation is active for public HTML pages. JSON API endpoints, RSS feeds, and static assets remain in their native formats.
