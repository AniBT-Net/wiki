---
title: LLM integration
description: Markdown entry points for the Wiki and public pages.
---

| Path | Use |
| --- | --- |
| `/llms.txt` | Index |
| `/llms-full.txt` | Full Simplified Chinese |
| `/llms-full.en.txt` | Full English |
| `/docs/<slug>.md` | Per-page source. Prefix `/en` for English, `/zh-Hant` for Traditional Chinese |

Public HTML pages accept `Accept: text/markdown`. JSON, RSS, and images are not converted.

```bash
curl 'https://anibt.net/anime/638151' -H 'Accept: text/markdown'
```

Docs are CC-BY-SA. Keep a link to the original page when citing.
