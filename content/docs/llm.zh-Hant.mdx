```bash title="取單篇文件 Markdown"
curl 'https://wiki.anibt.net/docs/apply.md'
```

## 主站頁面的 Markdown

AniBT 主站公開 HTML 頁（番劇頁、釋出詳情）支援內容協商。請求標頭帶 `Accept: text/markdown` 會回傳清洗後的 Markdown。

```bash title="請求番劇頁 Markdown"
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

JSON 介面、RSS 和靜態檔案仍按各自格式回傳。
