## 專用 LLM 文字索引入口

無需費力解析複雜的 HTML DOM 樹，直接使用 AniBT 為大語言模型預先產生的標準文字端點：

<TypeTable
  type={{
    '/llms.txt': {
      type: 'GET',
      description: '符合 llms.txt 規範的站點摘要、結構大綱與核心文件索引。',
    },
    '/llms-full.txt': {
      type: 'GET',
      description: '全站 Wiki 文件的簡體中文完整拼接純文字，便於全量嵌入與上下文餵入。',
    },
    '/llms-full.en.txt': {
      type: 'GET',
      description: '全站 Wiki 文件的英文完整拼接純文字。',
    },
    '/openapi.yaml': {
      type: 'GET',
      description: 'AniBT 公開 API 的標準 OpenAPI 3.1 契約定義，可直接匯入 Agent 工具庫。',
    },
    '/docs/<slug>.md': {
      type: 'GET',
      description: '取得任意單篇文件的原始 Markdown 內容（英文加 /en 前綴，繁體加 /zh-Hant）。',
    },
  }}
/>

## 公開頁面的 Markdown 內容協商

AniBT 主站的公開 HTML 詳情頁（如番劇頁、釋出詳情頁）支援 HTTP 內容協商。請求標頭中攜帶 `Accept: text/markdown` 即可直接取得清洗後的 Markdown 正文，避免冗餘樣式與腳本干擾：

```bash title="請求番劇頁純 Markdown 內容"
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

- **說明**：該協商機制僅對公開 HTML 頁面生效；JSON 介面、RSS feed 與靜態媒體檔案保持各自原始協議格式回傳。
