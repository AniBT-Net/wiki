---
title: LLM 對接
description: Wiki 與公開頁的 Markdown 入口。
---

| 地址 | 用途 |
| --- | --- |
| `/llms.txt` | 目錄 |
| `/llms-full.txt` | 簡體全文 |
| `/llms-full.en.txt` | 英文全文 |
| `/docs/<slug>.md` | 單頁源。英文加 `/en`，繁體加 `/zh-Hant` |

公開 HTML 頁可帶 `Accept: text/markdown`。JSON、RSS、圖片不轉換。

```bash
curl 'https://anibt.net/anime/638151' -H 'Accept: text/markdown'
```
