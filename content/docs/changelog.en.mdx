## July 5, 2026

<TypeTable
  type={{
    'Anime detail and subscription preview': {
      description: 'Anime detail pages now use a two-column layout, and release / episode lists share a consistent release row. The subscribe dialog previews matches from the show’s recent releases as you adjust groups, resolution, language, subtitle type, file format, or custom tags; after saving, the personal subscription RSS still exports the final server-side subscription results.',
      type: 'Added',
    },
    'Subtitle group image host': {
      description: 'Added /groups/<slug>/image-host. The current interface uses a single upload entry followed by image management, with no top mode switcher or two-column upload panel.       type: 'Added',
    },
    'Image host copy and moderation': {
      description: 'Image management now uses a dense small-thumbnail grid with lazy image loading and paginated loading, while the full copy-format set still opens in a dialog. The site-admin /admin/image-host review page uses the same dense thumbnail approach for scanning recent uploads across subtitle groups and deleting sensitive or policy-breaking images.',
      type: 'Added',
    },
    'Image host permissions and deployment': {
      description: 'Image hosting is limited to subtitle group members and checks membership before reading the body. Delete permissions are limited to the uploader, group owner/admin, or site admin, and deletion now soft-deletes Convex metadata before a media worker asynchronously deletes the object. The Bun native image pipeline converts static images to WebP when possible, preserves animated GIF/WebP/APNG, SVG, and reliably unconvertible images in their original format. Docs now cover the dedicated object bucket, Bun.Image/Bun.S3Client runtime gate, and required Web/worker environment variables.',
      type: 'Docs',
    },
  }}
