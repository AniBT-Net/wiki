Only user-visible feature changes are recorded. Newest first.

## August 31, 2026

- **Fixed duplicate weekly cards across midnight**
  The same episode airing on different platforms is now merged into one card, even when its times cross midnight in Shanghai. Different episodes remain separate.
- **Fixed RSS is current after publication**
  Catalogued, unfiltered fixed RSS feeds (site-wide, group, anime-pair, and other categories) are served from the publication version. Every RSS reader request checks the current version; an unchanged `ETag` may return `304`, and an old body is never authoritative. RSS with `limit`, filters, or search keeps its bounded refresh policy.
- **Personal subscription RSS uses versioned cache identity**
  Updating subscriptions advances the feed version, making the old cache identity unreachable. Credential cleanup is bounded garbage collection and is not the correctness mechanism.
- **New releases no longer wait on a long cache window**
  After a normal publish, the home/release list and fixed RSS converge within a bounded time. If a request temporarily returns `503`, retry after the response's `Retry-After`; taking many minutes to appear is not expected. The RSS client's polling interval still affects when the item is actually seen.

## August 28, 2026

- **Public anime pages use bounded reads**
  Anime detail SSR returns metadata first and hydration issues one release-groups bundle request. The home cross-season weekly view now uses one window read. Successful `/api/anime/groups` JSON, `ETag`, `HEAD`, and `304` behavior is unchanged.
- **Unavailable public projections are explicit**
  Missing or inconsistent projections, bounded-read overflow, and temporary read failures return `503 SEARCH_UNAVAILABLE` with `Retry-After` and `no-store`; `missing_projection` is no longer presented as a 404 or an empty 200.

## August 27, 2026

- **`/magnets` uses previous/next cursors**
  The release list paginates with an opaque `cursor`. Old `/magnets?page=` bookmarks show an invalid state and do not redirect. Open API and RSS are unchanged.

## August 23, 2026

- **Fixed subtitle-group publish preview failures**
  Some anime with generated covers returned HTTP 500 when `preview=true`. Preview creation now succeeds.

## August 22, 2026

- **Bangumi Moe sync now uses account credentials**
  Browser Cookies are no longer used. Enter the username or email and password of an activated account. See [Bangumi Moe sync](/docs/site-sync/bangumi).

## August 17, 2026

- **Other releases add collection, movie, and other**
  Category codes `collection` / `movie` / `other`, mapped to `/rss/other/<category>.xml`. Existing releases are not reclassified.

## August 14, 2026

- **No TOTP**
  Sign-in is email code, password, OAuth, and optional Passkey.

## August 13, 2026

- **Nyaa descriptions capped at 20000 characters**
  Custom descriptions and inherited `notes` share this limit. Site `notes` may still be longer. See [Nyaa proxy](/docs/nyaa-proxy).

## August 11, 2026

- **RSS `<pubDate>` uses Asia/Shanghai**
  RFC 822 is `+0800`; the time embedded in the torrent is RFC 3339 `+08:00`.

## August 8, 2026

- **Image-host deletion progress can be queried**
  Deletion returns `202`. When complete, on-site links are `404` / `410`. Browser caches and reposts outside the site are outside completion. See [Image host](/docs/image-host).

## August 7, 2026

- **Custom release title templates**
  Group members can read them. Create, edit, and delete are limited to the owner / administrators.

## July 30, 2026

- **MediaInfo is plain text**
- **Release notes restore Markdown + raw HTML** (the page does not sanitize)

## July 25, 2026

- **Personal subscription RSS is not stored in the shared cache**
  `/rss/subscriptions.xml` is `private, no-store`.

## July 22, 2026

- **Anime release deletion API**
  `DELETE /api/releases/{releaseId}`, status `GET .../deletion`. `rel_*` only. See [API reference](/docs/open-api/reference).
- **API Key scopes**
  `releases:publish` / `releases:delete`. Old keys have publish only.
- **Email registration verifies first, then sets the password**

## July 19, 2026

- **Tracker is fixed at** `https://tracker.anibt.net/announce`
  Unlisted torrents receive `not whitelisted`. `/scrape` and UDP are closed. See [Tracker](/docs/tracker).

## July 18, 2026

- **Public RSS `limit` is 1–100**; invalid values are no longer truncated.
- **Public HTML supports** `Accept: text/markdown`.

## July 17, 2026

- **Publish whoami**: `GET /api/releases/publish` and `GET /api/other-releases/publish` do not write.
- **A formal publish with no torrent and size 0 returns 422** `EMPTY_RELEASE_CONTENT`. Preview still allows it.

## July 16, 2026

- **RSS adds** `<anibt:bgmId>` (emitted only when bound). `/rss/other/*` does not.
- **Torrent match is POST only** `/api/animes/torrent-match`. GET returns 405.

## July 12, 2026

- **Publish errors use a unified JSON envelope**
  503 during deployment, 409 for a duplicate version, 429 when rate-limited. Includes `Retry-After`.

## July 7, 2026

- **Publish anime IDs unified as** `animeIdType` + `animeId` (`bgm` / `anilist` / `mal` / `anidb`). `bgmId` remains compatible.

## July 6, 2026

- **Publish language codes expanded**; `language` is no longer limited to 4 items.
- **`/api/seasons/anime` adds `query`**

## July 5, 2026

- **Subtitle group image host**
  `/groups/<slug>/image-host`. See [Image host](/docs/image-host).

## July 4, 2026

- **Seasonal anime adds** `rssReleaseCount` / `hasRelease`
- **RSS opened in a browser is native XML**

- **Other releases support Nyaa proxy publishing**
