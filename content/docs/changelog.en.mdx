This page logs user-facing features, enhancements, and fixes for visitors, anime fans, and fansub groups.

<Callout type="info">
  Entries are listed in reverse chronological order. If you encounter any bugs during regular use, feel free to report them via our [Support Email](/en/docs/contact).
</Callout>

## September 17, 2026

- **Image Host HTML Includes Width & Height Attributes**
  HTML code copied from the fansub image host now embeds real image pixel `width` and `height` attributes. Release notes reserve space in advance, eliminating Cumulative Layout Shift (CLS) when images finish loading.

## September 15, 2026

- **Smoother Expired Session Redirects**
  When a login session expires, opening the sign-in page stays on the login form without bouncing to and from the homepage. Signed-in users still redirect back to their previous page automatically.
- **Improved Multi-Device Sign-Out Verification**
  When signing out on another device, local credentials reconcile within ~5 minutes. Sensitive operations (password updates, fansub administration, release publishing) immediately verify active server sessions.

## September 14, 2026

- **Open API External Sync Status Inspection**
  Fansub API keys with `releases:sync:read` scope can now call `GET /api/releases/{releaseId}/sync-status` to inspect real-time publishing results, external links, error messages, and retry histories across Bangumi Moe, Mikan, DMHY, ACGNX, ACG.rip, and Nyaa.

## September 10, 2026

- **Live UI Updates in Fansub Console**
  Confirming a release deletion immediately removes the item from the list with localized completion feedback. Anime claims and release title templates also update in real time without requiring manual page refreshes.
- **Torrent File Mandatory for API Releases**
  Both anime and other releases via Open API now mandate torrent bytes (multipart `.torrent` upload or JSON `torrentStorageId`). Releasing with only a magnet URI returns `422 TORRENT_REQUIRED`, ensuring valid distribution and tracker whitelist registration.
- **Fixed Detail Pages for Movies and Specials**
  Resolved an issue where certain movie/OVA/BD release detail pages threw errors and prevented torrent downloads.
- **Add Registered Members Directly**
  The team member management interface in the fansub console now adds members directly using their registered email or user ID.

## September 2, 2026

- **Streamlined Image Host Export Formats**
  The image host management interface now provides four standardized embed formats: Direct URL, BBCode, Markdown, and Anti-shift HTML.

## August 31, 2026

- **Fixed Duplicate Midnight Episodes in Schedule**
  Episodes airing across midnight across different broadcast platforms are now unified into a single calendar card.
- **Faster RSS Visibility for New Releases**
  Newly published releases now propagate into site-wide magnets, group feeds, and anime category RSS feeds with significantly lower latency.

## August 22, 2026

- **Bangumi Moe Sync Uses Account & Password**
  Due to authentication changes on the upstream platform, Bangumi Moe sync now requires an email-activated username/email and password instead of legacy browser cookies.

## August 17, 2026

- **Expanded Categories for Other Releases**
  In addition to regular anime releases, the "other" category now supports manga, music, raw footage, stage plays, collections, and movie specials, along with dedicated RSS feeds.
