Subtitle-group publishing still requires a separate [admission application](/docs/apply).

## Register

1. Enter an email, complete human verification, and get a 6-digit code (valid for 10 minutes).
2. Enter a display name, password, and the code.
3. After verification succeeds, the password is registered. If this step is interrupted, retry in the same tab. Do not reuse a consumed code.

A registered address still shows a send-success message, but no new registration code is sent. Use sign-in or password recovery.

Codes, CAPTCHA, and third-party sign-in callbacks are one-time. Do not refresh the callback page repeatedly.

## Sign in

| Method | Notes |
| --- | --- |
| Email and password | Email + password + human verification. Repeated failures are rate-limited. |
| Third-party | The sign-in page shows currently enabled providers. On failure, return to the sign-in page and start again. |
| Forgot password | Use the entry on the sign-in page. Mail is sent in the background; a short delay does not mean failure. |

The site does not provide TOTP / two-factor authentication.

## Sign-in state

Opening the sign-in page while already signed in returns you to the previous page. If the sign-in is no longer valid, the sign-in page stays put instead of bouncing to the home page and back.

After you sign out on another device, this browser may still look signed in for up to about five minutes. Sensitive actions such as changing the password always follow the server session.
