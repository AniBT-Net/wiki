title: Nyaa 代发

平台使用站点 Nyaa 账号代发。字幕组需在白名单内。**发布超分资源者不能申请。**

累计发布满 10 次可申请。未满 10 次可单独申请，须提交自制资源图片和 BT 发布记录截图。

## 前提

- 字幕组已加入白名单，否则发布页无开关，API 会拒绝。
- `.torrent` 的 announce 必须包含 `http://nyaa.tracker.wf:7777/announce`。不会自动添加缺失的 tracker；已有 tracker 的排列可调整为 Nyaa 能识别的格式，infohash 不变。
- 每次必须选 Nyaa 分类。中文动画字幕常用 `1_3`。
- 提交到 Nyaa 的说明最多 20000 字。默认用本站 `notes`，也可单独填写。本站 `notes` 仍可更长。

分类代码见 [发布资源](/docs/open-api/releases-publish#nyaa-代发字段和分类)。

## 发布

网页：`/groups/<slug>/publish`，打开 Nyaa 代发并选分类。

API：`nyaa=true`，`nyaaCategory` 必填。须 multipart 上传种子。

```bash
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'torrent=@release.torrent' \
  -F 'title=[字幕组] 作品名 - 01 [1080p][CHS]' \
  -F 'nyaa=true' \
  -F 'nyaaCategory=1_3'
```

其他类资源用 `/api/other-releases/publish`，同样参数。

## 与 Nyaa 同步的区别

| | 同步 | 代发 |
| --- | --- | --- |
| 账号 | 字幕组自己的 Nyaa 账密 | 平台账号 |
| 入口 | [站点同步](/docs/site-sync/nyaa) | 本页 |
| 条件 | 自备账号 | 白名单 + Nyaa tracker |

## 补发旧发布

<Callout type="warn">
仅字幕组所有者、字幕组管理员和站点管理员可以操作。原始 `.torrent` 缺少所需 tracker 或无法解析时，补发失败，不会上传到 Nyaa。系统不会自动补齐缺失的 tracker。
</Callout>

<Steps>
<Step>
### 打开补发
在 `/groups/<slug>/releases` 找到番剧资源，点击行尾的「Nyaa 补发」。之前没有选择代发的旧发布也可使用。
</Step>
<Step>
### 确认代发选项
检查分类、合集、重制及说明。已有代发选项会自动带入，说明可继承本站简介或单独填写。平台代发保持匿名发布。
</Step>
<Step>
### 查看结果
确认补发后，在弹窗查看排队、同步进度、失败原因和外站链接。关闭弹窗后可重新打开查看。
</Step>
</Steps>

tracker 缺失时，请使用包含 `http://nyaa.tracker.wf:7777/announce` 的种子重新发布。仅修改磁力链接或字幕组设置不能替代原始种子检查。
