平台使用站点 Nyaa 账号代发。字幕组需在白名单内。**发布超分资源者不能申请。**

累计发布满 10 次可申请。未满 10 次可单独申请，须提交自制资源图片和 BT 发布记录截图。

## 前提

- 字幕组已加入白名单，否则发布页无开关，API 会拒绝。
- `.torrent` 的 announce 必须包含 `http://nyaa.tracker.wf:7777/announce`。代发不改种子。
- 每次必须选 Nyaa 分类。中文动画字幕常用 `1_3`。
- 提交到 Nyaa 的说明最多 20000 字。默认用本站 `notes`，也可单独填写。本站 `notes` 仍可更长。

分类代码见 [发布资源](/docs/open-api/releases-publish#nyaa-代发字段和分类)。

## 发布

网页：`/groups/<slug>/publish`，打开 Nyaa 代发并选分类。

API：`nyaa=true`，`nyaaCategory` 必填。须 multipart 上传种子。

```bash
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'torrent=@release.torrent' \
  -F 'title=[字幕组] 作品名 - 01 [1080p][CHS]' \
  -F 'nyaa=true' \
  -F 'nyaaCategory=1_3'
```

其他类资源用 `/api/other-releases/publish`，同样参数。

## 与 Nyaa 同步的区别

| | 同步 | 代发 |
| --- | --- | --- |
| 账号 | 字幕组自己的 Nyaa 账密 | 平台账号 |
| 入口 | [站点同步](/docs/site-sync/nyaa) | 本页 |
| 条件 | 自备账号 | 白名单 + Nyaa tracker |
