title: Nyaa 代发
description: 白名单字幕组可在 AniBT 发布时，由平台代为向 Nyaa 提交同一资源。
---

Nyaa 代发面向已加入白名单的字幕组：在 AniBT 发布资源时，可同步请求将同一条资源提交到 Nyaa。

平台 Nyaa 账号由管理员在后台维护。字幕组只需通过白名单，并在发布时提交符合要求的种子与参数。

<Callout type="warn">
  <strong className="text-red-600 dark:text-red-400">发布超分资源者无法申请白名单。</strong>

  在本站或其它 BT 站累计发布次数须达到 10 次及以上。发布次数未满 10 次但希望发布至 Nyaa 时，可按情况单独申请白名单，提交内容将经过人工审核。

  （*须提交资源为本人自制的相关图片，以及 BT 发布记录截图。）
</Callout>

## 发布方式

<Tabs items={['网页发布', 'API 发布']}>
  <Tab value="网页发布">
    <Steps>
      <Step>
        ### 制作带 Nyaa tracker 的种子

        在种子的 tracker 列表中加入：

        ```txt title="Nyaa tracker"
        http://nyaa.tracker.wf:7777/announce
        ```
      </Step>

      <Step>
        ### 打开字幕组发布页

        进入 `/groups/<slug>/publish`。字幕组已加入白名单时，页面会显示 **Nyaa 发布** 区块。
      </Step>

      <Step>
        ### 开启代发并选择分类

        打开代发开关，选择 Nyaa 分类。说明可继承本站 notes，也可单独填写 Markdown。
      </Step>
    </Steps>
  </Tab>

  <Tab value="API 发布">
    API 发布页位于 `/groups/<slug>/publish?tab=api`，API Key 在 `/groups/<slug>/api-keys` 创建。

    ```bash title="Nyaa 代发 multipart 请求"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'torrent=@release.torrent' \
      -F 'title=[字幕组] 作品名 - 01 [1080p][CHS]' \
      -F 'animeIdType=mal' \
      -F 'animeId=58514' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=1_3' \
      -F 'nyaaComplete=false' \
      -F 'nyaaRemake=false' \
      -F 'nyaaDescription=可选：覆盖提交到 Nyaa 的 Markdown 说明'
    ```

    未传 `nyaaDescription` 时，Nyaa 说明继承本站发布说明 `notes`。`nyaaCategory` 完整可选值见 [发布资源 API](/docs/open-api/releases-publish#nyaa-代发字段和分类)。

    其他类资源使用同一组参数，仅端点与基础字段不同：

    ```bash title="其他类资源 Nyaa 代发"
    curl -X POST 'https://anibt.net/api/other-releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'category=manga' \
      -F 'title=Example Manga Vol.01' \
      -F 'torrent=@release.torrent' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=3_2' \
      -F 'nyaaComplete=false' \
      -F 'nyaaRemake=false' \
      -F 'nyaaDescription=可选：覆盖提交到 Nyaa 的 Markdown 说明'
    ```

    其他类资源完整参数见 [发布其他类资源 API](/docs/open-api/other-releases-publish#nyaa-代发)。
  </Tab>
</Tabs>

## 常见失败原因

| 错误 | 处理 |
| --- | --- |
| 未加入白名单 | 联系管理员申请白名单，并按本页要求提交发布记录证明。 |
| 缺少 Nyaa tracker | 重新制作种子，加入 `http://nyaa.tracker.wf:7777/announce`。 |
| 未选择 Nyaa 分类 | 在发布页或 API 参数中传入 `nyaaCategory`。 |
| 提交的是 JSON 而不是 torrent 文件 | Nyaa 代发需要服务端校验实际 torrent bytes，请使用 multipart 上传 `.torrent`。 |

接口字段详见 [发布资源 API](/docs/open-api/releases-publish) 与 [发布其他类资源 API](/docs/open-api/other-releases-publish)。自备账号同步见 [Nyaa 同步](/docs/site-sync/nyaa)。
