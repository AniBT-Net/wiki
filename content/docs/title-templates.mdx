title: 番剧标题模板
description: 为同一番剧分别配置简体、繁体与简繁标题模板，并在发布第三步快速切换自动、指定模板或手工标题。
---

字幕组可以为每个番剧保存三套标题模板：**简体**、**繁体**和**简繁**。发布时，AniBT 会根据每条资源的字幕语言选择对应槽位，也允许临时指定其他模板或直接手工修改标题。

## 使用流程

1. 打开 `/groups/<slug>/settings`，在“标题模板”中设置字幕组默认模板；需要自定义命名规则时，可在同一区域创建自定义模板并设为默认。
2. 打开 `/groups/<slug>/anime_templates`，添加或编辑番剧模板。
3. 分别切换“简体 / 繁体 / 简繁”槽位，为每个槽位选择内置模板、自定义模板或“继承”。选择器支持搜索并立即显示示例标题。
4. 进入 `/groups/<slug>/publish`。在第三步检查每条资源的标题模式；需要统一调整时，先勾选资源，再使用批量标题模板操作。

## 三个语言槽位

| 资源语言 | 自动使用的番剧槽位 |
| --- | --- |
| 包含 `CHS`、不包含 `CHT` | 简体 |
| 包含 `CHT`、不包含 `CHS` | 繁体 |
| 同时包含 `CHS` 与 `CHT` | 简繁 |
| 不包含 `CHS` 或 `CHT` | 不使用番剧语言槽位，直接进入字幕组默认回退 |

槽位显示“继承”时，不会复制一份默认模板，而是在发布时按当前字幕组设置动态解析。自动模式的完整顺序是：

```text
对应番剧槽位
→ 字幕组默认自定义模板
→ 字幕组默认内置模板
→ 原始种子标题
```

因此可以只为有特殊命名需求的语言配置槽位，其余语言继续跟随字幕组默认值。内置模板也包含“合集”，可用于批量集数或合集资源。

## 发布第三步的标题模式

每条资源的标题按钮会显示当前模式和来源。打开后可搜索并从三组结果中选择：

- **番剧自动**：根据资源语言使用番剧槽位，并按上面的回退顺序生成标题。
- **字幕组自定义模板**：固定使用选中的自定义模板。
- **内置模板**：固定使用选中的内置模板。

直接编辑标题文本会切换到**手工标题**。手工标题不会因为之后修改番剧、集数、语言、分辨率或封装格式而被自动覆盖。重新选择“番剧自动”或某个模板后，标题才会恢复自动生成。

## 批量选择

发布第三步支持对已勾选资源批量应用标题模式。选择器顶部的示例只用于展示一个代表资源；实际应用时，每条资源都会使用自己的番剧、语言、集数和媒体参数独立生成标题，不会把同一个示例标题复制给所有资源。批量操作完成后可以立即撤销。

<Callout type="info">
  推荐把常规规则放在字幕组默认模板，只为确实需要区别简体、繁体或简繁命名的番剧设置专属槽位。这样后续调整默认规则时，仍处于“继承”的番剧会自动跟随。
</Callout>
