---
title: 字幕组图床
description: 在字幕组后台图床模块上传图片，复制全球加速链接、BBCode、Markdown、HTML 等格式。
---

字幕组图床用于在组内上传发布相关图片，并复制多种引用格式。入口位于字幕组后台 **图床** 模块，通过 Web 上传。

上传成功后可复制：

| 格式 | 示例 |
| --- | --- |
| 全球加速链接 | `https://i.anibt.net/image-host/2026/07/05/Ab3CdE1/pasted-image.webp` |
| BBCode | `[img]https://i.anibt.net/image-host/2026/07/05/Ab3CdE1/pasted-image.webp[/img]` |
| Markdown | `![pasted-image.webp](https://i.anibt.net/image-host/2026/07/05/Ab3CdE1/pasted-image.webp)` |
| HTML | `<img src="https://i.anibt.net/image-host/2026/07/05/Ab3CdE1/pasted-image.webp" alt="pasted-image.webp">` |
| BBCode 链接 | `[url=https://anibt.net/i/Ab3CdE1][img]https://i.anibt.net/image-host/...webp[/img][/url]` |
| BBCode 直链 | `[url=https://i.anibt.net/image-host/...webp][img]https://i.anibt.net/image-host/...webp[/img][/url]` |
| HTML 链接 | `<a href="https://anibt.net/i/Ab3CdE1" target="_blank" rel="noopener noreferrer"><img src="..." alt="..."></a>` |
| HTML 直链 | `<a href="https://i.anibt.net/image-host/...webp" target="_blank" rel="noopener noreferrer"><img src="..." alt="..."></a>` |

<Callout type="info">
  图床仅对已加入该字幕组的成员开放。菜单路径：字幕组后台 → **图床**（`/groups/<slug>/image-host`）。
</Callout>
