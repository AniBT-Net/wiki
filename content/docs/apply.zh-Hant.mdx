---
title: 申請入駐
description: 字幕組透過郵件提交入駐申請；站務人工核驗身份後開通釋出權限。
---

AniBT 不提供自助開通釋出權限。**字幕組**須按下列流程發郵件申請，由站務人工審核。通過後，會在已有普通帳號上綁定字幕組身份並開通釋出能力，之後可使用 [釋出 API](/docs/open-api/releases-publish) 推送資源，並透過 [站點同步](/docs/site-sync) 同步到其它 BT 站。

## 申請材料

<Steps>
  <Step>
    ### 使用註冊郵箱傳送

    須使用在 AniBT 註冊時填寫的郵箱傳送申請，用於核對申請人與帳號持有人一致。

    尚未註冊時，先閱讀[帳號、登入與 session](/docs/account-auth)，在 [anibt.net](https://anibt.net) 註冊普通帳號，再用同一郵箱發申請。
  </Step>
  <Step>
    ### 字幕組基本資訊

    郵件正文需包含：

    - **組名**：字幕組完整名稱。
    - **slug**：簡短、穩定的英文標識，作為唯一 ID（例如 `sakura-sub`）。開通後不宜更改，會出現在 [`/rss/group/<slug>.xml`](/docs/open-api/other-endpoints) 等公開 URL 中。
    - **簡要介紹**：一兩段說明作品類型、活躍時長與目前釋出節奏。
    - **聯絡方式**：Telegram、官網、Discord、郵件群組等可反向聯絡到字幕組的渠道。
  </Step>
  <Step>
    ### 身份證明（任選一項）

    提供下列材料之一即可，**不必全部提供**：

    - 字幕組在 nyaa / 末日站 / Mikan / ACG.rip 等站點已使用的釋出帳號或郵箱（用於比對）。
    - 官方網站 / Telegram 頻道 / Twitter 等公開渠道的管理員證明（例如臨時置頂一條宣告）。
    - 在既有字幕組成員中被廣泛認可的其它身份證據。

    目的是確認申請人代表該字幕組，避免冒用他人名義佔用 slug。
  </Step>
</Steps>

## 傳送地址

<Callout type="info">
  傳送至 **[support@anibt.net](mailto:support@anibt.net)**。主題建議寫 `字幕組入駐申請 - <組名>`。通常在幾個工作日內回覆。
</Callout>

若一週內未收到回覆（請同時檢查垃圾郵件箱），可再發一次，或透過 [其他聯絡方式](/docs/contact) 提醒站務。

## 審核通過後

站務會郵件確認開通，並在帳號上完成：

- 綁定字幕組身份與 slug。
- 開通 [釋出 API](/docs/open-api/releases-publish) 訪問權限（生成 API Key）。
- 字幕組出現在站點列表與 [字幕組 RSS](/docs/open-api/other-endpoints) 中。
