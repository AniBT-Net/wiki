---
title: 申請入駐
description: 用註冊郵箱發郵件申請字幕組釋出權限。
---

釋出權限不自助開通。用 **AniBT 註冊郵箱** 發到 [support@anibt.net](mailto:support@anibt.net)，主題：`字幕組入駐申請 - <組名>`。

## 郵件內容

- **組名**
- **slug**：穩定英文標識，例如 `sakura-sub`。開通後會出現在公開 URL 中，不宜更改。
- **簡介**：作品類型、活躍情況。
- **聯絡方式**：可反向聯絡到字幕組的渠道。
- **身份證明（任選一項）**：其它 BT 站帳號、公開頻道管理員證明，或等價材料。

尚未註冊時，先完成 [帳號](/docs/account-auth)。

通常幾個工作日內回覆。一週無回覆時檢查垃圾郵件後可再發一次。

開通後會綁定 slug、發放 API Key，字幕組出現在站內列表和 RSS。接著配置 [站點同步](/docs/site-sync)、[Tracker](/docs/tracker)、[釋出 API](/docs/open-api/reference)。
