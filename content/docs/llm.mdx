## 公开页面的 Markdown 内容协商

AniBT 主站的公开 HTML 详情页（如番剧页、发布详情页）支持 HTTP 内容协商。请求头中携带 `Accept: text/markdown` 即可直接获取清洗后的 Markdown 正文，避免冗余样式与脚本干扰：

```bash title="请求番剧页纯 Markdown 内容"
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

- **说明**：该协商机制仅对公开 HTML 页面生效；JSON 接口、RSS feed 与静态媒体文件保持各自原始协议格式返回。
