## 公开页面实时转换

AniBT 已启用 Cloudflare Markdown for Agents。请求公开 HTML 页面时加入 `Accept: text/markdown`：

```bash
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

成功响应使用 `Content-Type: text/markdown; charset=utf-8`，并包含：

- `Vary: accept`：HTML 与 Markdown 使用不同缓存变体。
- `x-markdown-tokens`：转换后 Markdown 的估算 token 数。
- `x-original-tokens`：转换前 HTML 的估算 token 数。
- `Content-Signal: ai-train=yes, search=yes, ai-input=yes`：当前公开内容允许用于 AI 训练、搜索与 Agent 输入。

仅转换 HTML。JSON API、RSS/XML、图片与 R2 对象保持原内容类型。实时转换会移除脚本、样式、导航等非正文内容；若页面同时渲染多套响应式 DOM，结果仍可能出现重复区块。抓取 Wiki 文档时优先使用上方静态 `.md` 或 `llms-full.*` 端点。

## 用法示例

### ChatGPT / Claude / Gemini Web UI

将 URL 粘贴进对话即可：

```txt
请基于这份文档回答后续问题：
https://anibt.net/llms-full.en.txt
```

模型会拉取并将整份文档载入上下文。`llms-full.en.txt` 约 80 KB，主流大模型可一次完整载入。

### Cursor / Continue / Cline 等 IDE Agent

将 `.md` 端点配置为自定义文档。Cursor 的 `@Docs` 也支持该格式：

```txt
https://anibt.net/llms.txt
```

Agent 会展开索引，并按需抓取每篇 `.md`。

### RAG / 自建 pipeline

```python title="拉取整站做向量化"
import requests, re

base = 'https://anibt.net'
index = requests.get(f'{base}/llms.txt').text

# llms.txt 里每行的 (link) 就是一篇文档；加上 .md 后缀就是源
urls = re.findall(r'\(([^)]+)\)', index)
for path in urls:
    if not path.startswith('/docs'):
        continue
    md = requests.get(f'{base}/zh-CN{path}.md').text
    # → 喂进 chunker / embedder
```

仅需英文时将语言段换为 `/en`（默认 zh-CN 无前缀；英文为 `/en`，繁体为 `/zh-Hant`）。

## 端点对比

| 端点                    | 内容                            | 推荐用途                          |
| ----------------------- | ------------------------------- | --------------------------------- |
| `/llms.txt`             | 站点目录 + 链接（数 KB）         | 给 Agent 作 sitemap，按需抓取     |
| `/llms-full.txt`        | 全部 zh-CN 内容（约 80 KB）     | 一次性载入中文 LLM                |
| `/llms-full.en.txt`     | 全部英文内容                    | 国际 LLM / 英文回答               |
| `/<lang>/docs/<slug>.md`| 单页源 Markdown                | 精准引用某一篇                    |
| `Accept: text/markdown` | 任意公开 HTML 页的实时转换      | Agent 临时抓取站点公开页面         |

<Callout type="info">
  `llms.txt`、`llms-full.*` 与单页 `.md` 为**纯静态产物**，缓存 1 年（`Cache-Control: s-maxage=31536000`）。Wiki 更新发布后会重新构建，通常几分钟内端点随之更新。`Accept: text/markdown` 实时转换沿用原 HTML 页面的缓存策略。
</Callout>

## 内容覆盖

`/llms.txt` 与 `/llms-full.*` 的来源即本 Wiki，包括：

- 站点同步流程
- [公开 API](/docs/open-api)（RSS / JSON / 缓存 / 限流 / 故障排查）
- [Tracker 地址](/docs/tracker)
- [相关项目](/docs/projects)

任意 Wiki 页面均可加 `.md` 取得源文件。例如：

```txt
原始页面     https://anibt.net/zh-CN/docs/open-api/rss-anime
Markdown 源  https://anibt.net/zh-CN/docs/open-api/rss-anime.md
```
