## 主站页面的 Markdown

AniBT 主站公开 HTML 页（番剧页、发布详情）支持内容协商。请求头带 `Accept: text/markdown` 会返回清洗后的 Markdown。

```bash title="请求番剧页 Markdown"
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

JSON 接口、RSS 和静态文件仍按各自格式返回。

## 主站抓取与收录

搜索引擎和其他抓取程序从 `robots.txt` 与站点地图发现 AniBT 主站的公开页面。每个可收录页面有三种语言地址：简体中文不带前缀，繁体中文在 `/zh-hant/…`，英文在 `/en/…`。每种语言地址都声明自己的 canonical，不指回简体地址。页面内容不含磁力链接、种子下载地址或 infohash，下载地址在点击按钮时才获取。

### 可收录页面

下表列出不带前缀的简体地址，`/zh-hant/…` 与 `/en/…` 形式的规则相同。

<TypeTable
  type={{
    '/release/<id>、/other-release/<id>': {

      description: '资源详情页。canonical 为页面自身。',

    '/magnets': {
      type: '收录',
      description: '资源列表，包括分类、筛选、排序和翻页后的页面。canonical 保留这些参数与 cursor。带 q 关键词的列表为 noindex, follow。',
    },
    '/search?q=…': {
      type: '有结果时收录',
      description: '番剧搜索结果页。canonical 保留 q 以及 format、status、seasonYear 筛选。没有关键词或没有结果时为 noindex, follow。',
    },
    '/anime/<id>': {
      type: '收录',

    },
    '/group/<slug>': {

`/magnets` 与字幕组「发布」页签的上一页、下一页是普通链接，翻页位置写在 URL 的 `cursor` 参数中，不执行 JavaScript 也能逐页访问。分页链接失效时回到当前条件的第一页。

### 语言版本

可收录页面在 HTML `<head>` 中列出自己的三种语言地址（hreflang `zh-Hans`、`zh-Hant`、`en`），其中包括页面自身，另有 `x-default` 指向简体地址。三种地址的路径和查询参数相同。

```html title="/en/anime/617123 的 head（节选）"
<link rel="canonical" href="https://anibt.net/en/anime/617123"/>
<link rel="alternate" hrefLang="zh-Hans" href="https://anibt.net/anime/617123"/>
<link rel="alternate" hrefLang="zh-Hant" href="https://anibt.net/zh-hant/anime/617123"/>
<link rel="alternate" hrefLang="en" href="https://anibt.net/en/anime/617123"/>
<link rel="alternate" hrefLang="x-default" href="https://anibt.net/anime/617123"/>
```

noindex 页面（没有关键词或没有结果的搜索、带 q 关键词的 `/magnets`）、错误页、登录页和登录后才能访问的页面不输出语言互指。

### robots.txt

`https://anibt.net/robots.txt` 不禁止抓取 `/magnets` 与 `/search`，也不禁止它们的 `/zh-hant/`、`/en/` 形式。`/api/` 下只允许抓取 `/api/torrent/` 和 `/api/other-torrent/`；其他接口、`/rss/`、登录和后台路径禁止抓取。后台、登录和注册路径的 `/zh-hant/`、`/en/` 形式（例如 `/en/admin/`、`/zh-hant/auth/`、`/en/sign-in`）同样禁止抓取；接口和 RSS 没有语言前缀。

### 站点地图

`https://anibt.net/sitemap.xml` 是站点地图索引，直接列出下面的 URL 集合，不嵌套其他索引。

<TypeTable
  type={{
    '/sitemap-static.xml': {
      type: 'urlset',
      description: '固定页面，包括 /magnets 及其各分类页。',
    },
    '/sitemap-groups.xml': {
      type: 'urlset',
      description: '字幕组主页，不带 lastmod。',
    },
    '/sitemap-seasons.xml': {
      type: 'urlset',
      description: '当前季度之前、有 TV 动画的季度页 /seasonal?season=…&year=…。',
    },
    '/sitemap-anime/<起始年>-<结束年>.xml': {
      type: 'urlset',
      description: '番剧页，按年代分片，例如 /sitemap-anime/2020-2029.xml。',
    },
    '/sitemap-releases/<YYYY-MM>.xml': {
      type: 'urlset',
      description: '番剧资源详情页，按资源创建时间所在的北京时间（UTC+8）月份分片，新月份在前。每个文件最多 16,666 个资源（每个资源三种语言共 3 条 URL）。一个月份放不下时，依次拆成 <YYYY-MM>-2.xml、<YYYY-MM>-3.xml。',
    },
    '/sitemap-other-releases/<YYYY-MM>.xml': {
      type: 'urlset',
      description: '其他类资源详情页，分片规则同上。',
    },
  }}
/>

资源 URL 的 `lastmod` 是该资源内容最近一次变更的时间，时间未知时省略。索引没有列出的月份分片返回 `404`。旧的 `/sitemap-anime.xml` 仍可访问，已经提交它的站长平台不需要修改，但根索引不再引用它。

每个 URL 集合把每个页面列出三次：不带前缀、`/zh-hant/`、`/en/` 各一条 `<url>`。每条都附带与页面 head 相同的 `xhtml:link` 语言互指，三条的 `lastmod` 相同。

```xml title="/sitemap-releases/2026-10.xml 中的一条（节选）"
<url>
  <loc>https://anibt.net/release/rel_-OH17wI8Sghm</loc>
  <lastmod>2026-09-30T16:04:00.592Z</lastmod>
  <xhtml:link rel="alternate" hreflang="zh-Hans" href="https://anibt.net/release/rel_-OH17wI8Sghm"/>
  <xhtml:link rel="alternate" hreflang="zh-Hant" href="https://anibt.net/zh-hant/release/rel_-OH17wI8Sghm"/>
  <xhtml:link rel="alternate" hreflang="en" href="https://anibt.net/en/release/rel_-OH17wI8Sghm"/>
  <xhtml:link rel="alternate" hreflang="x-default" href="https://anibt.net/release/rel_-OH17wI8Sghm"/>
</url>
<!-- 随后是 /zh-hant/release/rel_-OH17wI8Sghm 与 /en/release/rel_-OH17wI8Sghm 两条，互指相同 -->
```

### 删除的资源

资源删除后，详情页的三种语言地址和种子下载地址都返回 `404`：

- 番剧资源：`/release/<id>`、`/zh-hant/release/<id>`、`/en/release/<id>`、`/api/torrent/<id>.torrent`
- 其他类资源：`/other-release/<id>`、`/zh-hant/other-release/<id>`、`/en/other-release/<id>`、`/api/other-torrent/<id>.torrent`

删除回执为 `completed` 时（见 [删除状态](/docs/open-api/releases-deletion)），这四个地址都已确认返回 `404`。站点地图随后不再列出该资源，IndexNow 也会收到这三个详情页地址的删除通知。

### IndexNow

AniBT 通过 [IndexNow](https://www.indexnow.org/) 向参与该协议的搜索引擎通知资源详情页的变化，提交地址为 `https://api.indexnow.org/indexnow`。

<TypeTable
  type={{
    '新公开或内容变更': {
      type: '提交 1 个地址',
      description: '不带前缀的简体详情页地址：/release/<id> 或 /other-release/<id>。',
    },
    '删除': {
      type: '提交 3 个地址',
      description: '三种语言的详情页地址，确认它们都返回 404 后提交。',
    },
  }}
/>

- 变更按 5 分钟为一个窗口合并，每个窗口提交一批，同一窗口内重复的地址只提交一次。提交前会再次确认资源仍公开或已删除。
- 只提交资源详情页。番剧页、字幕组页和列表页通过站点地图与普通抓取发现；搜索、带查询参数的地址、下载地址、API、发布预览和登录后才能访问的页面不会提交。
- 密钥文件位于 `https://anibt.net/<key>.txt`，以 `text/plain` 返回。
- IndexNow 返回 `200` 或 `202` 只表示已接收提交，不代表页面已被收录。Google 不参与 IndexNow。
