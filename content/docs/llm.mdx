---
title: LLM 对接
description: Wiki 与公开页的 Markdown 入口。
---

| 地址 | 用途 |
| --- | --- |
| `/llms.txt` | 目录 |
| `/llms-full.txt` | 简体全文 |
| `/llms-full.en.txt` | 英文全文 |
| `/docs/<slug>.md` | 单页源。英文加 `/en`，繁体加 `/zh-Hant` |

公开 HTML 页可带 `Accept: text/markdown`。JSON、RSS、图片不转换。

```bash
curl 'https://anibt.net/anime/638151' -H 'Accept: text/markdown'
```
