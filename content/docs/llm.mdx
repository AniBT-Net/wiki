## 公开页面实时转换

AniBT 已启用 Cloudflare Markdown for Agents。请求公开 HTML 页面时加入 `Accept: text/markdown`：

```bash
curl 'https://anibt.net/anime/638151' \
  -H 'Accept: text/markdown'
```

成功响应会使用 `Content-Type: text/markdown; charset=utf-8`，并包含：

- `Vary: accept`：HTML 与 Markdown 使用不同缓存变体。
- `x-markdown-tokens`：转换后 Markdown 的估算 token 数。
- `x-original-tokens`：转换前 HTML 的估算 token 数。
- `Content-Signal: ai-train=yes, search=yes, ai-input=yes`：当前公开内容允许用于 AI 训练、搜索与 Agent 输入。

只会转换 HTML。JSON API、RSS/XML、图片与 R2 对象仍保持原本的内容类型。实时转换会移除脚本、样式、导航等非正文内容，但页面若同时渲染多套响应式 DOM，结果仍可能出现重复区块；抓取 Wiki 文档时优先使用上面的静态 `.md` 或 `llms-full.*` 端点。

## 用法示例

### ChatGPT / Claude / Gemini 的 Web UI

直接把 URL 贴进对话即可：

```txt
请基于这份文档回答我后续的问题：
https://anibt.net/llms-full.en.txt
```

模型会拉取并把整份文档进上下文。`llms-full.en.txt` ~80 KB，对主流大模型来说一次喂完没问题。

### Cursor / Continue / Cline 等 IDE Agent

把 `.md` 端点配成"自定义文档"。Cursor 的 `@Docs` 也吃这种格式：

```txt
https://anibt.net/llms.txt
```

它会自动展开索引、按需抓取每篇 `.md`。

### RAG / 自建 pipeline

```python title="拉取整站做向量化"
import requests, re

base = 'https://anibt.net'
index = requests.get(f'{base}/llms.txt').text

# llms.txt 里每行的 (link) 就是一篇文档；加上 .md 后缀就是源
urls = re.findall(r'\(([^)]+)\)', index)
for path in urls:
    if not path.startswith('/docs'):
        continue
    md = requests.get(f'{base}/zh-CN{path}.md').text
    # → 喂进你的 chunker / embedder
```

如果你只关心英文，把语言段换成 `/en` 即可（默认 zh-CN 不带前缀，英文是 `/en`，繁体是 `/zh-Hant`）。

## 端点对比

| 端点                    | 内容                            | 推荐用途                          |
| ----------------------- | ------------------------------- | --------------------------------- |
| `/llms.txt`             | 站点目录 + 链接（数 KB）         | 给 Agent 当 sitemap，按需抓取     |
| `/llms-full.txt`        | 全部 zh-CN 内容（约 80 KB）     | 一次性喂中文 LLM                   |
| `/llms-full.en.txt`     | 全部英文内容                    | 喂国际 LLM / 写英文回答           |
| `/<lang>/docs/<slug>.md`| 单页源 Markdown                | 精准引用某一篇                    |
| `Accept: text/markdown` | 任意公开 HTML 页的实时转换      | Agent 临时抓取站点公开页面         |

<Callout type="info">
  `llms.txt`、`llms-full.*` 与单页 `.md` 是**纯静态产物**，缓存 1 年（`Cache-Control: s-maxage=31536000`）。Wiki 更新发布后会重新构建，几分钟内端点跟着更新。`Accept: text/markdown` 实时转换则沿用原 HTML 页面的缓存策略。
</Callout>

## 内容覆盖

`/llms.txt` 与 `/llms-full.*` 的来源就是你正在看的这份 Wiki：

- 站点同步流程
- [公开 API](/docs/open-api)（RSS / JSON / 缓存 / 限流 / 故障排查）
- [Tracker 地址](/docs/tracker)
- [相关项目](/docs/projects)

任何一篇 Wiki 页面都可以加 `.md` 拿到源。例如：

```txt
原始页面     https://anibt.net/zh-CN/docs/open-api/rss-anime
Markdown 源  https://anibt.net/zh-CN/docs/open-api/rss-anime.md
```
