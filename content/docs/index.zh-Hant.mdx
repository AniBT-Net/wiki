AniBT 是面向動漫的公共 BitTorrent 追蹤器。

- **字幕組**：申請入駐 → 站點同步 → Tracker → 釋出。
- **使用者 / 開發者**：匿名用 RSS 和 JSON；個人訂閱或釋出需要帳號。
