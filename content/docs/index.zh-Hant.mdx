**AniBT** 是面向動漫的公共 BitTorrent 追蹤器，主要服務字幕組釋出與跟番消費。本 Wiki 覆蓋站內釋出、外站同步、公開 API、帳號與周邊工具；讀者按用途選路徑即可。

兩條主線：

- **字幕組**：申請入駐 → 設定站點同步 → 製種時使用官方 Tracker → 用 API 或網頁釋出。
- **使用者 / 開發者**：匿名使用 RSS 與 JSON；需要個人訂閱或釋出權限時再註冊帳號。
