---
title: 站點同步
description: 釋出後同步到萌番組、Mikan、動漫花園、末日站、ACG.rip、Nyaa。
---

在字幕組後台 `/groups/<slug>/sync` 按站點儲存憑據。每個站點單獨配置。使用前需 [申請入駐](/docs/apply)。

1. 啟用要同步的站點。
2. 填寫憑據。
3. 測試連線通過後再發正式資源。

| 站點 | 憑據 |
| --- | --- |
| [萌番組](/docs/site-sync/bangumi) | 已啟用帳號的使用者名稱或郵箱和密碼。舊 Cookie 已失效 |
| [Mikan](/docs/site-sync/mikan) | API Token |
| [動漫花園](/docs/site-sync/dmhy) | 帳號、密碼、字幕組名稱 |
| [末日站](/docs/site-sync/acgnx) | UID 與 API Token |
| [ACG.rip](/docs/site-sync/acgrip) | API Token，不要帶 `tpx://acg.rip/` 前綴 |
| [Nyaa](/docs/site-sync/nyaa) | 使用者名稱和密碼 |

開坑在 `/groups/<slug>/claims`，不在同步頁。

## 補發舊的番劇資源

<Callout type="warn">
字幕組擁有者、字幕組管理員和網站管理員可以補發。補發會再次提交至外站，可能產生重複內容；先查看既有結果。
</Callout>

<Steps>
<Step>
### 找到舊釋出
在 `/groups/<slug>/releases` 開啟「全部資源」，或先選擇作品進入資源清單。
</Step>
<Step>
### 查看同步狀態
點選資源行尾的「同步」。彈窗顯示 Mikan、ACG.rip、萌番組、末日站和動漫花園的目前設定、進度、失敗原因、外站連結與最近傳送紀錄。
</Step>
<Step>
### 提交補發
選擇單站「補發」，或「補發已啟用站點」，然後確認。補發沿用字幕組目前儲存的設定；未啟用、缺少憑據或正在傳送的站點不會重複提交。
</Step>
</Steps>

排隊中和同步中的工作會自動重新整理。一般成員可以查看進度。此操作保留本站原釋出，不會建立新的本站資源。

Nyaa 使用行尾獨立的「Nyaa 補發」入口，要求已開通平台代發並通過原始種子的 tracker 檢查，見 [Nyaa 代發](/docs/nyaa-proxy)。
