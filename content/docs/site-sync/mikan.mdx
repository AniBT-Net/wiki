通常只需 **API Token**。保存后点查询即可带出字幕组 ID 与发布组 ID。自动查询失败时用本页末尾的手动方法。

<Steps>
  <Step>
    ### 复制 API Token

    登录 [https://mikanani.me](https://mikanani.me)，右上角 **账号设置** → **个人中心** → **编辑资料**，在 **基本资料** 下复制 **API Token**。没有则点右侧 **生成**。粘贴到 AniBT 蜜柑计划同步设置后 **保存**。

    ![蜜柑计划 API Token 与 ID 查询](/images/site-sync/mikan-api-token.webp)
  </Step>
  <Step>
    ### 查询 ID

    点击 **【从蜜柑查询「XXXXXX」的 ID】**，取得 **字幕组 ID** 与 **发布组 ID**。
  </Step>
</Steps>

## 手动获取 ID（可选）

仅在自动查询无法识别时使用。

<Tabs items={['字幕组 ID', '发布组 ID']}>
  <Tab value="字幕组 ID">
    字幕组 ID 是发布组页面 URL 末尾的数字。

    ```txt title="字幕组页面 URL"
    https://mikanani.me/Home/PublishGroup/359
    ```

    其中 `359` 即字幕组 ID。在列表或作品简介中点击 **字幕组**，打开的就是字幕组页面。

    ![蜜柑计划字幕组 ID 页面](/images/site-sync/mikan-publish-group-id.webp)
  </Tab>
  <Tab value="发布组 ID">
    以 LoliHouse 为例：打开任意以 LoliHouse 身份发布的动画列表，点击字幕组名字右侧的 **RSS 图标**：

    ```txt title="RSS 链接"
    https://mikanani.me/RSS/Bangumi?bangumiId=3953&subgroupid=370
    ```

    `subgroupid=370` 中的 `370` 就是发布组 ID。

    ![蜜柑计划 RSS 中的发布组 ID](/images/site-sync/mikan-rss-subgroup-id.webp)
  </Tab>
</Tabs>
