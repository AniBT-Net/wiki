Usually only the **API Token** is required. After saving, query to fill the publish group ID and release group ID. If auto-query fails, use the manual steps at the bottom.

<Steps>
  <Step>
    ### Copy the API Token

    Sign in at [https://mikanani.me](https://mikanani.me). Top-right **Account Settings** → **Personal Center** → **Edit Profile**, then copy **API Token** under **Basic Profile**. If none is shown, select **Generate** on the right. Paste into AniBT Mikan sync settings and **Save**.

    ![Mikan API Token and ID query](/images/site-sync/mikan-api-token.webp)
  </Step>
  <Step>
    ### Query IDs

    Select **【Query the ID of "XXXXXX" from Mikan】** to get the **publish group ID** and **release group ID**.
  </Step>
</Steps>

## Manual ID lookup (optional)

Use only when auto-query cannot identify the IDs.

<Tabs items={['Publish Group ID', 'Release Group ID']}>
  <Tab value="Publish Group ID">
    The publish group ID is the trailing number in the publish group page URL.

    ```txt title="Publish group page URL"
    https://mikanani.me/Home/PublishGroup/359
    ```

    Here `359` is the publish group ID. Select **subtitle group** in a list or anime description — that page is the publish group page.

    ![Mikan publish group ID page](/images/site-sync/mikan-publish-group-id.webp)
  </Tab>
  <Tab value="Release Group ID">
    Using LoliHouse: open any anime list published as LoliHouse, then select the **RSS icon** next to the subtitle group name:

    ```txt title="RSS link"
    https://mikanani.me/RSS/Bangumi?bangumiId=3953&subgroupid=370
    ```

    In `subgroupid=370`, `370` is the release group ID.

    ![Release group ID in Mikan RSS](/images/site-sync/mikan-rss-subgroup-id.webp)
  </Tab>
</Tabs>
