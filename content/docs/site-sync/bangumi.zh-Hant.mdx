---
title: 萌番組同步
description: 用已啟用帳號的使用者名稱或電子郵件和密碼設定同步。
---

用萌番組使用者名稱或電子郵件和密碼登入後同步釋出。

<Callout type="warn">
  帳號必須先完成電子郵件啟用。舊 Cookie 已失效，只配過 Cookie 的字幕組需改填使用者名稱和密碼。
</Callout>

<Steps>
  <Step>
    ### 填寫帳密

    字幕組後台 `/groups/<slug>/sync` → **萌番組同步**。啟用後點選 **修改帳密**，填使用者名稱或電子郵件和密碼。
  </Step>
  <Step>
    ### 釋出身份並儲存

    以 Team 身份釋出時填釋出身份名稱或 Team ID。個人身份兩項都留空。點選 **儲存**。
  </Step>
</Steps>

<TypeTable
  type={{
    '使用者名稱或電子郵件': {
      description: '萌番組登入使用者名稱或電子郵件。',
      type: 'string',
    },
    '密碼': {
      description: '萌番組登入密碼。帳號必須已完成電子郵件啟用。',
      type: 'string',
    },
    '釋出身份名稱': {
      description: '萌番組 Team 名稱。使用個人身份釋出時留空。',
      type: 'string',

    },
    'Team ID': {
      description: '固定使用指定 Team 時填寫；優先於名稱匹配。',
      type: 'string',
      default: '可留空',
    },
  }}
/>

儲存後點選 **測試連線**：

| 結果 | 處理 |
| --- | --- |
| 連線成功 | 可以釋出 |
| 帳號未啟用 | 先在萌番組完成電子郵件啟用 |
| 登入失敗 | 檢查使用者名稱或電子郵件和密碼 |
| 登入過於頻繁 | 等一段時間再測，不要連續登入 |
