从仪表盘个人设定复制 **API Token**。

<Callout type="warn">
  不要带前缀 `tpx://acg.rip/`，只复制后面的字符串。
</Callout>

<Steps>
  <Step>
    ### 复制 Token

    访问 [https://acg.rip](https://acg.rip)，顶栏右上角 **人头图标** → **仪表盘**。右侧 **个人设定** 第二项是 **API Token**。粘贴到 AniBT 后保存。

    ![ACG.rip API Token](/images/site-sync/acgrip-api-token.webp)

    ```txt title="API Token 格式"
    7723-pxxxxxxxxxxxxxxp
    ```
  </Step>
</Steps>
