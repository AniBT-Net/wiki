配置 ACG.rip 同步后，AniBT 发布的动漫资源将在后台自动同步提交至 ACG.rip 分发站点。

<Callout type="warn">
  复制 Token 时，**切勿包含 `tpx://acg.rip/` 协议前缀**，仅需复制后面的实际字符串。
</Callout>

## 配置流程

<Steps>
  <Step>
    ### 访问 ACG.rip 仪表盘
    登录 [ACG.rip 官网 (acg.rip)](https://acg.rip)，点击顶栏右上角的 **用户头像图标** 进入 **仪表盘**。

    ![ACG.rip API Token](/images/site-sync/acgrip-api-token.webp)
  </Step>

  <Step>
    ### 复制 API Token
    在右侧 **个人设定** 区域的第二项找到 **API Token**。复制该字符串，确保格式类似 `7723-pxxxxxxxxxxxxxxp`，不含任何前缀或额外空格。

    ```txt title="标准 API Token 字符串格式"
    7723-pxxxxxxxxxxxxxxp
    ```
  </Step>

  <Step>
    ### 填入 AniBT 并测试
    访问 AniBT 字幕组控制台 `/groups/<slug>/sync`，在 ACG.rip 卡片中填入 Token，点击 **保存** 并执行 **测试连接**。
  </Step>
</Steps>
