---
title: 站点同步
description: 发布后同步到萌番组、Mikan、动漫花园、末日站、ACG.rip、Nyaa。
---

在字幕组后台 `/groups/<slug>/sync` 按站点保存凭据。每个站点单独配置。使用前需 [申请入驻](/docs/apply)。

1. 启用要同步的站点。
2. 填写凭据。
3. 测试连接通过后再发正式资源。

| 站点 | 凭据 |
| --- | --- |
| [萌番组](/docs/site-sync/bangumi) | 已激活账号的用户名或邮箱和密码。旧 Cookie 已失效 |
| [Mikan](/docs/site-sync/mikan) | API Token |
| [动漫花园](/docs/site-sync/dmhy) | 账号、密码、字幕组名称 |
| [末日站](/docs/site-sync/acgnx) | UID 与 API Token |
| [ACG.rip](/docs/site-sync/acgrip) | API Token，不要带 `tpx://acg.rip/` 前缀 |
| [Nyaa](/docs/site-sync/nyaa) | 用户名和密码 |

开坑在 `/groups/<slug>/claims`，不在同步页。

## 补发旧的番剧资源

<Callout type="warn">
字幕组所有者、字幕组管理员和站点管理员可以补发。补发会再次提交到外站，可能产生重复内容；先查看已有结果。
</Callout>

<Steps>
<Step>
### 找到旧发布
在 `/groups/<slug>/releases` 打开「全部资源」，或先选择作品进入资源列表。
</Step>
<Step>
### 查看同步状态
点击资源行尾的「同步」。弹窗显示 Mikan、ACG.rip、萌番组、末日站和动漫花园的当前配置、进度、失败原因、外站链接和最近发送记录。
</Step>
<Step>
### 提交补发
选择单站「补发」，或「补发已启用站点」，然后确认。补发继承字幕组当前保存的设置；未启用、缺少凭据或正在发送的站点不会重复提交。
</Step>
</Steps>

排队中和同步中的任务会自动刷新。普通成员可以查看进度。此操作保留本站原发布，不会创建新的本站资源。

Nyaa 使用行尾独立的「Nyaa 补发」入口，要求已开通平台代发并通过原始种子的 tracker 检查，见 [Nyaa 代发](/docs/nyaa-proxy)。
