---
title: 末日站同步
description: 填写 UID 与 API Token。
---

在末日站账户 API 设置页复制 **UID** 和 **API Token**。

<Callout type="warn">
  粘贴后检查前后是否有空格。
</Callout>

<Steps>
  <Step>
    ### 复制并保存

    访问 [https://share.acgnx.se](https://share.acgnx.se)，左上角 **發佈資源**，侧边栏 **帳戶控制中心** → **帳戶API設置**。把 **UID** 和 **API Token** 填到 AniBT 后保存。

    ![末日站账户 API 设置](/images/site-sync/acgnx-api-settings.webp)
  </Step>
</Steps>
