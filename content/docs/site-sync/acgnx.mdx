配置末日站（ACGNX / 末日动漫资源库）同步后，AniBT 发布的动漫资源将在后台自动同步提交至末日站。

<Callout type="warn">
  末日站使用独立的 API Token 认证。粘贴 UID 与 Token 时，请仔细核对并去除开头和末尾误复制的多余空格。
</Callout>

## 配置流程

<Steps>
  <Step>
    ### 打开末日站 API 设置页面
    访问 [末日站主页 (share.acgnx.se)](https://share.acgnx.se) 并登录，点击页面左上角 **發佈資源**。在左侧边栏找到 **帳戶控制中心** → **帳戶API設置**。

    ![末日站账户 API 设置](/images/site-sync/acgnx-api-settings.webp)
  </Step>

  <Step>
    ### 复制 UID 与 API Token
    在 API 设置页面中复制你的数字 **UID** 与 **API Token**。若此前未启用，按页面提示生成专属令牌。
  </Step>

  <Step>
    ### 填入 AniBT 并保存测试
    打开 AniBT 字幕组控制台 `/groups/<slug>/sync`，在末日站同步卡片中填入 **UID** 与 **API Token**，点击 **保存** 并进行 **测试连接**。
  </Step>
</Steps>
