---
title: 萌番组同步
description: 用已激活账号的用户名或邮箱和密码配置同步。
---

用萌番组用户名或邮箱和密码登录后同步发布。

<Callout type="warn">
  账号必须先完成邮箱激活。旧 Cookie 已失效，只配过 Cookie 的字幕组需改填用户名和密码。
</Callout>

<Steps>
  <Step>
    ### 填写账密

    字幕组后台 `/groups/<slug>/sync` → **萌番组同步**。启用后点击 **修改账密**，填用户名或邮箱和密码。
  </Step>
  <Step>
    ### 发布身份并保存

    以 Team 身份发布时填发布身份名称或 Team ID。个人身份两项都留空。点击 **保存**。
  </Step>
</Steps>

<TypeTable
  type={{
    '用户名或邮箱': {
      description: '萌番组登录用户名或邮箱。',
      type: 'string',
    },
    '密码': {
      description: '萌番组登录密码。账号必须已完成邮箱激活。',
      type: 'string',
    },
    '发布身份名称': {
      description: '萌番组 Team 名称。使用个人身份发布时留空。',
      type: 'string',
      default: '可留空',
    },
    'Team ID': {
      description: '固定使用指定 Team 时填写；优先于名称匹配。',
      type: 'string',
      default: '可留空',
    },
  }}
/>

保存后点击 **测试连接**：

| 结果 | 处理 |
| --- | --- |
| 连接成功 | 可以发布 |
| 账号未激活 | 先在萌番组完成邮箱激活 |
| 登录失败 | 检查用户名或邮箱和密码 |
| 登录过于频繁 | 等一段时间再测，不要连续登录 |
