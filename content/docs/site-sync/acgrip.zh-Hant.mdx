---

從儀表板個人設定複製 **API Token**。

<Callout type="warn">
  不要帶字首 `tpx://acg.rip/`，只複製後面的字串。
</Callout>

<Steps>
  <Step>
    ### 複製 Token

    造訪 [https://acg.rip](https://acg.rip)，頂欄右上角 **人頭圖示** → **儀表板**。右側 **個人設定** 第二項是 **API Token**。貼上到 AniBT 後儲存。

    ![ACG.rip API Token](/images/site-sync/acgrip-api-token.webp)

    ```txt title="API Token 格式"
    7723-pxxxxxxxxxxxxxxp
    ```
  </Step>
</Steps>
