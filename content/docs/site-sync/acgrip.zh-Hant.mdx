設定 ACG.rip 同步後，AniBT 釋出的動漫資源將在後台自動同步提交至 ACG.rip 分發站點。

<Callout type="warn">
  複製 Token 時，**切勿包含 `tpx://acg.rip/` 協議前綴**，僅需複製後面的實際字串。
</Callout>

## 設定流程

<Steps>
  <Step>
    ### 造訪 ACG.rip 儀表板
    登入 [ACG.rip 官網 (acg.rip)](https://acg.rip)，點選頂欄右上角的 **使用者頭像圖示** 進入 **儀表板**。

    ![ACG.rip API Token](/images/site-sync/acgrip-api-token.webp)
  </Step>

  <Step>
    ### 複製 API Token
    在右側 **個人設定** 區域的第二項找到 **API Token**。複製該字串，確保格式類似 `7723-pxxxxxxxxxxxxxxp`，不含任何前綴或額外空格。

    ```txt title="標準 API Token 字串格式"
    7723-pxxxxxxxxxxxxxxp
    ```
  </Step>

  <Step>
    ### 填入 AniBT 並測試
    造訪 AniBT 字幕組控制台 `/groups/<slug>/sync`，在 ACG.rip 卡片中填入 Token，點選 **儲存** 並執行 **測試連線**。
  </Step>
</Steps>
