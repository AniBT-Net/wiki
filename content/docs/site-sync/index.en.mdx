---
title: Site sync
description: After publishing, sync to Bangumi Moe, Mikan, DMHY, ACGNX, ACG.rip, and Nyaa.
---

In the group admin at `/groups/<slug>/sync`, save credentials per site. Each site is configured separately. [Apply for admission](/docs/apply) first.

1. Enable the sites to sync.
2. Enter credentials.
3. Publish real releases only after the connection test succeeds.

| Site | Credentials |
| --- | --- |
| [Bangumi Moe](/docs/site-sync/bangumi) | Username or email and password of an activated account. Old Cookies no longer work |
| [Mikan](/docs/site-sync/mikan) | API Token |
| [DMHY](/docs/site-sync/dmhy) | Account, password, subtitle group name |
| [ACGNX](/docs/site-sync/acgnx) | UID and API Token |
| [ACG.rip](/docs/site-sync/acgrip) | API Token, without the `tpx://acg.rip/` prefix |
| [Nyaa](/docs/site-sync/nyaa) | Username and password |

Claims are on `/groups/<slug>/claims`, not the sync page.
