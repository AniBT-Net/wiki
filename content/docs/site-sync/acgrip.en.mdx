---
title: ACG.rip Sync
description: Enter the API Token.
---

Copy the **API Token** from Personal Settings on the dashboard.

<Callout type="warn">
  Do not include the `tpx://acg.rip/` prefix — only the string after it.
</Callout>

<Steps>
  <Step>
    ### Copy the token

    Visit [https://acg.rip](https://acg.rip). Top-right **avatar** → **Dashboard**. In **Personal Settings** on the right, the second item is **API Token**. Paste it into AniBT and save.

    ![ACG.rip API Token](/images/site-sync/acgrip-api-token.webp)

    ```txt title="API Token format"
    7723-pxxxxxxxxxxxxxxp
    ```
  </Step>
</Steps>
