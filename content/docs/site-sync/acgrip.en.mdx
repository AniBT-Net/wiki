Configuring ACG.rip sync automatically submits your anime releases from AniBT to the ACG.rip distribution site in the background.

<Callout type="warn">
  When copying the token, **do not include the `tpx://acg.rip/` prefix**; copy only the trailing token string.
</Callout>

## Setup Workflow

<Steps>
  <Step>
    ### Open ACG.rip Dashboard
    Log in to [acg.rip](https://acg.rip) and click the **user profile icon** in the top-right navbar to enter the **Dashboard**.

    ![ACG.rip API Token](/images/site-sync/acgrip-api-token.webp)
  </Step>

  <Step>
    ### Copy API Token
    Under the **Personal Settings** section on the right side, find the second item: **API Token**. Copy the string, ensuring it matches the standard format without prefixes or surrounding spaces:

    ```txt title="Standard API Token Format"
    7723-pxxxxxxxxxxxxxxp
    ```
  </Step>

  <Step>
    ### Save and Test in AniBT
    Visit your fansub console at `/groups/<slug>/sync`, enter the token in the ACG.rip card, click **Save**, and execute **Test Connection**.
  </Step>
</Steps>
