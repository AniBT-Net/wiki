---
title: DMHY Sync
description: Enter username, password, and subtitle group name, then save and test.
---

Requires a DMHY username, password, and the subtitle group name used on DMHY.

<Steps>
  <Step>
    ### Edit credentials

    In sync settings, select **Edit credentials**.
  </Step>
  <Step>
    ### Fill in

    Enter the username, password, and the subtitle group name used on DMHY.
  </Step>
  <Step>
    ### Save and test

    Select **Save**, then **Test connection**.
  </Step>
</Steps>
