---
title: Bangumi Moe Sync
description: Configure sync with an activated account username or email and password.
---

Sign in with a Bangumi Moe username or email and password, then sync publishes.

<Callout type="warn">
  Activate the account by email first. Pasted browser Cookies no longer work; groups that only stored a Cookie must enter a username and password.
</Callout>

<Steps>
  <Step>
    ### Enter credentials

    Subtitle group dashboard `/groups/<slug>/sync` → **Bangumi Moe Sync**. Enable it, select **Change credentials**, and enter the username or email and password.
  </Step>
  <Step>
    ### Publishing identity and save

    To publish as a Team, enter the publishing identity name or Team ID. Leave both empty to publish as the account. Select **Save**.
  </Step>
</Steps>

<TypeTable
  type={{
    'Username or email': {
      description: 'Bangumi Moe sign-in username or email.',
      type: 'string',
    },
    'Password': {
      description: 'Bangumi Moe password. The account must already be activated by email.',
      type: 'string',
    },
    'Publishing Identity Name': {
      description: 'Bangumi Moe Team name. Leave empty to publish as the account.',
      type: 'string',
      default: 'optional',
    },
    'Team ID': {
      description: 'Pin a specific Team. Takes priority over name matching.',
      type: 'string',
      default: 'optional',
    },
  }}
/>

After saving, select **Test Connection**:

| Result | Action |
| --- | --- |
| Connection successful | Publishing is available |
| Account not activated | Activate the account by email on Bangumi Moe first |
| Login failed | Check the username or email and password |
| Login too frequent | Wait, then test again. Do not sign in repeatedly |
