Configuring ACGNX sync automatically submits your anime releases from AniBT to the ACGNX distribution platform.

<Callout type="warn">
  ACGNX utilizes independent API Token authentication. When copying your UID and Token, ensure no leading or trailing whitespace is accidentally included.
</Callout>

## Setup Workflow

<Steps>
  <Step>
    ### Open ACGNX API Settings
    Log in to [ACGNX (share.acgnx.se)](https://share.acgnx.se) and click **Publish Resources** in the upper left. In the left navigation, navigate to **User Control Center** → **Account API Settings**.

    ![ACGNX Account API Settings](/images/site-sync/acgnx-api-settings.webp)
  </Step>

  <Step>
    ### Copy UID & API Token
    Locate your numeric **UID** and the accompanying **API Token**. Generate a token if one is not already assigned.
  </Step>

  <Step>
    ### Save and Test in AniBT
    Open your fansub console at `/groups/<slug>/sync`, enter your **UID** and **API Token** in the ACGNX card, click **Save**, and run **Test Connection**.
  </Step>
</Steps>
