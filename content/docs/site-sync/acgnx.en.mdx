---
title: ACGNX Sync
description: Enter UID and API Token.
---

Copy **UID** and **API Token** from the ACGNX account API settings page.

<Callout type="warn">
  After pasting, check for extra spaces at either end.
</Callout>

<Steps>
  <Step>
    ### Copy and save

    Visit [https://share.acgnx.se](https://share.acgnx.se). Top-left **發佈資源**, then sidebar **帳戶控制中心** → **帳戶API設置**. Paste **UID** and **API Token** into AniBT and save.

    ![ACGNX account API settings](/images/site-sync/acgnx-api-settings.webp)
  </Step>
</Steps>
