設定末日站（ACGNX / 末日動漫資源庫）同步後，AniBT 釋出的動漫資源將在後台自動同步提交至末日站。

<Callout type="warn">
  末日站使用獨立的 API Token 認證。貼上 UID 與 Token 時，請仔細核對並去除開頭和末尾誤複製的多餘空格。
</Callout>

## 設定流程

<Steps>
  <Step>
    ### 開啟末日站 API 設定頁面
    造訪 [末日站首頁 (share.acgnx.se)](https://share.acgnx.se) 並登入，點選頁面左上角 **發佈資源**。在左側邊欄找到 **帳戶控制中心** → **帳戶API設置**。

    ![末日站帳戶 API 設定](/images/site-sync/acgnx-api-settings.webp)
  </Step>

  <Step>
    ### 複製 UID 與 API Token
    在 API 設定頁面中複製你的純數字 **UID** 與 **API Token**。若此前未啟用，按頁面提示產生專屬權杖。
  </Step>

  <Step>
    ### 填入 AniBT 並儲存測試
    開啟 AniBT 字幕組控制台 `/groups/<slug>/sync`，在末日站同步卡片中填入 **UID** 與 **API Token**，點選 **儲存** 並進行 **測試連線**。
  </Step>
</Steps>
