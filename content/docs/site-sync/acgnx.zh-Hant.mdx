---
title: 末日站同步
description: 填寫 UID 與 API Token。
---

在末日站帳戶 API 設定頁複製 **UID** 和 **API Token**。

<Callout type="warn">
  貼上後檢查前後是否有空格。
</Callout>

<Steps>
  <Step>
    ### 複製並儲存

    造訪 [https://share.acgnx.se](https://share.acgnx.se)，左上角 **發佈資源**，側邊欄 **帳戶控制中心** → **帳戶API設置**。把 **UID** 和 **API Token** 填到 AniBT 後儲存。

    ![末日站帳戶 API 設定](/images/site-sync/acgnx-api-settings.webp)
  </Step>
</Steps>
