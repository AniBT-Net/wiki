字幕組可以為每個番劇儲存三套標題模板：**簡體**、**繁體**和**簡繁**。釋出時，AniBT 會根據每條資源的字幕語言選擇對應槽位，也允許臨時指定其他模板或直接手工修改標題。

## 使用流程

1. 開啟 `/groups/<slug>/settings`，在「標題模板」中設定字幕組預設模板；需要自訂命名規則時，可在同一區域建立自訂模板並設為預設。
2. 開啟 `/groups/<slug>/anime_templates`，新增或編輯番劇模板。
3. 分別切換「簡體 / 繁體 / 簡繁」槽位，為每個槽位選擇內建模板、自訂模板或「繼承」。選擇器支援搜尋並立即顯示示例標題。
4. 進入 `/groups/<slug>/publish`。在第三步檢查每條資源的標題模式；需要統一調整時，先勾選資源，再使用批次標題模板操作。

## 三個語言槽位

| 資源語言 | 自動使用的番劇槽位 |
| --- | --- |
| 包含 `CHS`、不包含 `CHT` | 簡體 |
| 包含 `CHT`、不包含 `CHS` | 繁體 |
| 同時包含 `CHS` 與 `CHT` | 簡繁 |
| 不包含 `CHS` 或 `CHT` | 不使用番劇語言槽位，直接進入字幕組預設回退 |

槽位顯示「繼承」時，不會複製一份預設模板，而是在釋出時按目前字幕組設定動態解析。自動模式的完整順序是：

```text
對應番劇槽位
→ 字幕組預設自訂模板
→ 字幕組預設內建模板
→ 原始種子標題
```

因此可以只為有特殊命名需求的語言設定槽位，其餘語言繼續跟隨字幕組預設值。內建模板也包含「合集」，可用於批次集數或合集資源。

## 釋出第三步的標題模式

每條資源的標題按鈕會顯示目前模式和來源。開啟後可搜尋並從三組結果中選擇：

- **番劇自動**：根據資源語言使用番劇槽位，並按上面的回退順序生成標題。
- **字幕組自訂模板**：固定使用選中的自訂模板。
- **內建模板**：固定使用選中的內建模板。

直接編輯標題文字會切換到**手工標題**。手工標題不會因為之後修改番劇、集數、語言、解析度或封裝格式而被自動覆蓋。重新選擇「番劇自動」或某個模板後，標題才會恢復自動生成。

## 批次選擇

釋出第三步支援對已勾選資源批次套用標題模式。選擇器頂部的示例只用於展示一個代表資源；實際套用時，每條資源都會使用自己的番劇、語言、集數和媒體參數獨立生成標題，不會把同一個示例標題複製給所有資源。批次操作完成後可以立即復原。

<Callout type="info">
  建議把常規規則放在字幕組預設模板，只為確實需要區分簡體、繁體或簡繁命名的番劇設定專屬槽位。這樣後續調整預設規則時，仍處於「繼承」的番劇會自動跟隨。
</Callout>
