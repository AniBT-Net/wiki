## FontInAss — Subtitle Font Subsetting Tool

When bundling external or muxed ASS/SRT subtitles into torrent releases, including complete font files can bloat release size by tens of megabytes. **FontInAss** scans the exact glyphs used across your subtitle files and cuts the original bulky fonts down to an optimal minimal subset.

<GithubInfo owner="Yuri-NagaSaki" repo="FontInAss" />

- **Web Tool**: [font.anibt.net](https://font.anibt.net)

### Workflow Steps

<Steps>
  <Step>
    ### Load Subtitles and Original Fonts
    In the FontInAss web interface or CLI, load all ASS / SRT subtitle files for your current episode release, and upload the corresponding font files referenced in the styles.
  </Step>

  <Step>
    ### Extract and Generate Subsets
    The program scans every character, kanji, kana, and symbol used, strips tens of thousands of unused glyphs, and compiles a clean, tiny `.ttf` / `.otf` subset font package of only a few hundred kilobytes.
  </Step>

  <Step>
    ### Bundle into Torrent Release
    Place the generated subset fonts into a `Fonts/` directory within your release folder and package it into your torrent. Viewers will enjoy the exact intended typography without needing full fonts pre-installed.
  </Step>
</Steps>

## AniBT-Speed — RSS Automated Seeding Agent

To ensure long-term torrent availability and high-speed downloading for anime fans, the community created **AniBT-Speed**, a lightweight auto-downloader and seeder built on AniBT public RSS feeds.

<GithubInfo owner="Yuri-NagaSaki" repo="AniBT-Speed" />

- **Key Highlights**:
  - Monitors and subscribes to AniBT [Anime RSS Feeds](/en/docs/open-api/rss-anime) or [Site-wide Magnets](/en/docs/open-api/rss-magnets).
  - Honors standard HTTP conditional caching with 304 Not Modified, minimizing server overhead during polling.
  - Interfaces directly with Aria2, qBittorrent, or Transmission for fully automated retrieval and persistent seeding.

## Torrent Parser — Inspect and Edit Torrents in the Browser

**Torrent Parser** opens a `.torrent` file in the browser to inspect its info hash, file list, and tracker list, build a magnet link, and export the torrent again after editing fields.

- **Live tool**: [parser.anibt.net](https://parser.anibt.net/)
