---
title: Inspect your group
description: GET /api/subtitle-groups/me — authenticated lookup of the calling group, key identity, scopes, and stats.
---

`/api/subtitle-groups/me` is the **authenticated read** endpoint. With a group API key, it returns the group's basic info, the active key's safe identity and `scopes`, plus release, anime-coverage, and member statistics.

Use it for a CI identity banner, a dashboard widget, a group-binding sanity check, and a preflight that confirms `releases:publish` or `releases:delete` before a write.

## Request

```http title="HTTP"
GET https://anibt.net/api/subtitle-groups/me
Authorization: Bearer <YOUR_API_KEY>
```

```bash title="curl"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

## Response

```jsonc title="200 OK"
{
  "ok": true,
  "data": {
    "_id": "...",
    "name": "My Group",
    "slug": "my-group",
    "description": "...",
    "website": "https://...",
    "stats": {
      "totalReleases": 42,
      "totalAnimes": 10,
      "memberCount": 5
    },
    "status": "active",
    "createdAt": 1700000000000,
    "apiKeyId": "sgak_xxxxxxxx",
    "apiKeySuffix": "5c5d6fcd",
    "scopes": ["releases:publish", "releases:delete"]
  }
}
```

## Relationship to the public catalogue

<Callout type="info">
  Key differences from [`/api/subtitle-groups`](/docs/open-api/subtitle-groups):
  - `/api/subtitle-groups`: **public**, returns the trimmed list of **all** groups, no auth.
  - `/api/subtitle-groups/me`: **authenticated**, returns detailed info for the **caller's** group only — adds `stats`, key identity and `scopes`, plus internal `_id`, `description`, and `status`.
</Callout>

## Errors

| HTTP | Cause | Fix |
| ---- | ----- | --- |
| 401 | API key missing, malformed, invalid, or revoked | Use `Authorization: Bearer <KEY>` or `X-API-Key`; re-issue a revoked key |
| 429 | Too many requests | Back off according to `Retry-After` |
