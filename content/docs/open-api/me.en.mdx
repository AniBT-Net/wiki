---
title: Current group (me)
description: GET /api/subtitle-groups/me — inspect the current group, key identity, scopes, and stats with an API key.
---

`/api/subtitle-groups/me` is an **authenticated read** endpoint. With a subtitle-group API key, it returns the group profile, the current key’s safe identifiers and `scopes`, and stats such as release count, covered anime count, and member count.

Typical uses: confirm which key a CI job is using, show group status on a dashboard, and verify `releases:publish` / `releases:delete` before publish or delete.

## Preconditions

- The group has an API key.
- Send `Authorization: Bearer <KEY>` or `X-API-Key`.

## Request

```http title="HTTP"
GET https://anibt.net/api/subtitle-groups/me
Authorization: Bearer <YOUR_API_KEY>
```

```bash title="curl example"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

## Success response

```jsonc title="200 OK"
{
  "ok": true,
  "data": {
    "_id": "...",
    "name": "My Group",
    "slug": "my-group",
    "description": "...",
    "website": "https://...",

```

## Relation to the public catalogue

<Callout type="info">
  Compared with [`/api/subtitle-groups`](/docs/open-api/subtitle-groups):
  - `/api/subtitle-groups`: **public**, returns a **slim** list of **all** visible groups, no auth.
  - `/api/subtitle-groups/me`: **auth**, returns only the **caller’s** group in detail, with `stats`, key identity, `scopes`, and internal `_id` / `description` / `status`.
</Callout>

## Error responses

| HTTP | Cause | Action |
| ---- | ----- | ------ |
| 401 | Missing, malformed, invalid, or revoked API key | Use `Authorization: Bearer <KEY>` or `X-API-Key`; regenerate in the dashboard if revoked |
| 429 | Too many requests | Back off per `Retry-After` |
