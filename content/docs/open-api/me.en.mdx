---
title: Current group (me)
description: GET /api/subtitle-groups/me — inspect the current group, scopes, and stats with an API key.
---

Returns the group bound to this key, `scopes`, and stats. Check scope before publish or delete.

<ApiEndpoint method="GET" path="/api/subtitle-groups/me" auth="auth">
`Authorization: Bearer <KEY>`, or `X-API-Key`. Bearer wins.
</ApiEndpoint>

<Callout type="warn">
  Only `status=active` can publish. `apiKeySuffix` is not a credential.
</Callout>

Full fields: [API reference](/docs/open-api/reference).

```bash title="curl"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

| HTTP | What to do |
| --- | --- |
| 401 | Check Bearer / `X-API-Key`; rotate in the dashboard if revoked |
| 429 | Back off with `Retry-After` |
