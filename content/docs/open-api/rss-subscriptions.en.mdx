---
title: Personal subscription RSS
description: GET /rss/subscriptions.xml — saved “My subscriptions” rolled into one private feed.
---

Exports saved subscriptions as RSS. Use the full URL from the account dashboard.

<ApiEndpoint method="GET" path="/rss/subscriptions.xml" auth="auth">
`Cache-Control: private, no-store`. No public ETag.
</ApiEndpoint>

When subscription content changes, the server advances the subscription feed
version, making the old cache identity unreachable. Token cleanup is bounded
garbage collection, not the correctness mechanism.

<Callout type="warn">
  The URL carries credentials. Do not paste it into issues, screenshots, git, or chats. Reset it in the dashboard if leaked.
</Callout>

Poll interval ≥ 5 minutes. Faster polling returns 429. Item shape matches [`/rss/anime.xml`](/docs/open-api/rss-anime). Full notes: [API reference](/docs/open-api/reference).

```txt title="Request"
GET https://anibt.net/rss/subscriptions.xml
```

| HTTP | What to do |
| --- | --- |
| 400 | Copy the full URL from the dashboard again |
| 401 | Sign in again, or fetch a new URL |
| 403 | Credential revoked / user banned |
| 429 | Lengthen the interval |
