Production base URL: `https://anibt.net`. Paths and query parameters are the public contract: additive only, no incompatible changes. Internal primary keys (`organizationId`, `_id`) are not public; third parties use `slug`.

<Callout type="warn">
  Use only the main-site paths listed in these docs. Do not put publish/delete/`/me` API Keys in clients or repositories.
</Callout>

Methods, parameters, responses, and Try-it live on each endpoint page. Rate limits, caching, and 304 details are in [Limits](/docs/open-api/limits) and [Caching](/docs/open-api/caching).

Machine-readable spec: [openapi.yaml](/openapi.yaml).

## Auth

| Type | Usage |
| --- | --- |
| Public reads | No auth |
| Subtitle-group API Key | `Authorization: Bearer <KEY>`, or `X-API-Key`. Bearer wins |
| Key scopes | `releases:publish`, `releases:delete`, `releases:sync:read`; pick at least one |
| Personal subscription RSS | The full URL generated in account settings |

## Errors

Write endpoints use one JSON shape:

```json title="Error"
{
  "ok": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "…",
    "reason": "RATE_LIMITED",
    "retryable": true,
    "retryAfterMs": 2000,
    "requestId": "req-…"
  }
}
```

| HTTP | Meaning |
| --- | --- |
| 400 | Bad parameter or JSON |
| 401 | Auth failed |
| 403 | No permission or missing scope |
| 404 | Missing, or same as missing when unauthorized |
| 413 | Body too large |
| 422 | Validation failed |
| 429 | Back off using `Retry-After` |
| 503 | Temporarily unavailable or deploying; retry using `Retry-After` |

Public reads also return `429` when limited; Cloudflare edge limits may be HTML `429`.
