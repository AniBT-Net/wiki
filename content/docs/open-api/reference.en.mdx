---
title: API reference
description: Methods, paths, parameters, and responses for AniBT JSON and RSS endpoints.
---

Production base URL: `https://anibt.net`. Paths and query parameters are the public contract: additive only, no breaking changes. Internal IDs (`organizationId`, `_id`) are not public; use `slug`.

<Callout type="warn">
  Use only the main-site paths listed here. Do not put write/delete/`/me` API keys in clients or git.
</Callout>

Rate limits, caching, and 304 details: [Limits](/docs/open-api/limits), [Caching](/docs/open-api/caching).

## Auth

| Kind | How |
| --- | --- |
| Public reads | No auth |
| Group API key | `Authorization: Bearer <KEY>`, or `X-API-Key`. Bearer wins |
| Key scopes | `releases:publish`, `releases:delete`; at least one |
| Personal RSS | Subscription URL from the account dashboard |

## Errors

Write endpoints share one JSON envelope:

```json title="error"
{
  "ok": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "…",
    "reason": "RATE_LIMITED",
    "retryable": true,
    "retryAfterMs": 2000,
    "requestId": "req-…"
  }
}
```

| HTTP | Meaning |
| --- | --- |
| 400 | Bad parameters or JSON |
| 401 | Authentication failed |
| 403 | Forbidden or missing scope |
| 404 | Missing, or same as missing when unauthorized |
| 413 | Payload too large |
| 422 | Validation failed |
| 429 | Back off with `Retry-After` |
| 503 | Temporarily unavailable or deploy in progress; retry after `Retry-After` |

Public reads also return `429` when limited. Cloudflare edge limits may be HTML `429`.

### Groups for one anime

<ApiEndpoint method="GET" path="/api/anime/groups" auth="public">
Groups currently releasing a `bgmId`, plus the latest 30 items per group.
</ApiEndpoint>

<TypeTable
  type={{
    bgmId: { type: 'integer', required: true, description: 'Bangumi subject id' },
  }}
/>

The endpoint returns `200` only when the public Anime projection is complete and
live. An explicit `ANIME_NOT_FOUND` result is `404`; a missing or inconsistent
projection, more than 10,000 candidate releases, a representation over 2 MiB,
or a temporary read failure returns `503 SEARCH_UNAVAILABLE` with `Retry-After`
and `Cache-Control: no-store`. Successful JSON, `ETag`, `HEAD`, and `304`
behavior remain stable; browsers revalidate with `max-age=0` while the edge
caches according to the endpoint contract. `magnet` may be `null`. `subtitle`:
`EMBEDDED` / `EXTERNAL` / `BUILT_IN` / `NONE`.

### Match torrent title to anime

<ApiEndpoint method="POST" path="/api/animes/torrent-match" auth="public">
Parse the release title and torrent name; return auto / manual / …. `groupId` requires a login in that group. GET returns `405 METHOD_NOT_ALLOWED`.
</ApiEndpoint>

<TypeTable
  type={{
    rawTitle: { type: 'string', required: true, description: 'Raw release title, 1–1000 chars' },
    torrentName: { type: 'string', description: 'Torrent internal name, 1–1000 chars' },
    publishedAt: { type: 'integer', description: 'Publish time, milliseconds' },
    groupId: { type: 'string', description: 'Group id; requires a session if set' },
    limit: { type: 'integer', default: '10', description: 'Candidates, max 50' },
  }}
/>

Public route: `diagnostics=true` returns `403`. Body max 32 KiB. No store.

```json title="200"
{
  "version": 3,
  "decision": {
    "kind": "auto",
    "reason": "multi_branch_identity_unique",
    "animeId": "anime_example",
    "bgmId": 253046,
    "confidence": "high",
    "vetoes": []
  },
  "candidates": [],
  "search": { "candidateSetComplete": true, "generation": "match_v3_20260718_2040" },
  "diagnostics": null
}
```

| `decision.kind` | Meaning |
| --- | --- |
| `auto` | Use `decision.animeId`; it must appear in `candidates` |
| `manual` | Show candidates; do not auto-bind |
| `none` | No candidates |
| `non_anime` | Not anime |
| `unsupported` | Batch/multi-title cannot be one subject |
| `unavailable` | Search unavailable; retry later |

Publish runs the same matcher when no anime id is sent. Do not send a caller-forged match result to publish.

## RSS

Browsers get raw XML. Crawlers skip `/rss/`.

### Anime RSS

<ApiEndpoint method="GET" path="/rss/anime.xml" auth="public">
Main feed. Provide `bgmId` or `groupSlug` (or both). Mikan aliases: `bangumiId`, `subgroupid`.
</ApiEndpoint>

<TypeTable
  type={{
    bgmId: { type: 'integer', description: 'Bangumi subject id. Alias bangumiId' },
    groupSlug: { type: 'string', description: 'Group slug. Aliases subgroupSlug, subgroupid' },
    resolution: { type: 'enum[]', description: '4K / 2160p / 1080p / 720p / 480p / 360p' },
    language: { type: 'enum[]', description: 'CHS / CHT / JP / EN / KO / ES / PT / FR / DE / IT / RU / AR / HI / ID / MS / TH / VI / TL / TR / PL / UK' },
    format: { type: 'enum[]', description: 'MKV / MP4 / AVI / WEBM' },
    subtitle: { type: 'enum[]', description: 'EXTERNAL / INTERNAL / EMBEDDED / NONE' },
    episode: { type: 'integer', description: 'Numeric episode, exact match' },
    episodeKey: { type: 'string', description: 'Display key, e.g. 01, BATCH' },
    limit: { type: 'integer', default: '100', description: '1–100, one integer, no leading zeros' },
  }}
/>

Repeated tags or commas are equivalent: `?resolution=1080p&resolution=720p` and `?resolution=1080p,720p`. Illegal `limit` is application `400`; production edge may return `403` first. Default-equivalent values `308` to the canonical URL.

Each `<item>`: `<title>`, `<link>` (`/release/<id>`), `<guid>`, `<pubDate>` (RFC 822, `+0800`), magnet `<enclosure>`, `<torrent>` infoHash, and `<anibt:bgmId>` when bound.

### Group short RSS

<ApiEndpoint method="GET" path="/rss/group/<slug>.xml" auth="public">
Same as `/rss/anime.xml?groupSlug=<slug>`. No tag filters. Path must end with `.xml`. Unknown slug → `404`.
</ApiEndpoint>

`limit=1..100` is supported.

### Site-wide magnets RSS

<ApiEndpoint method="GET" path="/rss/magnets.xml" auth="public">
Latest site-wide releases. Anime items include `<anibt:bgmId>` when bound.
</ApiEndpoint>

<TypeTable
  type={{
    limit: { type: 'integer', default: '100', description: '1–100' },
    q: { type: 'string', description: 'Keyword. Alias search. Max 160 UTF-8 bytes' },
    resolution: { type: 'enum[]', description: 'Same as anime RSS' },
    language: { type: 'enum[]', description: 'Same as anime RSS' },
  }}
/>

Provide only one of `q` or `search`. Empty, control characters, or over-long values return `400`.

### Other-release RSS

<ApiEndpoint method="GET" path="/rss/other/<category>.xml" auth="public">
Not mixed into anime RSS. Categories: `manga` / `music` / `raw` / `stage` / `collection` / `movie` / `other`. Empty categories still return a valid empty channel.
</ApiEndpoint>

<TypeTable
  type={{
    limit: { type: 'integer', default: '100', description: '1–100' },
    q: { type: 'string', description: 'Keyword. Alias search' },
    groupId: { type: 'string', description: 'Group organization id' },
    sortField: { type: 'enum', default: 'publishedAt', description: 'publishedAt / fileSize' },
    sortOrder: { type: 'enum', default: 'desc', description: 'desc / asc' },
  }}
/>

No `<anibt:bgmId>`. Detail path: `/other-release/<id>`.

### Personal subscriptions RSS

<ApiEndpoint method="GET" path="/rss/subscriptions.xml" auth="auth">
Merged feed of saved subscriptions. Use the full dashboard URL. Response is `Cache-Control: private, no-store` with no public ETag.
</ApiEndpoint>

Missing token → 400, bad credentials → 401, revoked → 403.

### Delete an anime release

<ApiEndpoint method="DELETE" path="/api/releases/{releaseId}" auth="auth · releases:delete">
`rel_*` only. No query, empty body. Waits up to ~2s: 200 if done, else 202. Repeated DELETE is idempotent.
</ApiEndpoint>

`releaseId`: `^rel_[A-Za-z0-9_-]+$`, 5–100 chars. Regular members delete their own releases; owner / admin can delete any in the group. Unauthorized looks like 404.

```json title="202"
{
  "ok": true,
  "result": {
    "operationId": "rdel_example",
    "releaseId": "rel_example",
    "state": "pending",
    "statusUrl": "/api/releases/rel_example/deletion",
    "acceptedAt": 1784693156387,
    "updatedAt": 1784693156387,
    "retryAfterMs": 2000
  }
}
```

Headers: `Location`, `Retry-After`, `Cache-Control: private, no-store`.

### Deletion status

<ApiEndpoint method="GET" path="/api/releases/{releaseId}/deletion" auth="auth · releases:delete">
Same receipt. Unknown, never deleted, or unauthorized → 404.
</ApiEndpoint>

| `state` | Meaning |
| --- | --- |
| `pending` | Keep polling with `Retry-After` |
| `completed` | AniBT public surfaces are gone |
| `failed` | Stop auto-retry; log `failure.code` and `X-Request-ID` |

`202` means accepted. Only `completed` means the primary record, public read models, caches, and object storage passed the deletion barrier.
