公開識別端點。傳入 `groupId` 時必須登入且屬於該組。

<ApiEndpoint method="POST" path="/api/animes/torrent-match" auth="公開">
GET 回傳 `405 METHOD_NOT_ALLOWED`。
</ApiEndpoint>

<Callout type="warn">
  不要把呼叫方偽造的匹配結果傳給釋出介面。未帶番劇 ID 時，釋出介面會在伺服端跑同一 matcher。
</Callout>

## 請求

<TypeTable
  type={{
    rawTitle: { type: 'string', required: true, description: '釋出標題原文，1–1000 字元' },
    torrentName: { type: 'string', description: 'torrent 內部名，1–1000 字元。與 rawTitle 指向不同番劇時禁止自動綁定' },
    publishedAt: { type: 'integer', description: '釋出時間，毫秒' },
    groupId: { type: 'string', description: '字幕組 ID，最多 200 字元。傳入則需 session 且屬於該組，否則 403' },
    limit: { type: 'integer', default: '10', description: '候選數，上限 50。縮小 limit 不會放寬自動綁定門檻' },
  }}
/>

公開路由 `diagnostics=true` 回傳 `403`。請求體上限 32 KiB。不快取。

完整欄位見 [API 參考](/docs/open-api/reference)。

```bash title="釋出標題 + torrent 內部名"
curl -sS 'https://anibt.net/api/animes/torrent-match' \
  -H 'Content-Type: application/json' \
  --data @- <<'JSON'
{
  "rawTitle": "[LoliHouse] 孤独摇滚！ / Bocchi the Rock! - 01 [WebRip 1080p HEVC-10bit AAC][简繁内封字幕]",
  "torrentName": "[LoliHouse] Bocchi the Rock! [01][1080p].mkv",
  "publishedAt": 1664640000000,
  "limit": 10
}
JSON
```

## `decision.kind`

| `decision.kind` | 呼叫方行為 |
| --- | --- |
| `auto` | 可用 `decision.animeId`，且必須出現在 `candidates` |
| `manual` | 展示候選，不得自動綁定 |
| `none` | 無候選 |
| `non_anime` | 非番劇 |
| `unsupported` | 合集等無法用單番劇表達 |
| `unavailable` | 檢索不可用，稍後重試 |

`candidates` 不是授權欄位。高 `matchScore` 不能代替 `decision.kind="auto"`。

| HTTP | 處理 |
| --- | --- |
| 400 | 非法 JSON |
| 403 | `groupId` 無 session 或非成員；或公開路由傳了 `diagnostics=true` |
| 413 | 請求體超過 32 KiB |
| 422 | 校驗未通過 |
| 429 | 180 次 / 60 秒 / IP，按 `Retry-After` 退避 |
