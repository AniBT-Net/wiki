`/api/animes/torrent-match` 是公開、無需鑑權的番劇識別端點。釋出頁、字幕組腳本或匯入工具可先把種子標題解析成站內番劇候選，再決定自動綁定或交給人工確認。

<Callout type="info">
  生產實作只讀取 AniBT 已入庫的 Bangumi Data、bgm.tv source snapshot、站內番劇主資料和 `animeAliases`。執行時不會抓取外站，也不會呼叫 OpenCC 或音譯服務。
</Callout>

## 請求

```txt title="URL"
GET https://anibt.net/api/animes/torrent-match?query=<title>&seasonYear=<year>&limit=<n>
```

```bash title="多語標題"
curl -sS -G 'https://anibt.net/api/animes/torrent-match' \
  --data-urlencode 'query=本好きの下剋上 / Ascendance of a Bookworm S04' \
  --data 'limit=10'
```

## 匹配資料與安全邊界

- 站內主標題、Bangumi Data / bgm.tv 標題與可信站點線索可形成番劇級
  Season / Cour / Part / Sequence / Format 共識。
- 匯入的 `animeAliases`（包括 TVDB / TMDB 等外部來源）仍參與召回、精確碰撞檢測與
  全域消歧，但不會單獨生成番劇級修飾符共識，避免系列級別名讓舊季度、特別篇或
  新續作錯誤繼承同一季標記。
- canonical 標題中的成對 `～副標題～` 只透過有界、安全的結構化 stem 規則派生；
  例如可識別「無職轉生 3期」，但不會把普通電影或沒有季度證據的副標題無條件折疊成
  裸系列名。
- 多語標題列表會保留完整查詢，只按帶空格的 ` / `、` ／ ` 安全分段；
  `Fate/stay night` 這類內部斜線不會被拆分。長多語 exact 查詢會透過請求體傳送，
  不受 Typesense GET 查詢字串 4000 字元限制。

| `decisionReason` | 含義 |
| ---------------- | ---- |
| `exact_unique` | 唯一且可授權的精確匹配。 |
| `structured_unique` | Season / Cour / Part / Sequence / Format 與證據一致且全域唯一。 |
| `corroborated_weak_unique` | 兩個獨立來源族共同佐證唯一弱證據。 |
| `ambiguous_exact` | 多個番劇共享精確標題或去季度 base。 |
| `modifier_conflict` | 查詢與候選修飾符衝突。 |
| `variant_modifier_conflict` | 多語標題片段給出互相衝突的修飾符。 |
| `exact_overflow` | exact 結果超過安全上限。 |
| `low_evidence` | 有候選，但證據不足以授權自動綁定。 |
| `candidate_unavailable` | 唯一 alias 候選無法從公開 `animes` 索引 hydrate。 |
| `no_candidates` / `empty_query` | 沒有候選 / 查詢為空。 |

<Callout type="warn">
  Recall、Typesense 文字分數、`seasonYear` 和單一官網 slug 都不能單獨授權自動綁定。呼叫方必須以 `shouldAutoSelect` 為準；false 時顯示 `matches` 讓使用者確認。
</Callout>

## 快取、限流與錯誤

| 項目 | 值 |
| ---- | -- |
| `Cache-Control` | `public, max-age=0, s-maxage=60`；不啟用 SWR / stale-if-error |
| ETag | 支援 `If-None-Match`；未變更返回 `304 Not Modified` |
| 速率限制 | 預設 180 次 / 60 秒 / IP |
| `400` | 參數無效 |
| `429` | `RATE_LIMIT_EXCEEDED`，按 `Retry-After` / `retryAfterMs` 退避 |
| `503` | `SEARCH_UNAVAILABLE`；不回退到 Convex |

釋出腳本可先呼叫本端點；只有 `shouldAutoSelect=true` 時才把匹配到的 ID 傳給
[`/api/releases/publish`](/docs/open-api/releases-publish)。其他情況應保留人工確認。
