公開搜尋。拿到 `bgmId` 再去拼 RSS 或釋出。

<ApiEndpoint method="GET" path="/api/bgm/search" auth="公開">
站內未收錄的作品搜不到。
</ApiEndpoint>

<TypeTable
  type={{
    q: { type: 'string', required: true, description: '關鍵詞。中 / 英 / 日 / 羅馬音' },
    limit: { type: 'integer', default: '5', description: '條數，上限 25' },
  }}
/>

<Callout type="warn">
  不保證第一條就是目標作品。撞名時加大 `limit` 再挑。把 `bgmId` 快取到本地。
</Callout>

完整欄位見 [API 參考](/docs/open-api/reference)。

```bash title="curl"
curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=3'
```
