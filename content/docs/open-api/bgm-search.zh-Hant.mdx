`/api/bgm/search` 是**公開**搜尋端點，無需鑑權。用於把「使用者輸入的番劇名」對應為穩定的 Bangumi.tv subject id（`bgmId`），再交給 [`/rss/anime.xml`](/docs/open-api/rss-anime) 或 [`/api/releases/publish`](/docs/open-api/releases-publish)。

## 前置條件

- 無需鑑權。
- 查詢目標須為站內已索引番劇；未收錄作品需先完成站內番劇同步。

<Callout type="info">
  生產實作由主站 Web runtime 直接查詢 AniBT 的 Typesense 番劇索引，不再經 Convex HTTP action 透傳 Bangumi 上游。
</Callout>

## 請求

```txt title="URL"
GET https://anibt.net/api/bgm/search?q=<keyword>&limit=<n>
```

支援中文、英文、日文、羅馬音任意關鍵詞。

```bash title="curl 示例"
curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=3'
```

## 實戰：搜尋 → 拼 RSS

```bash title="一行打出 bgmId 給 RSS 用"
BGM=$(curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=1' \
  | jq -r '.data[0].bgmId')

echo "https://anibt.net/rss/anime.xml?bgmId=$BGM&resolution=1080p&language=CHS"
```

## 快取與限流

| 項目            | 值                                                                 |
| --------------- | ------------------------------------------------------------------ |
| `Cache-Control` | `public, max-age=0, s-maxage=300, stale-while-revalidate=300, stale-if-error=300` |
| ETag            | 支援 `If-None-Match`；未變化返回 `304 Not Modified`                 |
| 速率限制        | 60 次 / 60 秒 / IP，詳見 [限流與上限](/docs/open-api/limits)         |

## 注意事項

<Callout type="info">
  搜尋結果按文本相關度、熱度與更新時間排序，**不**保證第一條就是最熱門版本。番名易撞車時（多季 / 同名作品），宜增大 `limit` 後人工挑選。
</Callout>

<Callout type="warn">
  生產程式碼宜將解析出的 `bgmId` 快取到本機，避免每次釋出或拉 RSS 前都查詢。
</Callout>
