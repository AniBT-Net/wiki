在接入 AniBT 開放 API 或設定 RSS 自動化腳本時，如遇到異常回應或數據不符合預期，可參考本指南快速定位排查。

<Callout type="info">
  **快速定位秘訣**：所有非 2xx 的 API 回應均會附帶 `requestId` 欄位（回應標頭中亦有 `X-Request-ID`）。向平台管理員報告問題時，附帶該 ID 能在系統日誌中秒級定位原因。
</Callout>

## 常用排錯偵錯指令

在排查問題時，建議先使用 `curl` 隔離排查，排除客戶端軟體自身的設定干擾：

<Tabs items={['檢查 RSS 回應', '查詢字幕組 Slug', '核驗 API Key 身份']}>
  <Tab value="檢查 RSS 回應">
    直接檢視回傳的最新番劇標題與釋出時間戳記：

    ```bash title="快速抓取 RSS 內容摘要"
    curl -s 'https://anibt.net/rss/anime.xml?bgmId=543360&limit=3' \
      | grep -E '<title>|<pubDate>|<enclosure'
    ```
  </Tab>

  <Tab value="查詢字幕組 Slug">
    取得全站字幕組的標準 `slug` 標識列表：

    ```bash title="列出字幕組名稱與對應 slug"
    curl -s https://anibt.net/api/subtitle-groups \
      | jq '.data[] | {name, slug}'
    ```
  </Tab>

  <Tab value="核驗 API Key 身份">
    自檢目前 API Key 綁定的字幕組名稱、所屬 slug 與具備的權限 scopes：

    ```bash title="自檢 API Key 身份"
    curl -s https://anibt.net/api/subtitle-groups/me \
      -H "Authorization: Bearer <YOUR_API_KEY>" \
      | jq .
    ```
  </Tab>
</Tabs>
