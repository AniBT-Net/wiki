304 沒有正文，只能重用同一 URL 先前儲存的表示。首次請求或本機正文遺失時，不要只傳送舊 ETag。優先使用 If-None-Match；條件請求仍可能消耗限流額度。

釋出回傳 200 不代表外站同步、搜尋和 RSS 已完成更新。外站進度應查詢同步狀態介面；不要把單次觀測的延遲當作完成期限。
