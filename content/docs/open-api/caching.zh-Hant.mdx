---
title: HTTP 快取與 304
description: 公開讀取用 If-None-Match。未變回傳 304。輪詢間隔 ≥ 5 分鐘。
---

公開 RSS 與 JSON 支援條件請求。寫入、刪除、`/me`、個人訂閱不快取。

<Callout type="info">
  帶上次的 `ETag`。未變化回傳 `304`，無正文。優先 `If-None-Match`，不要依賴 `If-Modified-Since`。
</Callout>

輪詢間隔 ≥ 5 分鐘。更短沒有收益，且容易 429。

```bash title="If-None-Match"
H=$(curl -sI "https://anibt.net/rss/anime.xml?bgmId=543360")
ETAG=$(echo "$H" | grep -i '^etag:' | cut -d' ' -f2- | tr -d '\r')
curl -sI -H "If-None-Match: $ETAG" \
  "https://anibt.net/rss/anime.xml?bgmId=543360"
```

釋出介面的 `200` 不表示 RSS 立刻包含該條。用回傳的 `releaseId` 在詳情頁或 RSS 正文核對。
