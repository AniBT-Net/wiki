---
title: 個人訂閱 RSS
description: GET /rss/subscriptions.xml —— 前端「我的訂閱」合併成一份私人 RSS。
---

把已儲存的訂閱匯出為 RSS。使用帳戶後台產生的完整連結。

<ApiEndpoint method="GET" path="/rss/subscriptions.xml" auth="鑑權">
`Cache-Control: private, no-store`。無公開 ETag。
</ApiEndpoint>

<Callout type="warn">
  連結帶身分憑證。不要貼到 issue、截圖、倉庫或群。洩露後立刻到後台重設。
</Callout>

輪詢間隔 ≥ 5 分鐘。過快回傳 429。條目結構與 [`/rss/anime.xml`](/docs/open-api/rss-anime) 相同。完整說明見 [API 參考](/docs/open-api/reference)。

```txt title="請求"
GET https://anibt.net/rss/subscriptions.xml
```

| HTTP | 處理 |
| --- | --- |
| 400 | 從後台重新複製完整連結 |
| 401 | 重新登入，或重新取得連結 |
| 403 | 憑證已吊銷 / 使用者被封禁 |
| 429 | 拉長間隔 |
