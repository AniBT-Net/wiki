Manga, music, RAW, stage, collection, movie, other. Requires `releases:publish`. Not mixed into anime lists.

<ApiEndpoint method="POST" path="/api/other-releases/publish" auth="auth · releases:publish">
`category` and `title` required. Multipart requires `torrent`; JSON requires `torrentStorageId`. Magnets are optional extras. Magnet-only returns `422` / `TORRENT_REQUIRED`.
</ApiEndpoint>

<Callout type="warn">
  Do not put the key in clients, git, or issues. HTML in `notes` is rendered as-is.
</Callout>

Full fields: [API reference](/docs/open-api/reference). Nyaa category codes: [Publish a release](/docs/open-api/releases-publish#nyaa-proxy-fields-and-categories).

## Whoami

GET the same path. Does not write. `kind` is `other`.

```bash title="whoami"
curl -X GET 'https://anibt.net/api/other-releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>'
```

## Publish

```bash title="Upload torrent"
curl -X POST 'https://anibt.net/api/other-releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'category=manga' \
  -F 'title=Example Manga Vol.01' \
  -F 'customTags=电子版,中文' \
  -F 'torrent=@/path/to/release.torrent'
```

| Code | RSS |
| --- | --- |
| `manga` | `/rss/other/manga.xml` |
| `music` | `/rss/other/music.xml` |
| `raw` | `/rss/other/raw.xml` |
| `stage` | `/rss/other/stage.xml` |
| `collection` | `/rss/other/collection.xml` |
| `movie` | `/rss/other/movie.xml` |
| `other` | `/rss/other/other.xml` |

- `title` max 500 characters.
- `customTags` max 20, each max 80 characters. Alias `tags`.
- Multipart requires `torrent`. JSON requires `torrentStorageId`. Magnets are optional extras; magnet-only returns `422` / `TORRENT_REQUIRED`.
- Nyaa proxy rules match anime publish: allowlist, multipart, Nyaa tracker. Translated manga usually `3_2`, lossless music `2_1`, RAW / live capture `4_4`, anime RAW `1_4`.

Detail page: `https://anibt.net/other-release/<releaseId>`.

## Failures

| HTTP | What to do |
| --- | --- |
| 400 | Fill `category` / `title` / torrent or `torrentStorageId` |
| 401 | Check Bearer / `X-API-Key` |
| 403 | Use a key with `releases:publish` |
| 404 | `torrentStorageId` missing; upload via multipart |
| 422 | `TORRENT_REQUIRED` (multipart missing `torrent`, or JSON missing `torrentStorageId`) |
| 429 / 503 | Back off with `Retry-After` |
