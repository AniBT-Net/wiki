---

AniBT 對外提供 **RSS**（訂閱）和 **JSON**（程式讀取）。公開讀取可匿名，並依各端點快取契約支援 **HTTP 304**。釋出、刪除、`/me` 必須帶字幕組 API Key，回應不快取。

<Callout type="warn">
  生產 base URL 為 `https://anibt.net`。只使用文件列出的主站路徑。
</Callout>

請求、參數、回應見 [API 參考](/docs/open-api/reference)。

qBittorrent / Sonarr / FlexGet 等 RSS 客戶端無需額外設定。快取、限流、排查仍在對應頁。

## 穩定性

- 路徑與查詢參數不會做不相容變更；新參數只做擴充。
- `slug` 一旦釋出盡量保持穩定。
- 內部主鍵不屬於公開契約，一律使用 `slug`。
