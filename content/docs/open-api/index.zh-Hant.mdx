AniBT 提供公開查詢與訂閱介面，以及透過字幕組 API Key 呼叫的釋出、刪除和同步狀態介面。

<Callout type="info">
  https://anibt.net · [OpenAPI 3.1](/openapi.yaml)
</Callout>

<TypeTable type={{

  },

  "訂閱與下載": {
    "type": "RSS / .torrent",
    "description": "公開 RSS、個人 RSS、種子下載，以及 Sonarr / Radarr / Prowlarr 使用的 Torznab。"
  }
}} />

正式 Base URL 為 https://anibt.net。API Key、個人 RSS 權杖和登入工作階段適用於不同介面，不能互相取代。成功回應的包裝、空值與錯誤格式依各端點定義處理。

機器可讀定義見 [/openapi.yaml](/openapi.yaml)。介面頁展示請求欄位和回應示例；標題匹配可匿名呼叫，但傳入 groupId 時要求登入工作階段及該組成員身份。
