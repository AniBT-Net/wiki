AniBT 透過兩類公開端點對外暴露讀取資料：**RSS** 用於訂閱，**JSON API** 用於程式整合。公開讀取端點可匿名存取，並依各自快取契約支援 **HTTP 304 Not Modified**。釋出、刪除與身分檢查端點必須攜帶字幕組 API Key，回應不快取。

<Callout type="info">
  qBittorrent / Sonarr / FlexGet / Tiny Tiny RSS 等標準 RSS 客戶端無需額外設定；快取與條件請求由回應標頭自動生效。
</Callout>

<Callout type="warn">
  公開 API 的生產 base URL 為 `https://anibt.net`。第三方整合應只使用本文檔列出的主站路徑。
</Callout>

## 設計邏輯

整套介面按「職責分層」組織，便於按場景選擇端點：

```txt title="資料流"
┌────────────────────────────────────────────────────────────┐
│              第三方應用 (downloader / bot)                   │
└────────────────────────────────────────────────────────────┘
        │ ① 啟動時 / 每天 1 次：拉取字幕組目錄
        ▼
┌────────────────────────────────────────────────────────────┐
│  GET https://anibt.net/api/subtitle-groups                  │
│  返回 [{slug, name, totalReleases, totalAnimes, ...}]        │
│  → 把「展示名」或「使用者輸入」對應到穩定 slug                      │
└────────────────────────────────────────────────────────────┘
        │ ② 使用者訂閱時 / 每 N 分鐘：拉 RSS
        ▼
┌────────────────────────────────────────────────────────────┐
│  /rss/anime.xml?bgmId=...&groupSlug=...&resolution=...&...  │   主入口（最靈活）
│  /rss/group/<slug>.xml                                      │   字幕組短鏈
│  /rss/magnets.xml                                           │   全站新片
│  返回 RSS 2.0 + BEP 36（enclosure + <torrent infoHash>）    │
└────────────────────────────────────────────────────────────┘
        │ ③ 每一次輪詢都帶上上次的 ETag
        ▼
┌────────────────────────────────────────────────────────────┐
│  服務端用弱 ETag 快速比較：                                    │
│   - 資料未變：304 Not Modified（空 body，幾十字節）            │
│   - 資料變化：200 + 完整 RSS                                 │
└────────────────────────────────────────────────────────────┘
```

## 介面穩定性承諾

- 路徑與查詢參數視為公開契約，**不會做不相容變更**；新增參數只會擴展。
- `slug` 一旦釋出也儘量保持穩定。
- 內部主鍵（如 `organizationId`）不屬於公開契約，第三方一律使用 `slug`。
