AniBT 秉持開放的社群理念，將全站番劇資訊、釋出資源、字幕組目錄與最新磁力連結全面對外開放。

<Callout type="info">
  **生產 Base URL**：`https://anibt.net`。除特別說明外，所有數據均透過標準 HTTPS 提供服務。所有公開讀取介面均可匿名呼叫，無需申請 Token 或設定複雜憑證。
</Callout>

每個介面文件頁面均內嵌了基於 OpenAPI 契約產生的 **Try-it 互動測試面板**，你可以在瀏覽器中直接填寫參數並發起真實請求，快速驗證回應結構。

## 體系架構與核心能力

<Tabs items={['公開讀取 (免鑑權)', '字幕組自動化 (需 API Key)', '標準 RSS 體系']}>
  <Tab value="公開讀取 (免鑑權)">
    面向普通開發者、第三方動漫客戶端、機器人與數據分析腳本：

    - **番劇檢索與詳情**：透過動畫名稱、日文原名或 Bangumi ID 取得結構化條目數據
    - **字幕組目錄**：查詢全站活躍字幕組列表及其穩定英文 `slug`
    - **種子匹配**：呼叫標題解析引擎，自動分析動畫集數、解析度與字幕語言
    - **條件快取**：全面支援 HTTP 弱 ETag 與 304 協商，輪詢極大節省流量
  </Tab>

  <Tab value="字幕組自動化 (需 API Key)">
    面向入駐字幕組的 CI/CD 自動壓制釋出流程與管理腳本：

    - **資源釋出**：透過 `POST /api/releases/publish` 自動提交 `.torrent` 種子
    - **身份核驗**：透過 `GET /api/releases/publish` 執行 whoami 自檢
    - **外站同步追蹤**：即時查詢六大 BT 站的同步釋出結果與外站連結
    - **非同步刪除**：透過 `DELETE /api/releases/{id}` 撤回釋出並追蹤清理終態
  </Tab>

  <Tab value="標準 RSS 體系">
    面向 qBittorrent、Sonarr、FlexGet 等主流自動化下載器：

    - **單番劇訂閱**：按 Bangumi ID 聚合訂閱，支援疊加字幕組、畫質、字幕語言過濾
    - **字幕組訂閱**：按字幕組 `slug` 訂閱該組全部最新作品
    - **全站磁力**：全站最新入庫資源的即時磁力推送來源
    - **標準協議**：完整支援 RFC 規範與 BitTorrent BEP 36 擴充標籤
  </Tab>
</Tabs>

## 介面穩定性與規範承諾

1. **向下相容保證**：已公開的端點路徑與參數不會進行不相容修改，新功能僅透過追加參數實現。
2. **識別碼規範**：第三方在呼叫與持久化時請務必使用 **`slug`**（如 `kirara-fantasia`）或 **`bgmId`**，避免依賴易變的內部主鍵。
3. **機器可讀契約**：標準 OpenAPI 3.1 規範檔案可在 [/openapi.yaml](/openapi.yaml) 直接取得。
