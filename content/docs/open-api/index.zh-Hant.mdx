正式 Base URL 為 https://anibt.net。API Key、個人 RSS 權杖和登入工作階段適用於不同介面，不能互相取代。成功回應的包裝、空值與錯誤格式依各端點定義處理。

機器可讀定義見 [/openapi.yaml](/openapi.yaml)。介面頁展示請求欄位和回應示例；標題匹配可匿名呼叫，但傳入 groupId 時要求登入工作階段及該組成員身份。

## 番劇查詢與評分

`/api/seasons/anime` 的 `scope.kind` 區分季度瀏覽、關鍵字搜尋與精確 ID 查詢。全庫關鍵字搜尋的 `requestedSeason` 為 `null`，每部作品使用自己的季度；首播日期與季度分類分開。`premiere.precision` 為 `day`、`month`、`season` 或 `year`，粗精度日期使用週期首日。

季度瀏覽最多回傳 200 筆，關鍵字搜尋最多 50 筆。`total` 是本次回傳數量，`truncated=true` 表示還有結果；完整分頁使用 `/api/animes/search`。`rating` 使用 0–10 分，缺有效來源評分時回傳 `5.0`；`averageScore` 使用 0–100 分，對應預設 `50`。現有 ani-rss 可直接排序，但舊版本不讀取截斷提示，仍最多顯示 50 筆搜尋結果。
