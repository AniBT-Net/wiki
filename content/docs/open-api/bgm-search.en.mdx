---
title: Bangumi search
description: GET /api/bgm/search — map a title to bgmId.
---

Public search. Use the `bgmId` to build RSS URLs or publish.

<ApiEndpoint method="GET" path="/api/bgm/search" auth="public">
Unindexed titles are not found.
</ApiEndpoint>

<TypeTable
  type={{
    q: { type: 'string', required: true, description: 'Keyword. Chinese / English / Japanese / romaji' },
    limit: { type: 'integer', default: '5', description: 'Count, max 25' },
  }}
/>

<Callout type="warn">
  The first hit is not guaranteed to be the target. Raise `limit` and pick. Cache `bgmId` locally.
</Callout>

Full fields: [API reference](/docs/open-api/reference).

```bash title="curl"
curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=3'
```
