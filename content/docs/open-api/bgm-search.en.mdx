---
title: Bangumi search
description: GET /api/bgm/search — public Bangumi subject lookup by Chinese, English, Japanese, or romanized keywords.
---

`/api/bgm/search` is a **public** search endpoint (no auth). It maps a free-text anime title to a stable Bangumi.tv subject id (`bgmId`) for [`/rss/anime.xml`](/docs/open-api/rss-anime) or [`/api/releases/publish`](/docs/open-api/releases-publish).

## Preconditions

- No authentication.
- Results cover anime already indexed on AniBT; titles missing from the site need local anime sync first.

<Callout type="info">
  Production queries AniBT’s Typesense anime index directly from the Web runtime; it no longer proxies Bangumi upstream through a Convex HTTP action.
</Callout>

## Request

```txt title="URL"
GET https://anibt.net/api/bgm/search?q=<keyword>&limit=<n>
```

Chinese, English, Japanese, and romanized keywords are all accepted.

```bash title="curl example"
curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=3'
```

## Practice: search → build RSS

```bash title="One-liner bgmId → RSS URL"
BGM=$(curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=1' \
  | jq -r '.data[0].bgmId')

echo "https://anibt.net/rss/anime.xml?bgmId=$BGM&resolution=1080p&language=CHS"
```

## Caching & rate limits

| Item | Value |
| ---- | ----- |
| `Cache-Control` | `public, max-age=0, s-maxage=300, stale-while-revalidate=300, stale-if-error=300` |
| ETag | `If-None-Match` supported; unchanged bodies return `304 Not Modified` |
| Rate limit | 60 req / 60 s / IP; see [Rate limits & caps](/docs/open-api/limits) |

## Notes

<Callout type="info">
  Results are ranked by text relevance, popularity, and recency — the first hit is **not** guaranteed to be the “main” season. For ambiguous titles (multi-season / same name), raise `limit` and pick manually.
</Callout>

<Callout type="warn">
  Production code should cache resolved `bgmId` values locally instead of searching before every publish or RSS pull.
</Callout>
