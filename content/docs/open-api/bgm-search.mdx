title: Bangumi 搜索
description: GET /api/bgm/search —— 把番剧名映射为 bgmId。
---

公开搜索。拿到 `bgmId` 再去拼 RSS 或发布。

<ApiEndpoint method="GET" path="/api/bgm/search" auth="公开">
站内未收录的作品搜不到。
</ApiEndpoint>

<TypeTable
  type={{
    q: { type: 'string', required: true, description: '关键词。中 / 英 / 日 / 罗马音' },
    limit: { type: 'integer', default: '5', description: '条数，上限 25' },
  }}
/>

<Callout type="warn">
  不保证第一条就是目标作品。撞名时加大 `limit` 再挑。把 `bgmId` 缓存到本地。
</Callout>

完整字段见 [接口参考](/docs/open-api/reference)。

```bash title="curl"
curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=3'
```
