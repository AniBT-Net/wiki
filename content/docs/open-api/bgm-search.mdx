`/api/bgm/search` 是**公开**搜索端点，无需鉴权。用于把「用户输入的番剧名」映射为稳定的 Bangumi.tv subject id（`bgmId`），再交给 [`/rss/anime.xml`](/docs/open-api/rss-anime) 或 [`/api/releases/publish`](/docs/open-api/releases-publish)。

## 前置条件

- 无需鉴权。
- 查询目标须为站内已索引番剧；未收录作品需先完成站内番剧同步。

<Callout type="info">
  生产实现由主站 Web runtime 直接查询 AniBT 的 Typesense 番剧索引，不再经 Convex HTTP action 透传 Bangumi 上游。
</Callout>

## 请求

```txt title="URL"
GET https://anibt.net/api/bgm/search?q=<keyword>&limit=<n>
```

支持中文、英文、日文、罗马音任意关键词。

```bash title="curl 示例"
curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=3'
```

## 实战：搜索 → 拼 RSS

```bash title="一行打出 bgmId 给 RSS 用"
BGM=$(curl -s -G 'https://anibt.net/api/bgm/search' \
  --data-urlencode 'q=葬送的芙莉莲' -d 'limit=1' \
  | jq -r '.data[0].bgmId')

echo "https://anibt.net/rss/anime.xml?bgmId=$BGM&resolution=1080p&language=CHS"
```

## 缓存与限流

| 项目            | 值                                                                 |
| --------------- | ------------------------------------------------------------------ |
| `Cache-Control` | `public, max-age=0, s-maxage=300, stale-while-revalidate=300, stale-if-error=300` |
| ETag            | 支持 `If-None-Match`；未变化返回 `304 Not Modified`                 |
| 速率限制        | 60 次 / 60 秒 / IP，详见 [限流与上限](/docs/open-api/limits)         |

## 注意事项

<Callout type="info">
  搜索结果按文本相关度、热度与更新时间排序，**不**保证第一条就是最热门版本。番名易撞车时（多季 / 同名作品），宜增大 `limit` 后人工挑选。
</Callout>

<Callout type="warn">
  生产代码宜将解析出的 `bgmId` 缓存到本地，避免每次发布或拉 RSS 前都查询。
</Callout>
