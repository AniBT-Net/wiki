生產 base URL：`https://anibt.net`。路徑與查詢參數是公開契約，只做擴充、不做不相容變更。內部主鍵（`organizationId`、`_id`）不屬於公開契約，第三方用 `slug`。

<Callout type="warn">
  只使用文件列出的主站路徑。寫入、刪除、`/me` 的 API Key 不要放進用戶端或倉庫。
</Callout>

各端點的方法、參數、回應和 Try-it 見側欄對應頁。限流、快取、304 細節見 [限流](/docs/open-api/limits)、[快取](/docs/open-api/caching)。

機器可讀契約：[openapi.yaml](/openapi.yaml)。

## 鑑權

| 類型 | 用法 |
| --- | --- |
| 公開讀取 | 無需鑑權 |
| 字幕組 API Key | `Authorization: Bearer <KEY>`，或 `X-API-Key`。Bearer 優先 |
| Key scope | `releases:publish`、`releases:delete`、`releases:sync:read`，至少選一個 |
| 個人訂閱 RSS | 帳戶後台產生的訂閱連結 |

## 錯誤

寫入介面統一 JSON：

```json title="錯誤"
{
  "ok": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "…",
    "reason": "RATE_LIMITED",
    "retryable": true,
    "retryAfterMs": 2000,
    "requestId": "req-…"
  }
}
```

| HTTP | 含義 |
| --- | --- |
| 400 | 參數或 JSON 有誤 |
| 401 | 認證未通過 |
| 403 | 無權限或缺少 scope |
| 404 | 資源不存在，或無權存取時與不存在相同 |
| 413 | 請求體過大 |
| 422 | 校驗未通過 |
| 429 | 按 `Retry-After` 退避 |
| 503 | 服務暫時不可用或部署中，按 `Retry-After` 重試 |

公開讀取超限同樣回傳 `429`；Cloudflare 邊緣限流可能是 HTML `429`。
