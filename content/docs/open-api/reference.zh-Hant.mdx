本文件規定了呼叫 AniBT 開放 API 的全域約定、身份鑑權方式以及標準的錯誤處理格式。

<Callout type="warn">
  **生產 Base URL**：`https://anibt.net`。請始終使用文件和 OpenAPI 規範中列出的路徑。字幕組 API Key 擁有寫入操作與刪除權限，請妥善保管，切勿硬編碼提交至公開倉庫或客戶端代碼中。
</Callout>

## 統一錯誤回應結構

所有寫入操作與非 2xx 的 JSON 回應均遵循統一的錯誤結構，便於程式解析與重試判定：

```json title="標準 JSON 錯誤格式"
{
  "ok": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Torrent file is missing in multipart request",
    "reason": "TORRENT_REQUIRED",
    "retryable": false,
    "requestId": "req_01j7abc123456789"
  }
}
```

- **`code`**：粗粒度錯誤類別（如 `BAD_REQUEST`、`UNAUTHORIZED`、`FORBIDDEN`、`VALIDATION_ERROR`、`RATE_LIMITED`）。
- **`reason`**：機器可讀的精確錯誤原因（如 `EMPTY_RELEASE_CONTENT`、`TORRENT_REQUIRED`）。
- **`retryable`**：布林值，指示目前錯誤是否可透過延時重試恢復（例如限流為 `true`，參數錯誤為 `false`）。
- **`requestId`**：目前請求的全域唯一追蹤標識，同時會透過回應標頭 `X-Request-ID` 回傳。在向管理員回饋問題時請務必附帶此 ID。
