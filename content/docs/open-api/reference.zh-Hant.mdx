生產 base URL：`https://anibt.net`。路徑與查詢參數是公開契約，只做擴充、不做不相容變更。內部主鍵（`organizationId`、`_id`）不屬於公開契約，第三方用 `slug`。

<Callout type="warn">
  只使用本文列出的主站路徑。寫入、刪除、`/me` 的 API Key 不要放進客戶端或倉庫。
</Callout>

限流、快取、304 細節見 [限流](/docs/open-api/limits)、[快取](/docs/open-api/caching)。

## 鑑權

| 類型 | 用法 |
| --- | --- |
| 公開讀取 | 無需鑑權 |
| 字幕組 API Key | `Authorization: Bearer <KEY>`，或 `X-API-Key`。Bearer 優先 |
| Key scope | `releases:publish`、`releases:delete`，至少選一個 |
| 個人訂閱 RSS | 帳戶後台產生的訂閱連結 |

## 錯誤

寫入介面統一 JSON：

```json title="錯誤"
{
  "ok": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "…",
    "reason": "RATE_LIMITED",
    "retryable": true,
    "retryAfterMs": 2000,
    "requestId": "req-…"
  }
}
```

| HTTP | 含義 |
| --- | --- |
| 400 | 參數或 JSON 有誤 |
| 401 | 認證未通過 |
| 403 | 無權限或缺少 scope |
| 404 | 資源不存在，或無權存取時與不存在相同 |
| 413 | 請求體過大 |
| 422 | 校驗未通過 |
| 429 | 按 `Retry-After` 退避 |
| 503 | 服務暫時不可用或部署中，按 `Retry-After` 重試 |

公開讀取超限同樣返回 `429`；Cloudflare 邊緣限流可能是 HTML `429`。

### 單番劇字幕組

<ApiEndpoint method="GET" path="/api/anime/groups" auth="公開">
某 `bgmId` 正在釋出的字幕組，以及每組最近 30 條資源。
</ApiEndpoint>

<TypeTable
  type={{
    bgmId: { type: 'integer', required: true, description: 'Bangumi subject id' },
  }}
/>

只有公共讀模型中的 Anime 投影完整且為 live 時才回傳 `200`。明確的
`ANIME_NOT_FOUND` 結果回傳 `404`；公共投影缺失或不一致、候選資源超過
10,000 條、表示超過 2 MiB，或讀取暫時不可用時回傳 `503 SEARCH_UNAVAILABLE`，
並帶 `Retry-After` 與 `Cache-Control: no-store`。成功回應的 JSON、`ETag`、
`HEAD` 和 `304` 保持穩定；瀏覽器使用 `max-age=0`，邊緣按介面契約快取。
`magnet` 可能為 `null`。`subtitle`：`EMBEDDED` / `EXTERNAL` / `BUILT_IN` / `NONE`。

### 種子標題匹配番劇

<ApiEndpoint method="POST" path="/api/animes/torrent-match" auth="公開">
解析釋出標題與種子內部名稱，返回 auto / manual 等決定。傳入 `groupId` 時必須登入且屬於該組。GET 返回 `405 METHOD_NOT_ALLOWED`。
</ApiEndpoint>

<TypeTable
  type={{
    rawTitle: { type: 'string', required: true, description: '釋出標題原文，1–1000 字元' },
    torrentName: { type: 'string', description: 'torrent 內部名稱，1–1000 字元' },
    publishedAt: { type: 'integer', description: '釋出時間，毫秒' },
    groupId: { type: 'string', description: '字幕組 ID。傳入則需 session' },
    limit: { type: 'integer', default: '10', description: '候選數，上限 50' },
  }}
/>

公開路由 `diagnostics=true` 返回 `403`。請求體上限 32 KiB。不快取。

```json title="200"
{
  "version": 3,
  "decision": {
    "kind": "auto",
    "reason": "multi_branch_identity_unique",
    "animeId": "anime_example",
    "bgmId": 253046,
    "confidence": "high",
    "vetoes": []
  },
  "candidates": [],
  "search": { "candidateSetComplete": true, "generation": "match_v3_20260718_2040" },
  "diagnostics": null
}
```

| `decision.kind` | 含義 |
| --- | --- |
| `auto` | 可用 `decision.animeId`，且必須出現在 `candidates` |
| `manual` | 展示候選，不得自動綁定 |
| `none` | 無候選 |
| `non_anime` | 非番劇 |
| `unsupported` | 合集等無法用單番劇表達 |
| `unavailable` | 檢索不可用，稍後重試 |

釋出介面未帶番劇 ID 時會在服務端跑同一 matcher。不要把呼叫方偽造的匹配結果傳給釋出介面。

## RSS

瀏覽器直開返回原生 XML。搜尋引擎不抓 `/rss/`。

### 番劇 RSS

<ApiEndpoint method="GET" path="/rss/anime.xml" auth="公開">
主入口。`bgmId` 與 `groupSlug` 至少提供一個。相容 Mikan 的 `bangumiId`、`subgroupid`。
</ApiEndpoint>

<TypeTable
  type={{
    bgmId: { type: 'integer', description: 'Bangumi subject id。別名 bangumiId' },
    groupSlug: { type: 'string', description: '字幕組 slug。別名 subgroupSlug、subgroupid' },
    resolution: { type: 'enum[]', description: '4K / 2160p / 1080p / 720p / 480p / 360p' },
    language: { type: 'enum[]', description: 'CHS / CHT / JP / EN / KO / ES / PT / FR / DE / IT / RU / AR / HI / ID / MS / TH / VI / TL / TR / PL / UK' },
    format: { type: 'enum[]', description: 'MKV / MP4 / AVI / WEBM' },
    subtitle: { type: 'enum[]', description: 'EXTERNAL / INTERNAL / EMBEDDED / NONE' },
    episode: { type: 'integer', description: '數字集數，精確匹配' },
    episodeKey: { type: 'string', description: '顯示集數鍵，如 01、BATCH' },
    limit: { type: 'integer', default: '100', description: '1–100，單個無前導零整數' },
  }}
/>

Tag 可重複或逗號分隔：`?resolution=1080p&resolution=720p` 與 `?resolution=1080p,720p` 等價。非法 `limit` 返回應用 `400`，生產邊緣可能先 `403`。與預設值等價的寫法會 `308` 到規範 URL。

每個 `<item>`：`<title>`、`<link>`（`/release/<id>`）、`<guid>`、`<pubDate>`（RFC 822，`+0800`）、`<enclosure>` 磁力、`<torrent>` infoHash、已綁定時 `<anibt:bgmId>`。

### 字幕組短鏈 RSS

<ApiEndpoint method="GET" path="/rss/group/<slug>.xml" auth="公開">
等價 `/rss/anime.xml?groupSlug=<slug>`。不支援 Tag 過濾。路徑必須以 `.xml` 結尾。未知 slug 返回 `404`。
</ApiEndpoint>

支援 `limit=1..100`。

### 全站磁力 RSS

<ApiEndpoint method="GET" path="/rss/magnets.xml" auth="公開">
全站最近釋出。anime 條目帶 `<anibt:bgmId>`（已綁定才有）。
</ApiEndpoint>

<TypeTable
  type={{
    limit: { type: 'integer', default: '100', description: '1–100' },
    q: { type: 'string', description: '關鍵詞。別名 search。UTF-8 最多 160 bytes' },
    resolution: { type: 'enum[]', description: '同番劇 RSS' },
    language: { type: 'enum[]', description: '同番劇 RSS' },
  }}
/>

`q` 與 `search` 只能提供一個值。空、控制字元或超長返回 `400`。

### 其他類 RSS

<ApiEndpoint method="GET" path="/rss/other/<category>.xml" auth="公開">
不混入番劇 RSS。分類：`manga` / `music` / `raw` / `stage` / `collection` / `movie` / `other`。空分類仍返回有效空 channel。
</ApiEndpoint>

<TypeTable
  type={{
    limit: { type: 'integer', default: '100', description: '1–100' },
    q: { type: 'string', description: '關鍵詞。別名 search' },
    groupId: { type: 'string', description: '字幕組組織 ID' },
    sortField: { type: 'enum', default: 'publishedAt', description: 'publishedAt / fileSize' },
    sortOrder: { type: 'enum', default: 'desc', description: 'desc / asc' },
  }}
/>

無 `<anibt:bgmId>`。詳情頁路徑：`/other-release/<id>`。

### 個人訂閱 RSS

<ApiEndpoint method="GET" path="/rss/subscriptions.xml" auth="鑑權">
前端已儲存訂閱的合併 feed。使用後台產生的完整連結。回應 `Cache-Control: private, no-store`，無公開 ETag。
</ApiEndpoint>

缺少 token 返回 400，憑證無效 401，已吊銷 403。

### 刪除番劇釋出

<ApiEndpoint method="DELETE" path="/api/releases/{releaseId}" auth="鑑權 · releases:delete">
只支援 `rel_*`。無 query、無請求體。最多等待約 2 秒：完成返回 200，否則 202。重複 DELETE 冪等。
</ApiEndpoint>

`releaseId`：`^rel_[A-Za-z0-9_-]+$`，5–100 字元。普通成員只能刪自己的釋出；owner / admin 可刪本組任意釋出。無權與不存在一樣返回 404。

```json title="202"
{
  "ok": true,
  "result": {
    "operationId": "rdel_example",
    "releaseId": "rel_example",
    "state": "pending",
    "statusUrl": "/api/releases/rel_example/deletion",
    "acceptedAt": 1784693156387,
    "updatedAt": 1784693156387,
    "retryAfterMs": 2000
  }
}
```

回應標頭：`Location`、`Retry-After`、`Cache-Control: private, no-store`。

### 刪除狀態

<ApiEndpoint method="GET" path="/api/releases/{releaseId}/deletion" auth="鑑權 · releases:delete">
查詢同一刪除回執。未知、從未刪除或無權一律 404。
</ApiEndpoint>

| `state` | 含義 |
| --- | --- |
| `pending` | 按 `Retry-After` 繼續輪詢 |
| `completed` | 站內公開面已不可見 |
| `failed` | 停止自動重試，記錄 `failure.code` 與 `X-Request-ID` |

`202` 只表示已受理。只有 `completed` 才表示主記錄、公開讀模型、快取和物件儲存已通過刪除屏障。
