## 字幕组短链

<ApiEndpoint method="GET" path="/rss/group/<slug>.xml" auth="公开">
等价 `/rss/anime.xml?groupSlug=<slug>`。不支持 Tag 过滤。
</ApiEndpoint>

路径必须以 `.xml` 结尾。未知 slug 返回 `404`。支持 `limit=1..100`。非法 `limit` 返回应用 `400`，生产边缘可能先 `403`。

```txt title="示例"
https://anibt.net/rss/group/kirara-fantasia.xml
```

## 全站磁力

<ApiEndpoint method="GET" path="/rss/magnets.xml" auth="公开">
全站最近发布。已绑定的 anime 条目带 `<anibt:bgmId>`。
</ApiEndpoint>

```txt title="示例"
https://anibt.net/rss/magnets.xml
https://anibt.net/rss/magnets.xml?q=葬送的芙莉莲
https://anibt.net/rss/magnets.xml?resolution=1080p&language=CHS
```

`q` 与 `search` 只能提供一个值。空、控制字符或超长返回 `400`。

## 季度番剧

<ApiEndpoint method="GET" path="/api/seasons/anime" auth="公开">
当季已上架番剧。`bgmId` 优先于 `season`，且不能与 `query` 同时使用。
</ApiEndpoint>

```txt title="示例"
https://anibt.net/api/seasons/anime
https://anibt.net/api/seasons/anime?season=2026春
https://anibt.net/api/seasons/anime?bgmId=543360
https://anibt.net/api/seasons/anime?query=夏日口袋
```

`weekday`：0=周日 … 6=周六，按 Asia/Shanghai；`null` 为未排播。`rating` 为 0–100。

## 单番剧字幕组

<ApiEndpoint method="GET" path="/api/anime/groups" auth="公开">
某 `bgmId` 正在发布的字幕组，以及每组最近 30 条资源。
</ApiEndpoint>

```txt title="示例"
https://anibt.net/api/anime/groups?bgmId=543360
```

只有公共读模型中的 Anime 投影完整且为 live 时才返回 `200`。明确的
`ANIME_NOT_FOUND` 结果仍为 `404`；公共投影缺失或不一致、候选资源超过
10,000 条、表示超过 2 MiB，或读取暂时不可用时返回 `503 SEARCH_UNAVAILABLE`，
并带 `Retry-After` 与 `Cache-Control: no-store`，不会伪装成 404 或 200 空结果。
成功响应支持 `ETag`、`HEAD` 与 `304`；浏览器 `max-age=0`，边缘可按接口合同缓存。
`magnet` 可能为 `null`。`slug` 可直接用于 `/rss/anime.xml?groupSlug=…`。
