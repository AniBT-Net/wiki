漫畫、音樂、RAW、舞台劇、合集、劇場版、其他。要求 `releases:publish`。不混入番劇列表。

<ApiEndpoint method="POST" path="/api/other-releases/publish" auth="鑑權 · releases:publish">
`category` 與 `title` 必填；`torrent` / `torrentStorageId` / `magnetLink` / `magnetBase64` 至少一個。
</ApiEndpoint>

<Callout type="warn">
  Key 不要寫進客戶端、倉庫或 issue。`notes` 中的 HTML 會直接渲染。
</Callout>

完整欄位見 [API 參考](/docs/open-api/reference)。Nyaa 分類代碼見 [釋出資源](/docs/open-api/releases-publish#nyaa-代發欄位和分類)。

## 身分自檢

GET 同一路徑，不寫庫。`kind` 為 `other`。

```bash title="whoami"
curl -X GET 'https://anibt.net/api/other-releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>'
```

## 釋出

```bash title="上傳種子"
curl -X POST 'https://anibt.net/api/other-releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'category=manga' \
  -F 'title=Example Manga Vol.01' \
  -F 'customTags=電子版,中文' \
  -F 'torrent=@/path/to/release.torrent'
```

| 代碼 | RSS |
| --- | --- |
| `manga` | `/rss/other/manga.xml` |
| `music` | `/rss/other/music.xml` |
| `raw` | `/rss/other/raw.xml` |
| `stage` | `/rss/other/stage.xml` |
| `collection` | `/rss/other/collection.xml` |
| `movie` | `/rss/other/movie.xml` |
| `other` | `/rss/other/other.xml` |

- `title` 最長 500 字元。
- `customTags` 最多 20 個，每個最長 80 字元。別名 `tags`。
- 無 torrent 時正式釋出必須 `fileSize > 0`，否則 `422` / `EMPTY_RELEASE_CONTENT`。
- Nyaa 代發規則與番劇釋出相同：白名單、multipart、Nyaa tracker。漫畫翻譯常用 `3_2`，無損音樂 `2_1`，RAW / 實拍 `4_4`，動畫 RAW `1_4`。

`releaseId` 詳情頁：`https://anibt.net/other-release/<releaseId>`。

## 失敗

| HTTP | 處理 |
| --- | --- |
| 400 | 補齊 `category` / `title` / 種子或磁力 |
| 401 | 檢查 Bearer / `X-API-Key` |
| 403 | 改用含 `releases:publish` 的 Key |
| 404 | `torrentStorageId` 不存在；改用 multipart 上傳 |
| 429 / 503 | 按 `Retry-After` 退避 |
