## Group short link

<ApiEndpoint method="GET" path="/rss/group/<slug>.xml" auth="public">
Same as `/rss/anime.xml?groupSlug=<slug>`. No tag filters.
</ApiEndpoint>

The canonical URL for a catalogued group slug without `limit` uses a fixed RSS
publication version. Successful responses are shared by the CDN for 300 seconds
with `must-revalidate`, and publication exact invalidation clears the old object
first. Clients still use `max-age=0`, and an unchanged `ETag` may return `304`.
URLs with `limit` remain dynamic RSS.

Path must end with `.xml`. Unknown slug returns `404`. `limit=1..100`. Invalid `limit` returns app `400`; production edge may return `403` first.

```txt title="Example"
https://anibt.net/rss/group/kirara-fantasia.xml
```

## Site-wide magnets

<ApiEndpoint method="GET" path="/rss/magnets.xml" auth="public">
Latest site-wide releases. Bound anime items include `<anibt:bgmId>`.
</ApiEndpoint>

`/rss/magnets.xml` with no query is a fixed RSS feed. Successful responses are
shared by the CDN for 300 seconds with `must-revalidate`, and publication exact
invalidation clears the old object first. Clients still use `max-age=0`, and an
unchanged `ETag` may return `304`. `q`, `search`, filters, and `limit` variants
keep the existing dynamic owner.

```txt title="Examples"
https://anibt.net/rss/magnets.xml
https://anibt.net/rss/magnets.xml?q=葬送的芙莉莲
https://anibt.net/rss/magnets.xml?resolution=1080p&language=CHS
```

`q` and `search` may supply only one value. Empty, control characters, or overlong input returns `400`.

## Seasonal anime

<ApiEndpoint method="GET" path="/api/seasons/anime" auth="public">
Anime listed for the current season. `bgmId` wins over `season`, and cannot be combined with `query`.
</ApiEndpoint>

```txt title="Examples"
https://anibt.net/api/seasons/anime
https://anibt.net/api/seasons/anime?season=2026春
https://anibt.net/api/seasons/anime?bgmId=543360
https://anibt.net/api/seasons/anime?query=夏日口袋
```

`weekday`: 0=Sunday … 6=Saturday, Asia/Shanghai; `null` means unscheduled. `rating` is 0–100.

## Groups for one anime

<ApiEndpoint method="GET" path="/api/anime/groups" auth="public">
Groups currently publishing a `bgmId`, plus the latest 30 items per group.
</ApiEndpoint>

```txt title="Example"
https://anibt.net/api/anime/groups?bgmId=543360
```

The endpoint returns `200` only when the public Anime projection is complete and
live. An explicit `ANIME_NOT_FOUND` result remains `404`; a missing or
inconsistent public projection, more than 10,000 candidate releases, a
representation over 2 MiB, or a temporary read failure returns `503
SEARCH_UNAVAILABLE` with `Retry-After` and `Cache-Control: no-store` rather than
pretending to be a 404 or an empty 200. Successful responses support `ETag`,
`HEAD`, and `304`; browsers revalidate (`max-age=0`) while the edge may cache
according to the endpoint contract. `magnet` may be `null`. `slug` can go
straight into `/rss/anime.xml?groupSlug=…`.
