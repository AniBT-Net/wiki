---
title: 其他類 RSS
description: GET /rss/other/<category>.xml —— 七個分類各自一份 RSS，不混入番劇 RSS。
---

漫畫、音樂、RAW、舞台劇、合集、劇場版、其他。訂閱這些資源必須用本頁路徑。

<ApiEndpoint method="GET" path="/rss/other/<category>.xml" auth="公開">
分類：`manga` / `music` / `raw` / `stage` / `collection` / `movie` / `other`。
</ApiEndpoint>

<Callout type="info">
  空分類仍回傳有效空 channel，不回傳 404。無 `<anibt:bgmId>`。
</Callout>

完整參數見 [API 參考](/docs/open-api/reference)。

```txt title="示例"
https://anibt.net/rss/other/manga.xml
https://anibt.net/rss/other/music.xml?q=FLAC&limit=50
```

`q` 與 `search` 只能提供一個值。空、控制字元或超長回傳 `400`。
