Store the complete response body with its ETag, then send If-None-Match on subsequent requests.

A 304 has no body: reuse the previously stored representation of the same URL. Do not send an old ETag if the local body is missing. Prefer If-None-Match. Conditional requests may still consume rate limits.

A 200 publish response does not prove that external syncing, search, or RSS visibility has completed. Use the sync-status endpoint for external progress. An observed delay is not a completion guarantee.
