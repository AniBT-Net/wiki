---
title: HTTP caching & 304
description: Public reads use If-None-Match. Unchanged bodies return 304. Poll interval ≥ 5 minutes.
---

Public RSS and JSON support conditional requests. Writes, deletes, `/me`, and personal subscriptions are not cached.

<Callout type="info">
  Send the last `ETag`. Unchanged → `304` with no body. Prefer `If-None-Match`. Do not rely on `If-Modified-Since`.
</Callout>

Poll interval ≥ 5 minutes. Faster polling has no benefit and often hits 429.

```bash title="If-None-Match"
H=$(curl -sI "https://anibt.net/rss/anime.xml?bgmId=543360")
ETAG=$(echo "$H" | grep -i '^etag:' | cut -d' ' -f2- | tr -d '\r')
curl -sI -H "If-None-Match: $ETAG" \
  "https://anibt.net/rss/anime.xml?bgmId=543360"
```

Publish `200` does not mean the item is already in RSS. Check the returned `releaseId` on the detail page or in the RSS body.
