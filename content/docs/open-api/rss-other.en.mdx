title: Other release RSS
description: GET /rss/other/<category>.xml — one feed per category; not mixed into anime RSS.
---

Manga, music, RAW, stage, collection, movie, other. Subscribe to these with this path.

<ApiEndpoint method="GET" path="/rss/other/<category>.xml" auth="public">
Categories: `manga` / `music` / `raw` / `stage` / `collection` / `movie` / `other`.
</ApiEndpoint>

<Callout type="info">
  An empty category still returns a valid empty channel, not 404. No `<anibt:bgmId>`.
</Callout>

A category URL without `limit`, `q`, `search`, or another filter is a fixed RSS
feed. Successful responses use a shared CDN cache for 300 seconds with
`must-revalidate`; publication exact invalidation clears the old object first,
while the TTL is the bounded fallback when invalidation is delayed. Clients
still use `max-age=0`, and an unchanged `ETag` may return `304`; unready and
error responses are not shared. URLs with `limit` or search keep their bounded
refresh policy. RSS `<ttl>` is only a client polling hint.

Full parameters: [API reference](/docs/open-api/reference).

```txt title="Examples"
https://anibt.net/rss/other/manga.xml
https://anibt.net/rss/other/music.xml?q=FLAC&limit=50
```

`q` and `search` may supply only one value. Empty, control characters, or overlong input returns `400`.
