title: Other-category RSS
description: GET /rss/other/<category>.xml — independent feeds for all seven other-release categories; never mixed into anime RSS.
---

`/rss/other/<category>.xml` serves independent feeds for other releases. Supported categories: `manga`, `music`, `raw`, `stage`, `collection`, `movie`, and `other`.

## Preconditions

- No authentication.
- Other-category items are **not** mixed into `/rss/magnets.xml`, `/rss/anime.xml`, or anime detail RSS; subscribe via these category paths.

## URL

```txt title="Category RSS"
https://anibt.net/rss/other/manga.xml
https://anibt.net/rss/other/music.xml
https://anibt.net/rss/other/raw.xml
https://anibt.net/rss/other/stage.xml
https://anibt.net/rss/other/collection.xml
https://anibt.net/rss/other/movie.xml
https://anibt.net/rss/other/other.xml
```

When a category has no releases, its canonical URL still returns `200 application/xml` with a valid empty RSS channel rather than `404`.

## Caching & indexing

- Responses compute an exact-body `W/"anibt-sha256-{...}"` ETag from final XML UTF-8 bytes and omit request-time `lastBuildDate`. Matching-ETag `304` means current feed bytes are unchanged. `Last-Modified` is currently omitted.
- latest/filter variants without `q` use `s-maxage=120`; searches with `q` (including empty results) use `s-maxage=600`; both use `stale-while-revalidate=60`.
- Category publishes invalidate the latest Redis family first, then purge non-full-text CDN variants for that category (including `groupId`-only filters). Search Redis/CDN identities with `q` / `search` stay on a 600-second TTL and are not purged by unrelated category publishes — this is not a real-time search SLA.
- Search cache identity stores only the SHA-256 of the normalized query. Duplicate/empty/control-character `q`, both `q` and `search`, or >160 bytes return `400 + no-store`. Reordering original query pairs returns the same canonical `200`; default/alias/byte-level normalization still returns a one-day-cacheable `308`.
- Only true CDN/Redis search MISSes consume distinct-query and global concurrency budgets; over-budget returns `429 + Retry-After`. Stable queries and cache HITs do not.
- Responses include `noindex, follow` so category feeds are not indexed by search engines.
