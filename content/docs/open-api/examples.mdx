AniBT 的公开 RSS 与开放 API 专为自动化集成而设计。无论是将订阅源添加至下载工具实现全自动追番，还是编写自动化脚本与 CI/CD 流水线对接，均可直接参考以下经过验证的代码示例。

<Callout type="info">
  **订阅技巧**：公开 RSS 源默认输出最新的 100 条记录（已是单次最大上限），直接使用基础链接即可，无需额外添加 `limit=100` 参数。
</Callout>

## 自动化下载器接入指引

<Tabs items={['qBittorrent', 'Sonarr', 'FlexGet']}>
  <Tab value="qBittorrent">
    1. 打开 qBittorrent，在左侧导航栏切换至 **RSS** 选项卡。
    2. 点击 **新增订阅**，将生成的 AniBT RSS 链接粘贴进去并保存。
    3. 点击右上角的 **RSS 下载器（规则）**，新建一条自动下载规则并勾选刚才添加的订阅源。
    4. 建议将客户端的默认轮询间隔设置为 **15 ~ 30 分钟**。
  </Tab>

  <Tab value="Sonarr">
    1. 进入 Sonarr 设置页，点击 **Settings** → **Indexers** → **Add**。
    2. 选择 **Torznab** 或通用 **RSS Sync** 类型。
    3. 在 URL 栏中填入 AniBT 对应番剧的 RSS 地址，配置自动抓取过滤规则即可。
  </Tab>

  <Tab value="FlexGet">
    在 `config.yml` 中直接将 AniBT RSS 作为输入源：

    ```yaml title="config.yml"
    tasks:
      anime_task:
        rss: https://anibt.net/rss/anime.xml?bgmId=543360&language=CHS
        all_series: yes
        download: ~/Downloads/Torrents/
    ```
  </Tab>
</Tabs>

## 实战脚本示例

### 1. 具备 304 缓存的 Bash 条件轮询脚本

通过保存并发送 `ETag`，当服务端无新资源时直接返回空响应体 `304`，避免重复下载 XML：

```bash title="conditional_rss_poll.sh"
#!/usr/bin/env bash
set -euo pipefail

FEED_URL="https://anibt.net/rss/anime.xml?bgmId=543360"
ETAG_FILE="/tmp/anibt_anime_543360.etag"

# 读取历史 ETag
ETAG=""
if [ -f "$ETAG_FILE" ]; then
  ETAG=$(cat "$ETAG_FILE")
fi

echo "正在检查新资源更新..."
if [ -n "$ETAG" ]; then
  RESPONSE=$(curl -sI -H "If-None-Match: $ETAG" "$FEED_URL")
else
  RESPONSE=$(curl -sI "$FEED_URL")
fi

HTTP_STATUS=$(echo "$RESPONSE" | grep -i '^http/' | awk '{print $2}')

if [ "$HTTP_STATUS" = "304" ]; then
  echo ">>> 内容未发生变化 (304 Not Modified)，无需重复下载。"
elif [ "$HTTP_STATUS" = "200" ]; then
  echo ">>> 发现新资源！拉取完整数据并保存最新 ETag..."
  NEW_ETAG=$(echo "$RESPONSE" | grep -i '^etag:' | cut -d' ' -f2- | tr -d '\r')
  echo "$NEW_ETAG" > "$ETAG_FILE"
  # 这里可以进一步执行下载或推送通知
fi
```

### 2. 异步撤回删除与轮询终态脚本

删除发布为异步操作，脚本先发起 `DELETE` 请求，随后轮询查询接口直至收到 `completed` 终态：

```bash title="delete_and_wait.sh"
#!/usr/bin/env bash
set -euo pipefail

RELEASE_ID="rel_01j7example123"
API_KEY="YOUR_SUBTITLE_GROUP_API_KEY"
BASE_URL="https://anibt.net"

echo "发起异步删除请求: $RELEASE_ID"
DELETE_RES=$(curl -sS -X DELETE \
  -H "Authorization: Bearer $API_KEY" \
  "$BASE_URL/api/releases/$RELEASE_ID")

STATE=$(echo "$DELETE_RES" | jq -r '.result.state // .error.details.state // "pending"')

# 轮询状态接口
while [ "$STATE" = "pending" ]; do
  echo "删除任务正在队列中处理，2 秒后重试..."
  sleep 2
  STATUS_RES=$(curl -sS \
    -H "Authorization: Bearer $API_KEY" \
    "$BASE_URL/api/releases/$RELEASE_ID/deletion")
  STATE=$(echo "$STATUS_RES" | jq -r '.result.state // "pending"')
done

if [ "$STATE" = "completed" ]; then
  echo ">>> 资源已彻底删除并通过安全屏障！"
else
  echo ">>> 删除未能完成，当前状态: $STATE"
fi
```
