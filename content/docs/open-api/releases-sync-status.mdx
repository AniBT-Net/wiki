          查询该 API Key 所属字幕组的普通 release 在六个外站的同步状态。

          请求只支持 `rel_...` 形式的 `releaseId`，且资源必须属于当前 Key 所属字幕组。

          不存在、已删除或跨组资源统一返回 `404 NOT_FOUND`。

          成功响应固定返回 `mikan`、`acgrip`、`bangumi`、`acgnx`、`dmhy`、`nyaa`
          六个平台；每站提供当前状态、外站 ID/链接、错误、generation、attempt、时间戳和最近 50 条历史。

          状态包括
          `not_started`、`pending`、`success`、`failed`、`ambiguous`、`deleted`；响应另含
          `overall` 汇总和 `historyTruncated`。

          接口不会返回外站原始响应正文或凭据，响应使用 `Cache-Control: no-store`。

          需要 `releases:sync:read`。
