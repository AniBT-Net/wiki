`/api/subtitle-groups/me` 是**鑑權讀取**端點。攜帶字幕組 API Key 後，返回該組的基本資訊、目前 Key 的安全標識與 `scopes`，以及釋出數、覆蓋番劇數、成員數等統計。

典型用途：CI 啟動時確認目前 Key、控制台展示字幕組狀態、腳本在釋出或刪除前校驗是否具備 `releases:publish` / `releases:delete`。

## 前置條件

- 字幕組已開通 API Key。
- 請求標頭攜帶 `Authorization: Bearer <KEY>` 或 `X-API-Key`。

## 請求

```http title="HTTP"
GET https://anibt.net/api/subtitle-groups/me
Authorization: Bearer <YOUR_API_KEY>
```

```bash title="curl 示例"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

## 與公共目錄的關係

<Callout type="info">
  與 [`/api/subtitle-groups`](/docs/open-api/subtitle-groups) 的核心差別：
  - `/api/subtitle-groups`：**公開**，返回**所有**可見字幕組的精簡資訊，無需鑑權。
  - `/api/subtitle-groups/me`：**鑑權**，只返回**呼叫方**這一組的詳細資訊，附帶 `stats`、Key 標識、`scopes`，以及內部 `_id`、`description`、`status`。
</Callout>

## 失敗回應

| HTTP | 原因 | 處理 |
| ---- | ---- | ---- |
| 401 | API Key 缺失、格式錯誤、無效或已撤銷 | 使用 `Authorization: Bearer <KEY>` 或 `X-API-Key`；失效時在後台重新產生 |
| 429 | 請求過於頻繁 | 按 `Retry-After` 退避 |
