回傳目前 Key 所屬字幕組、`scopes` 與統計。釋出或刪除前先確認 scope。

<ApiEndpoint method="GET" path="/api/subtitle-groups/me" auth="鑑權">
`Authorization: Bearer <KEY>`，或 `X-API-Key`。Bearer 優先。
</ApiEndpoint>

<Callout type="warn">
  僅 `status=active` 可釋出。`apiKeySuffix` 不能用於鑑權。
</Callout>

完整欄位見 [API 參考](/docs/open-api/reference)。

```bash title="curl"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

| HTTP | 處理 |
| --- | --- |
| 401 | 檢查 Bearer / `X-API-Key`；失效則後台重新產生 |
| 429 | 按 `Retry-After` 退避 |
