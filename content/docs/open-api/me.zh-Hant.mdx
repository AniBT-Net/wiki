title: 字幕組自身資訊

---

`/api/subtitle-groups/me` 是**鑑權讀取**端點。帶上字幕組 API Key，返回該字幕組的基本資訊、目前 Key 的安全識別與 `scopes`，以及釋出數、覆蓋番劇數、成員數等統計資料。

適合用在：CI 啟動時列印目前使用哪把 Key、控制台 dashboard 展示字幕組狀態、自動化指令碼校驗字幕組身分，並在釋出或刪除前確認 Key 是否具有 `releases:publish` / `releases:delete`。

## 請求

```http title="HTTP"
GET https://anibt.net/api/subtitle-groups/me
Authorization: Bearer <YOUR_API_KEY>
```

```bash title="curl 示例"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

## 與公共目錄的關係

<Callout type="info">
  與 [`/api/subtitle-groups`](/docs/open-api/subtitle-groups) 的核心差別：
  - `/api/subtitle-groups`：**公開**，返回**所有**字幕組的精簡資訊，不需要鑑權。
  - `/api/subtitle-groups/me`：**鑑權**，只返回**呼叫方**這一組的詳細資訊，附帶 `stats`、Key 識別與 `scopes`，以及內部 `_id`、`description`、`status`。
</Callout>

## 錯誤響應

| HTTP | 原因 | 處理 |
| ---- | ---- | ---- |
| 401 | API Key 缺失、格式錯誤、無效或已撤銷 | 使用 `Authorization: Bearer <KEY>` 或 `X-API-Key`；失效時在後台重新產生 |
| 429 | 請求過於頻繁 | 按 `Retry-After` 退避 |
