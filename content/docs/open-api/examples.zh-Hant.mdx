AniBT 的公開 RSS 與開放 API 專為自動化整合而設計。無論是將訂閱來源新增至下載工具實現全自動追番，還是撰寫自動化腳本與 CI/CD 流水線對接，均可直接參考以下經過驗證的程式碼範例。

<Callout type="info">
  **訂閱技巧**：公開 RSS 來源預設輸出最新的 100 筆記錄（已是單次最大上限），直接使用基礎連結即可，無需額外新增 `limit=100` 參數。
</Callout>

## 常用 RSS 訂閱連結組合

以下範例基於動畫條目 `bgmId=543360` 與常用字幕組 slug 示範：

  <Tab value="按番劇與字幕組">
    僅追蹤指定字幕組釋出的某部番劇：

    ```txt title="單一字幕組 × 單一番劇"
    https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia
    ```
  </Tab>

  <Tab value="跨組追番 (按畫質語言)">
    不限字幕組，只要是該番劇的 1080p 繁體中文/簡體中文版本即抓取：

    ```txt title="畫質與字幕語言過濾"
    https://anibt.net/rss/anime.xml?bgmId=543360&resolution=1080p&language=CHT
    ```
  </Tab>

  <Tab value="訂閱字幕組全部作品">
    追蹤某字幕組釋出的所有新番與資源（兩種連結形式完全等價）：

    ```txt title="字幕組全量釋出 RSS"
    https://anibt.net/rss/group/kirara-fantasia.xml
    https://anibt.net/rss/anime.xml?groupSlug=kirara-fantasia
    ```
  </Tab>

  <Tab value="僅下載完結全集 (合集)">
    跳過單集連載，僅在字幕組釋出合集（Batch / 季度打包）時下載：

    ```txt title="合集資源過濾"
    https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kitauji-sub&episodeKey=BATCH
    ```

## 自動化下載器接入指引

<Tabs items={['qBittorrent', 'Sonarr', 'FlexGet']}>
  <Tab value="qBittorrent">
    1. 開啟 qBittorrent，在左側導覽列切換至 **RSS** 標籤頁。
    2. 點選 **新增訂閱**，將產生的 AniBT RSS 連結貼上進去並儲存。
    3. 點選右上角的 **RSS 下載器（規則）**，新建一條自動下載規則並勾選剛才新增的訂閱來源。
    4. 建議將客戶端的預設輪詢間隔設定為 **15 ~ 30 分鐘**。
  </Tab>

  <Tab value="Sonarr">
    1. 進入 Sonarr 設定頁，點選 **Settings** → **Indexers** → **Add**。
    2. 選擇 **Torznab**，**URL** 填 `https://anibt.net/torznab`，**API Path** 保持 `/api`，**Anime Categories** 選擇 `5070`。完整步驟見 [Torznab 介面](/zh-Hant/docs/open-api/torznab)。
    3. 只想訂閱固定的番劇或字幕組時，也可以選擇 **Torrent RSS Feed**，URL 填上面的 RSS 位址。
  </Tab>

  <Tab value="FlexGet">
    在 `config.yml` 中直接將 AniBT RSS 作為輸入源：

    ```yaml title="config.yml"
    tasks:
      anime_task:
        rss: https://anibt.net/rss/anime.xml?bgmId=543360&language=CHT
        all_series: yes
        download: ~/Downloads/Torrents/
    ```
  </Tab>
</Tabs>

## 實戰腳本範例

### 1. 具備 304 快取的 Bash 條件輪詢腳本

透過儲存並發送 `ETag`，當伺服端無新資源時直接回傳空回應體 `304`，避免重複下載 XML：

```bash title="conditional_rss_poll.sh"
#!/usr/bin/env bash
set -euo pipefail

FEED_URL="https://anibt.net/rss/anime.xml?bgmId=543360"
ETAG_FILE="/tmp/anibt_anime_543360.etag"

# 讀取歷史 ETag
ETAG=""
if [ -f "$ETAG_FILE" ]; then
  ETAG=$(cat "$ETAG_FILE")
fi

echo "正在檢查新資源更新..."
if [ -n "$ETAG" ]; then
  RESPONSE=$(curl -sI -H "If-None-Match: $ETAG" "$FEED_URL")
else
  RESPONSE=$(curl -sI "$FEED_URL")
fi

HTTP_STATUS=$(echo "$RESPONSE" | grep -i '^http/' | awk '{print $2}')

if [ "$HTTP_STATUS" = "304" ]; then
  echo ">>> 內容未發生變化 (304 Not Modified)，無需重複下載。"
elif [ "$HTTP_STATUS" = "200" ]; then
  echo ">>> 發現新資源！拉取完整數據並儲存最新 ETag..."
  NEW_ETAG=$(echo "$RESPONSE" | grep -i '^etag:' | cut -d' ' -f2- | tr -d '\r')
  echo "$NEW_ETAG" > "$ETAG_FILE"
  # 這裡可以進一步執行下載或推送通知
fi
```

### 2. 非同步撤回刪除與輪詢終態腳本

刪除釋出為非同步操作，腳本先發起 `DELETE` 請求，隨後輪詢查詢介面直至收到 `completed` 終態：

```bash title="delete_and_wait.sh"
#!/usr/bin/env bash
set -euo pipefail

RELEASE_ID="rel_01j7example123"
API_KEY="YOUR_SUBTITLE_GROUP_API_KEY"
BASE_URL="https://anibt.net"

echo "發起非同步刪除請求: $RELEASE_ID"
DELETE_RES=$(curl -sS -X DELETE \
  -H "Authorization: Bearer $API_KEY" \
  "$BASE_URL/api/releases/$RELEASE_ID")

STATE=$(echo "$DELETE_RES" | jq -r '.result.state // .error.details.state // "pending"')

# 輪詢狀態介面
while [ "$STATE" = "pending" ]; do
  echo "刪除任務正在佇列中處理，2 秒後重試..."
  sleep 2
  STATUS_RES=$(curl -sS \
    -H "Authorization: Bearer $API_KEY" \
    "$BASE_URL/api/releases/$RELEASE_ID/deletion")
  STATE=$(echo "$STATUS_RES" | jq -r '.result.state // "pending"')
done

if [ "$STATE" = "completed" ]; then
  echo ">>> 資源已徹底刪除並通過安全屏障！"
else
  echo ">>> 刪除未能完成，目前狀態: $STATE"
fi
```
