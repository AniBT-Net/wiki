---
title: 限流与上限
description: 各端点的 limit 与速率窗口。
---

数字与状态码是公开契约。超限返回 `429`，按 `Retry-After` 退避。

## 各端点

| 端点 | `limit` 默认 | `limit` 上限 | 速率限制（默认） |
| --- | --- | --- | --- |
| `/rss/anime.xml` | **100** | **100** | 120 次 / 60 秒 / IP |
| `/rss/group/<slug>.xml` | 100 | **100** | 120 次 / 60 秒 / IP |
| `/rss/magnets.xml` | 100 | **100** | 120 次 / 60 秒 / IP |
| `/rss/other/<category>.xml` | 100 | **100** | 120 次 / 60 秒 / IP |
| `/api/bgm/search` | 5 | **25** | 60 次 / 60 秒 / IP |
| `/api/animes/search` | 24 | **50** | 120 次 / 60 秒 / IP |
| `/api/animes/torrent-match` | 10 | **50** | 180 次 / 60 秒 / IP |
| `/api/anime/lookup` | — | — | 60 次 / 60 秒 / IP |
| `/api/mikan/group-lookup` | — | — | 60 次 / 60 秒 / IP |
| `/api/subtitle-groups` | — | 全量返回 | 60 次 / 60 秒 / IP |
| `/api/seasons/anime` | — | — | 30 次 / 60 秒 / IP |
| `/api/anime/groups` | — | — | 30 次 / 60 秒 / IP |
| `DELETE /api/releases/{releaseId}` | — | — | 30 次 / 60 秒 / API Key |
| `GET /api/releases/{releaseId}/deletion` | — | — | 120 次 / 60 秒 / API Key |

删除另有认证前防滥用窗口。`pending` 回执里的 `Retry-After` 是状态轮询建议；真正超限是 `429`。

<Callout type="warn">
  公开 RSS 的 `limit` 只接受单个 `1..100` 整数。非法值应用返回 `400`，生产边缘可能先 `403`。默认就是 100，不要传 `limit=100`，否则可能 `308`。
</Callout>

`/rss/magnets.xml` 与 `/rss/other/*` 的 `q` / `search` 只能一个值，最多 160 UTF-8 bytes。新关键词搜索：每主题 120 次 / 10 分钟、1000 次 / 24 小时，超限 `429`。稳定查询不计入。

公开搜索最多 100 页。`/magnets?page=` 超出重定向到第 100 页。`/api/animes/search` 的 `cursor` 只接受 `ts_page:<页码>`。

过滤过严时条数可能少于 `limit`。

## 客户端

- 省略 `limit` 即 100 条。
- 带 `If-None-Match`。
- 间隔 ≥ 5 分钟。
- 不要对同一 URL 并发。
- 不要间隔 &lt; 1 分钟。
