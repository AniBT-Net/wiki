公开 RSS 的 `limit` 只接受无前导零的整数 `1..100`，重复、空值或格式错误返回 400；默认 `limit=100` 会规范化为省略参数的 URL。个人 RSS 使用独立规则，不能套用公开 RSS 的默认值。

RSS 的 q/search 与 Torznab 的 q 规范化后最多 160 个 UTF-8 字节。Bangumi 搜索、季度标题查询和标题匹配各有字符数限制，不能共用一个长度规则。公开 RSS 没有 cursor/page 分页；Torznab 使用有界 offset。

收到 429 时按 Retry-After 等待；该字段存在时单位为秒。没有该字段的错误不能假定 2 秒后成功。普通 RSS 建议至少间隔 5 分钟，并避免并发请求；304 仍可能消耗额度。
