---
title: 字幕组自身信息
description: GET /api/subtitle-groups/me —— 用 API Key 查询当前字幕组、Key 标识、scope 与统计数据。
---

`/api/subtitle-groups/me` 是**鉴权读取**端点。带上字幕组 API Key，返回该字幕组的基本信息、当前 Key 的安全标识与 `scopes`，以及发布数、覆盖番剧数、成员数等统计数据。

适合用在：CI 启动时打印当前用哪把 Key 跑、控制台 dashboard 展示字幕组当前状态、自动化脚本里校验字幕组身份，并在发布或删除前确认 Key 是否具有 `releases:publish` / `releases:delete`。

## 请求

```http title="HTTP"
GET https://anibt.net/api/subtitle-groups/me
Authorization: Bearer <YOUR_API_KEY>
```

```bash title="curl 示例"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

## 响应

```jsonc title="200 OK"
{
  "ok": true,
  "data": {
    "_id": "...",
    "name": "My Group",
    "slug": "my-group",
    "description": "...",
    "website": "https://...",
    "stats": {
      "totalReleases": 42,
      "totalAnimes": 10,

  }
}
```

## 与公共目录的关系

<Callout type="info">
  与 [`/api/subtitle-groups`](/docs/open-api/subtitle-groups) 的核心差别：
  - `/api/subtitle-groups`：**公开**，返回**所有**字幕组的精简信息，不需要鉴权。
  - `/api/subtitle-groups/me`：**鉴权**，只返回**调用方**这一组的详细信息，附带 `stats`、Key 标识与 `scopes`，以及内部 `_id`、`description`、`status`。
</Callout>

## 错误响应

| HTTP | 原因 | 处理 |
| ---- | ---- | ---- |
| 401 | API Key 缺失、格式错误、无效或已撤销 | 使用 `Authorization: Bearer <KEY>` 或 `X-API-Key`；失效时在后台重新生成 |
| 429 | 请求过于频繁 | 按 `Retry-After` 退避 |
