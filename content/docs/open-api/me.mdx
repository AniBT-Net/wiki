---
title: 字幕组自身信息
description: GET /api/subtitle-groups/me —— 用 API Key 查当前组、scope 与统计。
---

返回当前 Key 所属字幕组、`scopes` 与统计。发布或删除前先确认 scope。

<ApiEndpoint method="GET" path="/api/subtitle-groups/me" auth="鉴权">
`Authorization: Bearer <KEY>`，或 `X-API-Key`。Bearer 优先。
</ApiEndpoint>

<Callout type="warn">
  仅 `status=active` 可发布。`apiKeySuffix` 不能用于鉴权。
</Callout>

完整字段见 [接口参考](/docs/open-api/reference)。

```bash title="curl"
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  https://anibt.net/api/subtitle-groups/me
```

| HTTP | 处理 |
| --- | --- |
| 401 | 检查 Bearer / `X-API-Key`；失效则后台重新生成 |
| 429 | 按 `Retry-After` 退避 |
