---
title: 其他类 RSS
description: GET /rss/other/<category>.xml —— 七个分类各自一份 RSS，不混入番剧 RSS。
---

漫画、音乐、RAW、舞台剧、合集、剧场版、其他。订阅这些资源必须用本页路径。

<ApiEndpoint method="GET" path="/rss/other/<category>.xml" auth="公开">
分类：`manga` / `music` / `raw` / `stage` / `collection` / `movie` / `other`。
</ApiEndpoint>

<Callout type="info">
  空分类仍返回有效空 channel，不返回 404。无 `<anibt:bgmId>`。
</Callout>

不带 `limit`、`q`、`search` 或其他过滤条件的分类 URL 是 fixed RSS。客户端请求
会核对当前发布版本，未变化时可用 `ETag` 返回 `304`；响应使用
`no-store`，避免共享缓存保存旧正文。带 `limit` 或搜索条件的 URL 继续走
有界刷新策略。RSS `<ttl>` 只提示客户端轮询频率。

完整参数见 [接口参考](/docs/open-api/reference)。

```txt title="示例"
https://anibt.net/rss/other/manga.xml
https://anibt.net/rss/other/music.xml?q=FLAC&limit=50
```

`q` 与 `search` 只能提供一个值。空、控制字符或超长返回 `400`。
