description: "明确哪些端点支持 ETag，以及何时复用正文。"

保存完整响应正文及其 ETag，下次请求通过 If-None-Match 验证。

304 没有正文，只能复用同一个 URL 先前保存的表示。首次请求或本地正文丢失时，不要只发送旧 ETag。优先使用 If-None-Match；条件请求仍可能消耗限流额度。

发布返回 200 不代表外站同步、搜索和 RSS 已完成更新。外站进度应查询同步状态接口；不要把一次观测到的延迟当作完成时限。
