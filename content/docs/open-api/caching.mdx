---
title: HTTP 缓存与 304
description: 公开读取用 If-None-Match。未变返回 304。轮询间隔 ≥ 5 分钟。
---

公开 RSS 与 JSON 支持条件请求。写入、删除、`/me`、个人订阅不缓存。

<Callout type="info">
  带上次的 `ETag`。未变化返回 `304`，无正文。优先 `If-None-Match`，不要依赖 `If-Modified-Since`。
</Callout>

轮询间隔 ≥ 5 分钟。更短没有收益，且容易 429。

```bash title="If-None-Match"
H=$(curl -sI "https://anibt.net/rss/anime.xml?bgmId=543360")
ETAG=$(echo "$H" | grep -i '^etag:' | cut -d' ' -f2- | tr -d '\r')
curl -sI -H "If-None-Match: $ETAG" \
  "https://anibt.net/rss/anime.xml?bgmId=543360"
```

发布接口的 `200` 不表示 RSS 立刻包含该条。用返回的 `releaseId` 在详情页或 RSS 正文核对。
