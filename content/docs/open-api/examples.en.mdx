All examples use `bgmId=543360` (*Kamiina Botan, Yoeru Sugata wa Yuri no Hana*). The four group slugs below are validated via [`/api/subtitle-groups`](/docs/open-api/subtitle-groups):

```txt title="Target groups"
kirara-fantasia   Kirara Fantasia
pre-s             Prejudice-Studio
kitauji-sub       北宇治字幕组
haruhana          拨雪寻春
```

## 1. One group × one show (most common)

```txt title="One feed = one group × one anime"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=pre-s
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kitauji-sub
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=haruhana
```

## 3. Language + subtitle type

**北宇治字幕组**, Simplified Chinese, external or soft-internal subtitles:

```txt
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kitauji-sub&language=CHS&subtitle=EXTERNAL&subtitle=INTERNAL
```

## 4. Multiple filters stacked

**拨雪寻春**, 1080p, MKV, Simplified external, episode 5:

```txt
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=haruhana&resolution=1080p&format=MKV&language=CHS&subtitle=EXTERNAL&episode=5
```

## 5. Aggregate one show across groups

All groups under 543360 at 1080p Simplified Chinese:

```txt
https://anibt.net/rss/anime.xml?bgmId=543360&resolution=1080p&language=CHS
```

## 8. High-throughput pull (max page)

```txt
https://anibt.net/rss/anime.xml?groupSlug=kirara-fantasia&limit=100
```

<Callout type="info">
  Public RSS `limit` is capped at **100**. Oversized, duplicate, empty, zero-padded, or non-integer values are not truncated: the app returns 400; production edge may return Cloudflare 403 first. See [Rate limits & caps](/docs/open-api/limits).
</Callout>

## 9. Delete an anime release and poll completion

The delete key must explicitly include `releases:delete`. After `202 Accepted`, poll the status endpoint — do not treat “accepted” as “every public surface is clean”.

```bash title="DELETE + status poll"
release_id='rel_example'
base_url='https://anibt.net'

response=$(curl -sS -X DELETE \
  -H "Authorization: Bearer $ANIBT_API_KEY" \
  "$base_url/api/releases/$release_id")

while [ "$(jq -r '.result.state // .error.details.state // empty' <<<"$response")" = "pending" ]; do
  sleep 2
  response=$(curl -sS \
    -H "Authorization: Bearer $ANIBT_API_KEY" \
    "$base_url/api/releases/$release_id/deletion")
done

jq . <<<"$response"
```

Stop only on terminal `completed`. On `failed`, keep `operationId` and `X-Request-ID` and stop blind retries. Full fields, status codes, and completion boundaries: [Delete an anime release](/docs/open-api/releases-delete).
