Paste the RSS URL into the client. No extra setup. Poll interval ≥ 5 minutes.

<Callout type="info">
  Public RSS `limit` cap is **100**. Omit `limit` to take the full page. Get slugs from [`/api/subtitle-groups`](/docs/open-api/subtitle-groups).
</Callout>

## RSS URLs

All examples use `bgmId=543360`. Slugs: `kirara-fantasia`, `pre-s`, `kitauji-sub`, `haruhana`.

```txt title="One group × one show"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia
```

```txt title="1080p or 4K"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia&resolution=1080p&resolution=4K
```

```txt title="Language + subtitle type"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kitauji-sub&language=CHS&subtitle=EXTERNAL&subtitle=INTERNAL
```

```txt title="Stacked filters"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=haruhana&resolution=1080p&format=MKV&language=CHS&subtitle=EXTERNAL&episode=5
```

```txt title="One show across groups"
https://anibt.net/rss/anime.xml?bgmId=543360&resolution=1080p&language=CHS
```

```txt title="Everything from one group (equivalent)"
https://anibt.net/rss/anime.xml?groupSlug=kirara-fantasia
https://anibt.net/rss/group/kirara-fantasia.xml
```

```txt title="Batch"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kitauji-sub&episodeKey=BATCH
```

## qBittorrent / Sonarr / FlexGet

Paste the subscribe URL. qBittorrent’s 30-minute default is fine; it does not send `If-None-Match` and always pulls the full body. Custom scripts must send `If-None-Match`.

## curl

```bash title="If-None-Match"
H=$(curl -sI 'https://anibt.net/rss/anime.xml?bgmId=543360')
ETAG=$(echo "$H" | grep -i '^etag:' | cut -d' ' -f2- | tr -d '\r')
curl -sI -H "If-None-Match: $ETAG" \
  'https://anibt.net/rss/anime.xml?bgmId=543360'
```

```bash title="DELETE + poll"
release_id='rel_example'
base_url='https://anibt.net'

response=$(curl -sS -X DELETE \
  -H "Authorization: Bearer $ANIBT_API_KEY" \
  "$base_url/api/releases/$release_id")

while [ "$(jq -r '.result.state // .error.details.state // empty' <<<"$response")" = "pending" ]; do
  sleep 2
  response=$(curl -sS \
    -H "Authorization: Bearer $ANIBT_API_KEY" \
    "$base_url/api/releases/$release_id/deletion")
done

jq . <<<"$response"
```

The delete key must include `releases:delete`. Stop only on `completed`.
