title: 总览
description: AniBT 公开 RSS 与 JSON API 入口。契约见接口参考。
---

AniBT 对外提供 **RSS**（订阅）和 **JSON**（程序读取）。公开读取可匿名，并按各端点缓存合同支持 **HTTP 304**。发布、删除、`/me` 必须带字幕组 API Key，响应不缓存。

<Callout type="warn">
  生产 base URL 为 `https://anibt.net`。只使用文档列出的主站路径。
</Callout>

请求、参数、响应见 [接口参考](/docs/open-api/reference)。

qBittorrent / Sonarr / FlexGet 等 RSS 客户端无需额外配置。缓存、限流、排障仍在对应页。

## 稳定性

- 路径与查询参数不会做不兼容变更；新参数只做扩展。
- `slug` 一旦发布尽量保持稳定。
- 内部主键不属于公开契约，一律使用 `slug`。
