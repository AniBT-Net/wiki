AniBT 提供公开查询与订阅接口，以及通过字幕组 API Key 调用的发布、删除和同步状态接口。

<Callout type="info">
  https://anibt.net · [OpenAPI 3.1](/openapi.yaml)
</Callout>

<TypeTable type={{
  "公开查询": {

    "type": "RSS / .torrent",
    "description": "公开 RSS、个人 RSS、种子下载，以及 Sonarr / Radarr / Prowlarr 使用的 Torznab。"
  }
}} />

生产 Base URL 为 `https://anibt.net`。API Key、个人 RSS 令牌和登录会话适用于不同接口，不能互相替代。成功响应的包装、空值及错误格式按每个端点定义处理。

机器可读定义见 [/openapi.yaml](/openapi.yaml)。接口页展示请求字段和响应示例；标题匹配是公开查询，但传入 groupId 时要求登录会话及该组成员身份。
