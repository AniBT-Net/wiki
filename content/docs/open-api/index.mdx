AniBT 秉持开放的社区理念，将全站番剧信息、发布资源、字幕组目录与最新磁力链接全面对外开放。

<Callout type="info">
  **生产 Base URL**：`https://anibt.net`。除特别说明外，所有数据均通过标准 HTTPS 提供服务。所有公开读取接口均可匿名调用，无需申请 Token 或配置复杂凭证。
</Callout>

每个接口文档页面均内嵌了基于 OpenAPI 契约生成的 **Try-it 交互测试面板**，你可以在浏览器中直接填写参数并发起真实请求，快速验证响应结构。

## 体系架构与核心能力

<Tabs items={['公开读取 (免鉴权)', '字幕组自动化 (需 API Key)', '标准 RSS 体系']}>
  <Tab value="公开读取 (免鉴权)">
    面向普通开发者、第三方动漫客户端、机器人与数据分析脚本：

    - **番剧检索与详情**：通过动画名称、日文原名或 Bangumi ID 获取结构化条目数据
    - **字幕组目录**：查询全站活跃字幕组列表及其稳定英文 `slug`
    - **种子匹配**：调用标题解析引擎，自动分析动画集数、分辨率与字幕语言
    - **条件缓存**：全面支持 HTTP 弱 ETag 与 304 协商，轮询极大节省流量
  </Tab>

  <Tab value="字幕组自动化 (需 API Key)">
    面向入驻字幕组的 CI/CD 自动压制发布流程与管理脚本：

    - **资源发布**：通过 `POST /api/releases/publish` 自动提交 `.torrent` 种子
    - **身份核验**：通过 `GET /api/releases/publish` 执行 whoami 自检
    - **外站同步追踪**：实时查询六大 BT 站的同步发布结果与外站链接
    - **异步删除**：通过 `DELETE /api/releases/{id}` 撤回发布并追踪清理终态
  </Tab>

  <Tab value="标准 RSS 体系">
    面向 qBittorrent、Sonarr、FlexGet 等主流自动化下载器：

    - **单番剧订阅**：按 Bangumi ID 聚合订阅，支持叠加字幕组、画质、字幕语言过滤
    - **字幕组订阅**：按字幕组 `slug` 订阅该组全部最新作品
    - **全站磁力**：全站最新入库资源的实时磁力推送源
    - **标准协议**：完整支持 RFC 规范与 BitTorrent BEP 36 扩展标签
  </Tab>
</Tabs>

## 接口稳定性与规范承诺

1. **向下兼容保证**：已公开的端点路径与参数不会进行不兼容修改，新功能仅通过追加参数实现。
2. **标识符规范**：第三方在调用与持久化时请务必使用 **`slug`**（如 `kirara-fantasia`）或 **`bgmId`**，避免依赖易变的内部主键。
3. **机器可读契约**：标准 OpenAPI 3.1 规范文件可在 [/openapi.yaml](/openapi.yaml) 直接获取。
