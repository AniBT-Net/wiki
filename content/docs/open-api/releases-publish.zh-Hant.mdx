寫入番劇資源。正式釋出與 preview 都要求 `releases:publish`。

<ApiEndpoint method="POST" path="/api/releases/publish" auth="鑑權 · releases:publish">
推薦 multipart 上傳 `.torrent`；或 JSON 傳磁力。
</ApiEndpoint>

<Callout type="warn">
  Key 不要寫進客戶端、倉庫或 issue。CI 用 secret 注入。`200` 表示主記錄已寫入，不表示 RSS / 搜尋 / 頁面已可見。
</Callout>

完整欄位見 [API 參考](/docs/open-api/reference)。

## 身分自檢

GET 同一路徑，不寫庫，不要求 publish scope。批次釋出前確認 `groupSlug` 與 `scopes`。

```bash title="whoami"
curl -X GET 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>'
```

## 釋出

<Tabs items={['multipart（推薦）', 'JSON']}>
  <Tab value="multipart（推薦）">
    ```bash title="上傳種子"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'animeIdType=anilist' \
      -F 'animeId=170942' \
      -F 'title=[字幕組] 葬送的芙莉莲 - 01 [1080p].mkv' \
      -F 'episodeKey=01' \
      -F 'resolution=1080p' \
      -F 'language=CHS' -F 'language=JP' \
      -F 'subtitle=EXTERNAL' \
      -F 'format=MKV' \
      -F 'torrent=@/path/to/release.torrent'
    ```
  </Tab>
  <Tab value="JSON">
    ```bash title="JSON 磁力"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -H 'Content-Type: application/json' \
      --data @- <<'JSON'
    {
      "animeIdType": "mal",
      "animeId": "52991",
      "title": "[字幕組] 葬送的芙莉莲 - 01 [1080p].mkv",
      "magnetBase64": "magnet:?xt=urn:btih:...",
      "episodeKey": "01",
      "resolution": "1080p",
      "language": ["CHS", "JP"],
      "subtitle": "EXTERNAL",
      "format": "MKV",
      "fileSize": 734003200
    }
    JSON
    ```
  </Tab>
</Tabs>

## 約束

- JSON 必填 `title`；multipart 未傳時可用種子內部名。
- multipart 必填 `torrent`。JSON 必填 `magnetBase64`（原始 magnet 或 Base64）。
- 無 torrent 時正式釋出必須 `fileSize > 0`，否則 `422` / `EMPTY_RELEASE_CONTENT`。
- `notes`：Markdown + 原始 HTML，最多 50000 字元，頁面直接渲染。
- `preview=true`：預覽連結 10 分鐘過期，不進入公開列表。
- 未帶番劇 ID 時伺服端跑同一 matcher；不要傳偽造的匹配結果。只有 `auto` 才直接綁定。
- 未傳解析度等欄位時，預設 `resolution=1080p`、`format=MKV`、`subtitle=INTERNAL`、`language=["CHS"]`、`version=v1`；最終 `format=MP4` 時字幕預設更傾向 `EMBEDDED`。
- 同版本已存在回傳 `409`，換 `version`。

## Nyaa 代發

<Callout type="warn">
  僅白名單字幕組。釋出超分資源者無法申請。規則見 [Nyaa 代發](/docs/nyaa-proxy)。必須 multipart 上傳 `.torrent`，且種子含 `http://nyaa.tracker.wf:7777/announce`。
</Callout>

```bash title="AniBT + Nyaa"
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'torrent=@release.torrent' \
  -F 'title=[字幕組] 作品名 - 01 [1080p][CHS]' \
  -F 'animeIdType=mal' \
  -F 'animeId=58514' \
  -F 'nyaa=true' \
  -F 'nyaaCategory=1_3'
```

也可用 `sitePublish.nyaa.enabled` / `sitePublish.nyaa.category` 等結構化欄位。只傳 `nyaaCategory` 等 Nyaa 欄位時，伺服端視為啟用。

### Nyaa 代發欄位和分類

| 表單欄位 | JSON 結構化欄位 | 必填 | 說明 |
| --- | --- | --- | --- |
| `nyaa` | `sitePublish.nyaa.enabled` | 否 | `true` 表示請求代發 |
| `nyaaCategory` | `sitePublish.nyaa.category` | 啟用時必填 | 下表代碼，中文動畫字幕常用 `1_3` |
| `nyaaComplete` | `sitePublish.nyaa.complete` | 否 | Complete 標記。預設 `false` |
| `nyaaRemake` | `sitePublish.nyaa.remake` | 否 | Remake 標記。預設 `false` |
| `nyaaDescription` | `sitePublish.nyaa.description` | 否 | 提交到 Nyaa 的 Markdown，最多 20000 字元。不傳則用 `notes`，同樣受 20000 上限 |
| `nyaaInformation` | `sitePublish.nyaa.information` | 否 | information，最多 500 字元 |

| 代碼 | Nyaa 分類 | 什麼時候用 |
| --- | --- | --- |
| `1_1` | Anime - AMV | 動畫音樂影片、剪輯、MAD/AMV |
| `1_2` | Anime - English-translated | 英文翻譯動畫字幕 |
| `1_3` | Anime - Non-English-translated | 非英文翻譯動畫字幕。中文簡體、繁體、雙語中文字幕通常選這個 |
| `1_4` | Anime - Raw | 動畫 RAW，無翻譯字幕 |
| `2_1` | Audio - Lossless | 無損音訊，例如 FLAC、WAV |
| `2_2` | Audio - Lossy | 有損音訊，例如 MP3、AAC、Opus |
| `3_1` | Literature - English-translated | 英文翻譯漫畫、輕小說、書籍 |
| `3_2` | Literature - Non-English-translated | 非英文翻譯漫畫、輕小說、書籍。中文漫畫/小說通常選這個 |
| `3_3` | Literature - Raw | 未翻譯漫畫、輕小說、書籍原文 |
| `4_1` | Live Action - English-translated | 英文翻譯真人影視 |
| `4_2` | Live Action - Idol/Promotional Video | 偶像、宣傳影片、PV 類真人資源 |
| `4_3` | Live Action - Non-English-translated | 非英文翻譯真人影視 |
| `4_4` | Live Action - Raw | 真人影視 RAW |
| `5_1` | Pictures - Graphics | CG、畫集、插畫、掃描圖 |
| `5_2` | Pictures - Photos | 照片寫真 |
| `6_1` | Software - Applications | 應用軟體 |
| `6_2` | Software - Games | 遊戲 |

## 失敗

| HTTP | 處理 |
| --- | --- |
| 400 | 檢查 `title` / 番劇標識 / `.torrent` |
| 401 | 檢查 Bearer / `X-API-Key`；失效則重新產生 |
| 403 | 改用含 `releases:publish` 的 Key |
| 409 | 換 `version`，不要原樣重試 |
| 413 | 種子過大 |
| 422 | `EMPTY_RELEASE_CONTENT` 等校驗失敗 |
| 429 / 503 | 按 `Retry-After` 退避 |
