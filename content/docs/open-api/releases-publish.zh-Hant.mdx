      - content: |
          multipart 必填 `torrent`；JSON 必填 `torrentStorageId`。磁力为可选附加，不能单独发布。preview 同样要求种子。
          `200` 表示主记录已写入，不表示 RSS / 搜索 / 页面已可见。
          JSON 必填 `title`；multipart 未传时可用种子内部名。
          `animeIdType` 与 `animeId` 必填（`bgm` / `anilist` / `mal` / `anidb`）。Matcher 只在 `/api/animes/torrent-match`。
          `notes`：Markdown + 原始 HTML，最多 50000 字符，页面直接渲染。
          `preview=true`：预览链接 10 分钟过期，不进入公开列表。
          未传分辨率等字段时，默认 `resolution=1080p`、`format=MKV`、`subtitle=INTERNAL`、`language=["CHS"]`、`version=v1`；最终 `format=MP4` 时字幕默认更倾向 `EMBEDDED`。
          同版本已存在返回 `409`，换 `version`。
          Nyaa 代发仅白名单字幕组，必须 multipart 上传 `.torrent`，且种子含 `http://nyaa.tracker.wf:7777/announce`。启用时 `nyaaCategory` 必填，中文动画字幕常用 `1_3`。
          也可用 `sitePublish.nyaa.enabled` / `sitePublish.nyaa.category` 等结构化字段。只传 `nyaaCategory` 等 Nyaa 字段时，服务端视为启用。
          Key 不要写进客户端、仓库或 issue。
