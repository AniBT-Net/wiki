---
title: 釋出資源
description: POST /api/releases/publish —— 字幕組用 API Key 釋出種子的寫入端點；支援 JSON（磁力）和 multipart/form-data（種子檔案）兩種格式。
---

`/api/releases/publish` 是字幕組**寫入**資源的唯一端點。需要在請求頭裡攜帶字幕組 API Key 鑑權；支援 `application/json`（直接傳磁力連結）和 `multipart/form-data`（上傳種子檔案）兩種格式。

<Callout type="warn">
  這是**寫入介面**，呼叫頻率與配額由字幕組維度獨立計數；與公開 RSS 的 IP 速率視窗不共享。Key 一旦洩露請立即在後臺重置。
</Callout>

## URL

```http title="HTTP"
POST https://anibt.net/api/releases/publish
Authorization: Bearer <YOUR_API_KEY>
```

## 兩種請求格式

<Tabs items={['multipart/form-data（推薦）', 'application/json']}>
  <Tab value="multipart/form-data（推薦）">
    上傳種子檔案，後端**自動從種子裡提取**磁力連結、infoHash、檔案大小等後設資料。

    ```bash title="上傳種子"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'bgmId=400602' \
      -F 'title=[字幕組] 葬送的芙莉蓮 - 01 [1080p].mkv' \
      -F 'episodeKey=01' \
      -F 'resolution=1080p' \
      -F 'language=CHS' -F 'language=JP' \
      -F 'subtitle=EXTERNAL' \
      -F 'format=MKV' \
      -F 'torrent=@/path/to/release.torrent'
    ```

    `language` 重複表示多個值（CHS + JP）。
  </Tab>
  <Tab value="application/json">
    直接給磁力連結（**仍然需要先有種子**，因為後端只接受能解析的合法 magnet）。

    ```bash title="JSON 請求"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -H 'Content-Type: application/json' \
      --data @- <<'JSON'
    {
      "bgmId": 400602,
      "title": "[字幕組] 葬送的芙莉蓮 - 01 [1080p].mkv",
      "magnetBase64": "magnet:?xt=urn:btih:...",
      "episodeKey": "01",
      "resolution": "1080p",
      "language": ["CHS", "JP"],
      "subtitle": "EXTERNAL",
      "format": "MKV",
      "fileSize": 734003200,
      "notes": "**字型內嵌**，缺幀問題已修復。"
    }
    JSON
    ```

    `magnetBase64` 既接受原始 magnet 連結，也接受 Base64 編碼後的磁力。
  </Tab>
</Tabs>

## 引數值速查

### 請求格式差異

| 場景 | 應該怎麼傳 |
| ---- | ---------- |
| 上傳 `.torrent` | 使用 `multipart/form-data`，欄位名為 `torrent`，例如 `-F 'torrent=@release.torrent'`。 |
| 只傳磁力連結 | 使用 JSON，傳 `magnetBase64`。這個欄位既接受原始 `magnet:?xt=...`，也接受 Base64 編碼後的 magnet。 |
| 多語言 | JSON 用陣列：`"language":["CHS","JP"]`；multipart 可以重複欄位：`-F 'language=CHS' -F 'language=JP'`，也可以傳 JSON 陣列字串。 |
| tracker 列表 | JSON 用陣列；multipart 用換行分隔。站點會與預設 tracker 合併去重。 |
| 布林值 | JSON 用 `true/false`；multipart 可用 `true/false`、`1/0`、`yes/no`、`on/off`。 |

### 番劇與集數

| 欄位 | 可填值 | 說明 |
| ---- | ------ | ---- |
| `bgmId` | Bangumi subject id，例如 `400602` | 推薦填寫。可先呼叫 [`/api/bgm/search`](/docs/open-api/bgm-search) 搜尋番劇。 |
| `malId` | MyAnimeList anime id，例如 `52991` | 可替代 `bgmId`。本站按 bangumi-data 的 BGM 對應關係解析。 |
| `anidbId` | AniDB anime id，例如 `17617` | 可替代 `bgmId`。同一個 AniDB ID 對應多個 BGM 條目時會進入待匹配狀態。 |
| `anilistId` | AniList anime id，例如 `154587` | 可替代 `bgmId`。同一個 AniList ID 對應多個 BGM 條目時會進入待匹配狀態。 |
| `animeId` | 站內 `anime_...` / Convex doc id 字串 | 進階用法。一般不要手填，除非你的系統已經保存了站內番劇 ID。 |
| `episode` | 非負整數，例如 `1`、`12` | 用於排序。自訂 `episodeKey`（如 `SP`、`BATCH`）時請傳 `episode=0`。 |
| `episodeKey` | `01`、`1-12`、`13.5`、`SP`、`OVA`、`MOVIE`、`BATCH` | 用於顯示和去重。純數字會規範化為數字字串，例如 `01` 最終按 `1` 去重。 |
| `version` | `v1`、`v2`、`v2_fix` | 不傳時預設 `v1`。修正版建議用 `v2`。 |

番劇識別優先級為 `animeId` / `bgmId`，然後是 `malId` / `anidbId` / `anilistId`，最後才按標題和種子內部檔名自動匹配。外部 ID 的對應關係以 bangumi-data 為準；若外部 ID 對應多個 BGM 條目或多個外部 ID 解析結果互相衝突，資源會進入待匹配狀態，之後由字幕組或管理員補匹配。

| `language` | `PT` | 葡萄牙語。 |
| `language` | `FR` | 法語。 |
| `language` | `DE` | 德語。 |
| `language` | `IT` | 義大利語。 |
| `language` | `RU` | 俄語。 |
| `language` | `AR` | 阿拉伯語。 |
| `language` | `HI` | 印地語。 |
| `language` | `ID` | 印尼語。 |
| `language` | `MS` | 馬來語。 |
| `language` | `TH` | 泰語。 |
| `language` | `VI` | 越南語。 |
| `language` | `TL` | 菲律賓語 / 他加祿語。 |
| `language` | `TR` | 土耳其語。 |

| `subtitle` | `NONE` | 無字幕；設定後語言會按空列表處理。 |

如果不顯式傳這些欄位，服務端會先從 `title` 推斷，再從種子內部主檔名推斷。仍然無法識別時，預設值為 `resolution=1080p`、`format=MKV`、`subtitle=INTERNAL`、`language=["CHS"]`、`version=v1`；如果最終 `format=MP4`，預設字幕類型會更傾向 `EMBEDDED`。

<Callout type="info">
  現實世界語言數量取決於統計口徑；[Ethnologue 2025](https://www.ethnologue.com/insights/how-many-languages/) 統計約 7,159 種現存語言，ISO 639 也維護標準語言代碼。AniBT 不追全量語言清單，而是先支援字幕發布中常見的大語種；新增語言代碼優先沿用 ISO 639-1，兩岸中文繼續保留站內相容代碼 `CHS` / `CHT`。
</Callout>

## Nyaa 代發

<Callout type="warn">
  Nyaa 代發僅對白名單字幕組開放。發佈超分資源者無法申請白名單；申請規則見 [Nyaa 代發說明](/zh-Hant/docs/nyaa-proxy)。
</Callout>

Nyaa 代發必須使用 `multipart/form-data` 上傳 `.torrent` 檔案，並且種子的 `announce` 或 `announce-list` 必須包含：

```txt title="Nyaa tracker"
http://nyaa.tracker.wf:7777/announce
```

API Key 在 `/groups/<slug>/api-keys` 建立；站內引數說明頁在 `/groups/<slug>/publish?tab=api`。

```bash title="釋出到 AniBT 並請求 Nyaa 代發"
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'torrent=@release.torrent' \
  -F 'title=[字幕組] 作品名 - 01 [1080p][CHS]' \
  -F 'bgmId=12345' \
  -F 'nyaa=true' \
  -F 'nyaaCategory=1_3' \
  -F 'nyaaComplete=false' \
  -F 'nyaaRemake=false' \
  -F 'nyaaDescription=可選：覆蓋提交到 Nyaa 的 Markdown 說明'
```

也可以使用結構化欄位 `sitePublish.nyaa.enabled` / `sitePublish.nyaa.category` / `sitePublish.nyaa.description`。生產代發仍應使用 multipart，因為本站需要校驗實際 torrent bytes 中的 Nyaa tracker。

### Nyaa 代發欄位和分類

| 表單欄位 | JSON 結構化欄位 | 必填 | 說明 |
| -------- | --------------- | ---- | ---- |
| `nyaa` | `sitePublish.nyaa.enabled` | 否 | 設為 `true` 表示請求 Nyaa 代發。只傳 `nyaaCategory` 等 Nyaa 欄位時，服務端也會視為啟用。 |
| `nyaaCategory` | `sitePublish.nyaa.category` | 啟用代發時必填 | Nyaa 分類代碼，必須從下表選擇。普通中文動畫字幕常用 `1_3`。 |
| `nyaaComplete` | `sitePublish.nyaa.complete` | 否 | 對應 Nyaa 的 Complete 標記；合集、全卷、全季等完整資源可設為 `true`。預設 `false`。 |
| `nyaaRemake` | `sitePublish.nyaa.remake` | 否 | 對應 Nyaa 的 Remake 標記；重傳、修復版、重製版按需要設為 `true`。預設 `false`。 |
| `nyaaDescription` | `sitePublish.nyaa.description` | 否 | 提交到 Nyaa 的 Markdown 說明，最多 20000 字元。不傳時繼承本站 `notes`。 |
| `nyaaInformation` | `sitePublish.nyaa.information` | 否 | Nyaa information 欄位，最多 500 字元，通常填寫官網、字幕組頁面、專案頁或相關說明連結。 |

Nyaa 分類代碼必須原樣填寫：

| 代碼 | Nyaa 分類 | 什麼時候用 |
| ---- | --------- | ---------- |
| `1_1` | Anime - AMV | 動畫音樂影片、剪輯、MAD/AMV。 |
| `1_2` | Anime - English-translated | 英文翻譯動畫字幕。 |
| `1_3` | Anime - Non-English-translated | 非英文翻譯動畫字幕。中文簡體、繁體、雙語中文字幕通常選這個。 |
| `1_4` | Anime - Raw | 動畫 RAW，無翻譯字幕。 |
| `2_1` | Audio - Lossless | 無損音訊，例如 FLAC、WAV。 |
| `2_2` | Audio - Lossy | 有損音訊，例如 MP3、AAC、Opus。 |
| `3_1` | Literature - English-translated | 英文翻譯漫畫、輕小說、書籍。 |
| `3_2` | Literature - Non-English-translated | 非英文翻譯漫畫、輕小說、書籍。中文漫畫/小說通常選這個。 |
| `3_3` | Literature - Raw | 未翻譯漫畫、輕小說、書籍原文。 |
| `4_1` | Live Action - English-translated | 英文翻譯真人影視。 |
| `4_2` | Live Action - Idol/Promotional Video | 偶像、宣傳影片、PV 類真人資源。 |
| `4_3` | Live Action - Non-English-translated | 非英文翻譯真人影視。 |
| `4_4` | Live Action - Raw | 真人影視 RAW。 |
| `5_1` | Pictures - Graphics | CG、畫集、插畫、掃描圖等圖像資源。 |
| `5_2` | Pictures - Photos | 照片寫真類資源。 |
| `6_1` | Software - Applications | 應用軟體。 |
| `6_2` | Software - Games | 遊戲。 |

## 預覽模式

釋出前想先看看渲染效果（標題解析、Markdown 備註、磁力是否正確），把 `preview=true` 即可：

```bash title="預覽，不公開"
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'bgmId=400602' \
  -F 'title=[字幕組] 葬送的芙莉蓮 - 01 [1080p].mkv' \
  -F 'preview=true' \
  -F 'torrent=@/path/to/release.torrent'
```

返回的預覽 URL **10 分鐘後過期**，**不會**進入 RSS / 搜尋 / 前端列表。適合自動化流水線在正式釋出前做最後一次人工確認。

  <Step>

</Callout>

## 常見錯誤

| HTTP | 原因                                              | 處理                                                          |
| ---- | ------------------------------------------------- | ------------------------------------------------------------- |
| 400  | `title` / `bgmId` 缺失，或 `torrent` 解析失敗       | 檢查必填項；確認上傳的是合法 .torrent 檔案                       |
| 401  | `Authorization` 頭缺失或格式錯誤                    | `Bearer ` 字首必填，注意空格                                    |
| 403  | API Key 無效 / 已撤銷 / 不屬於該字幕組              | 重新生成 Key                                                  |
| 409  | 同一 infoHash 已經發布過                           | 想替換請用 `version=v2` 重發                                   |
| 413  | 種子檔案 / 表單超過大小限制                         | 壓縮種子（裁剪 tracker 列表）                                   |
| 429  | 寫入配額耗盡                                       | 按響應頭 `Retry-After` 退避                                    |
