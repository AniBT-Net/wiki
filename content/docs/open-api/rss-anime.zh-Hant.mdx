主訂閱入口。`bgmId` 與 `groupSlug` 至少提供一個。

<ApiEndpoint method="GET" path="/rss/anime.xml" auth="公開">
相容 Mikan 的 `bangumiId`、`subgroupid`。
</ApiEndpoint>

<Callout type="warn">
  `limit` 預設 100，範圍 1–100。重複、為空、前導零或非整數：應用 `400`，生產邊緣可能先 `403`。與預設值等價的寫法會 `308` 到規範 URL，跟隨跳轉。
</Callout>

不帶 `limit`、Tag 或搜尋條件，且同時指定已收錄 `bgmId` 與 `groupSlug` 的規範
anime-pair RSS 屬於 fixed feed。成功回應由 CDN 共用 300 秒並使用
`must-revalidate`；發布後的精確失效會先清掉舊物件，TTL 只作為失效延遲時的有界
後備。客戶端仍以 `max-age=0` 驗證，內容未變更時可用 `ETag` 回傳 `304`；未準備好
或錯誤回應不進入共用快取。帶 `limit`、Tag、搜尋或其他過濾條件的 URL 仍使用有界
更新策略。RSS `<ttl>` 只是客戶端輪詢提示。

完整參數見 [API 參考](/docs/open-api/reference)。

```txt title="示例"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia&resolution=1080p
```

Tag 可重複或逗號分隔：`?resolution=1080p&resolution=720p` 與 `?resolution=1080p,720p` 等價。

## Mikan

把主機換成 `anibt.net`，參數原樣工作：

```txt title="相容寫法"
https://anibt.net/rss/anime.xml?bangumiId=3921&subgroupid=615
```

新程式用 `bgmId` 與 `groupSlug`。
