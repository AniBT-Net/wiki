---
title: 个人订阅 RSS
description: GET /rss/subscriptions.xml —— 前端「我的订阅」合并成一份私人 RSS。
---

把已保存的订阅导出为 RSS。使用账户后台生成的完整链接。

<ApiEndpoint method="GET" path="/rss/subscriptions.xml" auth="鉴权">
`Cache-Control: private, no-store`。无公开 ETag。
</ApiEndpoint>

<Callout type="warn">
  链接带身份凭证。不要贴到 issue、截图、仓库或群。泄露后立刻到后台重置。
</Callout>

轮询间隔 ≥ 5 分钟。过快返回 429。条目结构与 [`/rss/anime.xml`](/docs/open-api/rss-anime) 相同。完整说明见 [接口参考](/docs/open-api/reference)。

```txt title="请求"
GET https://anibt.net/rss/subscriptions.xml
```

| HTTP | 处理 |
| --- | --- |
| 400 | 从后台重新复制完整链接 |
| 401 | 重新登录，或重新获取链接 |
| 403 | 凭证已吊销 / 用户被封禁 |
| 429 | 拉长间隔 |
