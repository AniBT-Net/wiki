Main subscribe URL. Provide at least one of `bgmId` or `groupSlug`.

<ApiEndpoint method="GET" path="/rss/anime.xml" auth="public">
Mikan aliases `bangumiId` and `subgroupid` work.
</ApiEndpoint>

<Callout type="warn">
  `limit` defaults to 100, range 1–100. Duplicate, empty, zero-padded, or non-integer values: app `400`; production edge may return `403` first. Forms equivalent to the default `308` to the canonical URL — follow the redirect.
</Callout>

An anime-pair RSS URL with no `limit`, tag, search, or other filter, and with both a
catalogued `bgmId` and `groupSlug`, is a fixed feed. Every client request checks
the current publication version; an unchanged `ETag` may return `304`, and an old
Cloudflare object is never authoritative. URLs with `limit`, tags, search, or
other filters keep the existing dynamic RSS owner.

Full parameters: [API reference](/docs/open-api/reference).

```txt title="Example"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia&resolution=1080p
```

Tags may repeat or use commas: `?resolution=1080p&resolution=720p` equals `?resolution=1080p,720p`.

## Mikan

Swap the host to `anibt.net`; parameters keep working:

```txt title="Compatible form"
https://anibt.net/rss/anime.xml?bangumiId=3921&subgroupid=615
```

New code should use `bgmId` and `groupSlug`.
