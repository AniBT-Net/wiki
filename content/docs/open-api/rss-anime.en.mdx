`/rss/anime.xml` is the most flexible subscription endpoint: combine `bgmId` + `groupSlug` + multiple tags (`resolution` / `language` / `format` / `subtitle` / `episode` / `episodeKey`) in any way to subscribe to a show, a group, or the whole site.

<Callout type="warn">
  At least one of `bgmId` or `groupSlug` is required. Requests with neither are rejected.
</Callout>

## URL

```txt title="URL"
GET https://anibt.net/rss/anime.xml?<query>
```

## Two equivalent ways to repeat a parameter

```txt title="Standard repeated query (recommended)"
?resolution=1080p&resolution=720p
```

```txt title="Comma-separated (also accepted)"
?resolution=1080p,720p
```

## Response

Returns native **RSS 2.0 + BEP 36** XML. Opening an RSS URL in a browser no longer loads AniBT custom XSL/CSS; the browser renders its default XML tree while RSS readers and BT clients keep consuming the standard fields.

## Backend execution

`/rss/anime.xml` is generated by the main Web runtime, not by a Convex RSS query fallback. The Web layer resolves `bgmId` / `groupSlug` through the Typesense `rss_resolvers` collection, then queries the Typesense `releases` collection:

| Provided                | Execution path                              |
| ----------------------- | ------------------------------------------- |
| `bgmId` + `groupSlug`   | Typesense filter constrained by anime and group |
| `bgmId` only            | Typesense filter constrained by anime       |
| `groupSlug` only        | Typesense filter constrained by group       |

Resolution, language, format, subtitle type, and similar tags are pushed into Typesense filters where possible. Display fields such as `episode` / `episodeKey` are post-filtered in a small Web-runtime window. Redis SSR cache defaults to **120 seconds TTL + 60 seconds stale-while-revalidate**; on publish events, the Cloudflare Worker clears the Redis RSS cache and purges CDN. The public RSS freshness target is therefore within 5 minutes, and the normal event path is usually faster.

## Mikan parameter compatibility

Mikan-style parameters can switch host and keep working as-is:

<Tabs items={['Original Mikan link', 'Switch host only', 'Recommended']}>

    ```txt
    https://mikanani.me/RSS/Bangumi?bangumiId=3921&subgroupid=615
    ```
  </Tab>
  <Tab value="Switch host only">
    ```txt
    https://anibt.net/rss/anime.xml?bangumiId=3921&subgroupid=615
    ```
    `bangumiId` and `subgroupid` are accepted as compatibility aliases.
  </Tab>
  <Tab value="Recommended">

    Use the canonical names in new code.
  </Tab>
</Tabs>
