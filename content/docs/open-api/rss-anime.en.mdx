          每个
          `<item>`：`<title>`、`<link>`（`/release/<id>`）、`<guid>`、`<pubDate>`（RFC
          822，`+0800`）、`<enclosure>` 磁力、`<torrent>` infoHash、已绑定时
          `<anibt:bgmId>`。

          `limit` 默认 100，上限 100。速率限制默认 120 次 / 60 秒 / IP。

          浏览器直开返回原生 XML。搜索引擎不抓 `/rss/`。
