主入口之外，AniBT 還提供四個常用端點：兩個 RSS（短鏈 + 全站）、兩個 JSON（季度 + 單番劇）。

本頁的 RSS 端點都返回原生 RSS 2.0 XML。瀏覽器直開 RSS URL 時不載入站點自訂 XSL/CSS，會使用瀏覽器預設 XML 樹展示；RSS 閱讀器和 BT 客戶端繼續按標準欄位消費。

## 字幕組短鏈 `/rss/group/<slug>.xml`

等價於 `/rss/anime.xml?groupSlug=<slug>` 但 URL 更短，便於貼 README / 論壇。

<Callout type="warn">
  路徑必須以 `.xml` 結尾。支援單值 `limit=1..100`，**不支援** Tag 過濾；需要過濾請走 [RSS 主入口](/docs/open-api/rss-anime)。非法 limit 返回應用 400，生產邊緣可能先返回 Cloudflare 403。
</Callout>

```txt title="示例"
https://anibt.net/rss/group/kirara-fantasia.xml
https://anibt.net/rss/group/pre-s.xml
https://anibt.net/rss/group/kitauji-sub.xml
https://anibt.net/rss/group/haruhana.xml
```

條目與 [RSS 主入口](/docs/open-api/rss-anime) 一樣會輸出 AniBT 擴展欄位（含 `<anibt:bgmId>`，有綁定才出現）。

<Callout type="info">
  已知字幕組的日常釋出只重新整理該 owner 的 RSS 變體。字幕組建立、規範 slug 重新命名或刪除時，舊/新完整路徑及其有界 `404` 負快取會一起收斂；任意未知 slug 仍不會被當成可失效的 owner。正常事件鏈路無需等完整 TTL 才反映真實生命週期變更，但客戶端仍應保存重新命名後的最終 URL。
</Callout>

## 全站磁力 `/rss/magnets.xml`

適合瀏覽全站最近釋出。搜尋引擎按 `robots.txt` 不會抓 `/rss/`；下載器訂閱不受影響。

```txt title="基本用法"
https://anibt.net/rss/magnets.xml
https://anibt.net/rss/magnets.xml?limit=100
https://anibt.net/rss/magnets.xml?q=葬送的芙莉蓮
https://anibt.net/rss/magnets.xml?resolution=1080p&language=CHS
```

每個 anime `<item>` 含 `xmlns:anibt` 結構化元資料，其中 **`<anibt:bgmId>`** 為 Bangumi subject id（已綁定則輸出）。與 `/rss/anime.xml`、`/rss/group/*.xml` 欄位一致；`/rss/other/*` 無此欄位。

<Callout type="info">
  無 `q` 的 latest/filter 變體快取 **120 秒**；帶 `q` 的搜尋（包括空結果）快取 **600 秒**；兩者均為 `stale-while-revalidate=60s`。詳見 [HTTP 快取與 304](/docs/open-api/caching)。
</Callout>

<Callout type="warn">
  `q` 與 `search` 是別名，只能提供一個值。搜尋詞會做 NFKC、trim 與空白折疊，UTF-8 最多 160 bytes；重複、空、控制字元或超長輸入返回 `400 + no-store`。僅改變原始 query 參數對順序時直接返回同一規範 `200`；預設值、相容別名或其它位元組級規範化仍返回可快取一天的 `308`。新的高基數 MISS 超出預算時返回 `429 + Retry-After`。
</Callout>

## 季度番劇 `/api/seasons/anime`

第三方追番站 / 看板 / 編輯器輔助使用。**返回當季已上架番劇 + 可選季度列表。**

### 請求

```txt title="多種呼叫方式"
GET https://anibt.net/api/seasons/anime
GET https://anibt.net/api/seasons/anime?season=2026春
GET https://anibt.net/api/seasons/anime?season=2026-SPRING   # 也接受英文形式
GET https://anibt.net/api/seasons/anime?bgmId=543360         # 精確返回單個番劇
GET https://anibt.net/api/seasons/anime?query=夏日口袋        # 按番劇標題搜尋
GET https://anibt.net/api/seasons/anime?season=2026夏&query=Summer%20Pockets
```

### 快取與限流

| 專案             | 值                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 速率限制         | **30 次 / 60 秒 / IP**（與 `/api/anime/groups` 共用視窗）                                |
| `Cache-Control`  | `public, max-age=0, s-maxage=600, stale-while-revalidate=86400, stale-if-error=86400`（**瀏覽器重新驗證 + CDN 10 分鐘新鮮 + 24h SWR/SIE**） |
| 條件請求         | `If-None-Match`（opaque ETag 形如 `W/"anibt-sha256-{64 lowercase hex}"`）；目前省略 `Last-Modified` |

<Callout type="info">
  `ts`、最終 JSON bytes 與 ETag 現在屬於同一個快取 representation：cache hit 時三者一起穩定，重新整理時一起推進。匹配 ETag 的 `304` 因此表示目前正文 bytes 未變化。
</Callout>

```bash title="條件請求"
curl 'https://anibt.net/api/seasons/anime'
curl 'https://anibt.net/api/seasons/anime?season=2026春'
curl 'https://anibt.net/api/seasons/anime?bgmId=543360'
curl 'https://anibt.net/api/seasons/anime?query=夏日口袋'

ETAG=$(curl -sSI 'https://anibt.net/api/seasons/anime' | grep -i ^etag: | awk '{print $2}' | tr -d '\r')
curl -i 'https://anibt.net/api/seasons/anime' -H "If-None-Match: $ETAG"
# → HTTP/2 304；目前快取 representation 的正文 bytes 未變化
```

## 單番劇字幕組 `/api/anime/groups`

> 「這部番都誰在做？」一個 `bgmId` 即可拿到全部正在釋出的字幕組、最近更新時間，以及**最近 30 條釋出**。

**專為給 `/rss/anime.xml` 拼 `groupSlug` 提供候選**，也方便客戶端直接做"番劇詳情頁 / 資源列表"。

### 請求

```txt
GET https://anibt.net/api/anime/groups?bgmId=543360
```

<TypeTable
  type={{
    'bgmId': {
      description: 'Bangumi ID（正整數），例如 543360。',
      type: 'integer',
    },
  }}
/>

### 響應（節選）

```jsonc title="200 OK"
{
  "ok": true,
  "ts": 1776841967132,
  "data": {
    "bgmId": 543360,
    "animeId": "nh73r0ernee7s0afv9s82f763983gcz7",
    "title": { /* primary / chinese / romaji / english / japanese */ },
    "groups": [
      {
        "groupId": "org_aagmgM9i0ZyR",
        "slug": "kitauji-sub",
        "name": "北宇治字幕組",
        "status": "ACTIVE",
        "lastUpdatedAt": 1776624843260,
        "items": [
          {
            "releaseId": "rel_fItEHE7r1gR1",
            "title": "[北宇治字幕組] 上伊那牡丹，酒醉身姿似百合 [02][WebRip][HEVC_AAC][繁日內嵌]",
            "magnet": "magnet:?xt=urn:btih:282e2b…",
            "episodeKey": "2",
            "resolution": "1080p",
            "language": ["CHT", "JP"],
            "subtitle": "EMBEDDED",
            "publishedAt": 1776624843260
          }
          /* … 最多 30 條，按 publishedAt desc … */
        ]
      }
      /* … 其他字幕組 … */
    ],
    "total": 4
  }
}
```

### 欄位

- `ts` 是快取 representation 的 materialization time；同一快取值中保持穩定，並與正文一起進入 exact-body ETag。
- `groups` 列表按 `lastUpdatedAt` 倒序（最近發過的排前面）。
- `items`：該字幕組對該番劇最近釋出的資源，**最多 30 條**，按 `publishedAt` desc。可直接渲染"番劇 × 字幕組"維度的資源面板，避免單獨拉 RSS。
  - `magnet` 可能為 `null`（僅有種子檔案、未生成磁力時）。
  - `episodeKey` 是穩定的集數鍵（如 `"01"`、`"SP01"`），便於客戶端排序 / 聚合。
  - `language`：`("CHS" | "CHT" | "JP" | "EN" | "KO" | "ES" | "PT" | "FR" | "DE" | "IT" | "RU" | "AR" | "HI" | "ID" | "MS" | "TH" | "VI" | "TL" | "TR" | "PL" | "UK")[]`。
  - `subtitle`：`"EMBEDDED" | "EXTERNAL" | "BUILT_IN" | "NONE"`（內嵌 / 外掛 / 內封 / 無）。
- `slug` 與 [`/api/subtitle-groups`](/docs/open-api/subtitle-groups) 完全一致，可直接餵給 `/rss/anime.xml?groupSlug=…`。
- 如果該 `bgmId` 未上架或被隱藏，返回 `404 ANIME_NOT_FOUND`。

### 典型用法 — 給追番器拼 RSS

```bash title="兩步拼出 RSS"
# Step 1: 知道 bgmId，拉它的字幕組列表
curl -s 'https://anibt.net/api/anime/groups?bgmId=543360' \
  | jq -r '.data.groups[].slug'
# kitauji-sub
# kirara-fantasia
# pre-s
# haruhana

# Step 2: 拼 RSS（多個字幕組、CHS+1080p）
curl 'https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kitauji-sub,kirara-fantasia,pre-s,haruhana&language=CHS&resolution=1080p&limit=50'
```

### 快取與限流

| 專案             | 值                                                                              |
| ---------------- | ------------------------------------------------------------------------------- |
| 速率限制         | **30 次 / 60 秒 / IP**（與 `/api/seasons/anime` 共用視窗）                        |
| `Cache-Control`  | `public, max-age=0, s-maxage=300, stale-while-revalidate=3600, stale-if-error=3600`（**瀏覽器重新驗證 + CDN 5 分鐘新鮮 + 1h SWR/SIE**） |
| 條件請求         | `If-None-Match`（`W/"anibt-sha256-{64 lowercase hex}"`）；目前省略 `Last-Modified` |

<Callout type="info">
  `ts`、groups/items 正文與 ETag 由同一個快取 representation 生成；任意正文 byte 變化都會推進 ETag。輪詢頻率仍建議不要短於 5 分鐘。
</Callout>
