## 字幕組短鏈

<ApiEndpoint method="GET" path="/rss/group/<slug>.xml" auth="公開">
等價 `/rss/anime.xml?groupSlug=<slug>`。不支援 Tag 過濾。
</ApiEndpoint>

路徑必須以 `.xml` 結尾。未知 slug 回傳 `404`。支援 `limit=1..100`。非法 `limit` 回傳應用 `400`，生產邊緣可能先 `403`。

```txt title="示例"
https://anibt.net/rss/group/kirara-fantasia.xml
```

## 全站磁力

<ApiEndpoint method="GET" path="/rss/magnets.xml" auth="公開">
全站最近釋出。已綁定的 anime 條目帶 `<anibt:bgmId>`。
</ApiEndpoint>

```txt title="示例"
https://anibt.net/rss/magnets.xml
https://anibt.net/rss/magnets.xml?q=葬送的芙莉莲
https://anibt.net/rss/magnets.xml?resolution=1080p&language=CHS
```

`q` 與 `search` 只能提供一個值。空、控制字元或超長回傳 `400`。

## 季度番劇

<ApiEndpoint method="GET" path="/api/seasons/anime" auth="公開">
當季已上架番劇。`bgmId` 優先於 `season`，且不能與 `query` 同時使用。
</ApiEndpoint>

```txt title="示例"
https://anibt.net/api/seasons/anime
https://anibt.net/api/seasons/anime?season=2026春
https://anibt.net/api/seasons/anime?bgmId=543360
https://anibt.net/api/seasons/anime?query=夏日口袋
```

`weekday`：0=週日 … 6=週六，按 Asia/Shanghai；`null` 為未排播。`rating` 為 0–100。

## 單番劇字幕組

<ApiEndpoint method="GET" path="/api/anime/groups" auth="公開">
某 `bgmId` 正在釋出的字幕組，以及每組最近 30 條資源。
</ApiEndpoint>

```txt title="示例"
https://anibt.net/api/anime/groups?bgmId=543360
```

只有公共讀模型中的 Anime 投影完整且為 live 時才回傳 `200`。明確的
`ANIME_NOT_FOUND` 結果仍為 `404`；公共投影缺失或不一致、候選資源超過
10,000 條、表示超過 2 MiB，或讀取暫時不可用時回傳 `503 SEARCH_UNAVAILABLE`，
並帶 `Retry-After` 與 `Cache-Control: no-store`，不會偽裝成 404 或 200 空結果。
成功回應支援 `ETag`、`HEAD` 與 `304`；瀏覽器 `max-age=0`，邊緣可按介面契約快取。
`magnet` 可能為 `null`。`slug` 可直接用於 `/rss/anime.xml?groupSlug=…`。
