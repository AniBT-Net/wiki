When integrating with the AniBT Open API or configuring automated RSS downloaders, use this troubleshooting guide to resolve common issues.

<Callout type="info">
  **Debugging Tip**: All non-2xx API error responses include a `requestId` field (also mirrored in the `X-Request-ID` response header). Always supply this ID when contacting support for instant log tracing.
</Callout>

## Common Debugging Commands

Before debugging client-side configurations, run these isolated `curl` commands to inspect direct server responses:

<Tabs items={['Inspect RSS Output', 'Query Fansub Slugs', 'Check API Key Identity']}>
  <Tab value="Inspect RSS Output">
    Directly view returned episode titles and publication timestamps:

    ```bash title="Fast RSS summary inspection"
    curl -s 'https://anibt.net/rss/anime.xml?bgmId=543360&limit=3' \
      | grep -E '<title>|<pubDate>|<enclosure'
    ```
  </Tab>

  <Tab value="Query Fansub Slugs">
    List all active fansub group names and permanent `slug` identifiers:

    ```bash title="List fansub names and slugs"
    curl -s https://anibt.net/api/subtitle-groups \
      | jq '.data[] | {name, slug}'
    ```
  </Tab>

  <Tab value="Check API Key Identity">
    Verify the group name, slug, and granted permission scopes bound to your API key:

    ```bash title="Verify API Key identity"
    curl -s https://anibt.net/api/subtitle-groups/me \
      -H "Authorization: Bearer <YOUR_API_KEY>" \
      | jq .
    ```
  </Tab>
</Tabs>
