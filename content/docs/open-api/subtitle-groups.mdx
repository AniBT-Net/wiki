---
title: 字幕组目录
description: GET /api/subtitle-groups —— 公开字幕组列表。拼 RSS 前先拉一份做 name → slug。
---

返回可见字幕组的 `slug`、展示名与统计。启动时调一次，本地缓存后再拼 RSS。

<ApiEndpoint method="GET" path="/api/subtitle-groups" auth="公开">
无需鉴权。
</ApiEndpoint>

<Callout type="info">
  数据很少变。带 `If-None-Match` 时多数会 304。
</Callout>

第三方用 `slug`，不要硬编码 `organizationId`。完整字段见 [接口参考](/docs/open-api/reference)。

```http title="请求"
GET https://anibt.net/api/subtitle-groups
Accept: application/json
```

```bash title="挑出 slug"
curl -s https://anibt.net/api/subtitle-groups \
  | jq '.data[] | {name, slug}'
```
