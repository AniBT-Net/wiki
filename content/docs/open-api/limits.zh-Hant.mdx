---
title: 限流與上限
description: 各端點的 limit 與速率視窗。
---

數字與狀態碼是公開契約。超限回傳 `429`，按 `Retry-After` 退避。

## 各端點

| 端點 | `limit` 預設 | `limit` 上限 | 速率限制（預設） |
| --- | --- | --- | --- |
| `/rss/anime.xml` | **100** | **100** | 120 次 / 60 秒 / IP |
| `/rss/group/<slug>.xml` | 100 | **100** | 120 次 / 60 秒 / IP |
| `/rss/magnets.xml` | 100 | **100** | 120 次 / 60 秒 / IP |
| `/rss/other/<category>.xml` | 100 | **100** | 120 次 / 60 秒 / IP |
| `/api/bgm/search` | 5 | **25** | 60 次 / 60 秒 / IP |
| `/api/animes/search` | 24 | **50** | 120 次 / 60 秒 / IP |
| `/api/animes/torrent-match` | 10 | **50** | 180 次 / 60 秒 / IP |
| `/api/anime/lookup` | — | — | 60 次 / 60 秒 / IP |
| `/api/mikan/group-lookup` | — | — | 60 次 / 60 秒 / IP |
| `/api/subtitle-groups` | — | 全量回傳 | 60 次 / 60 秒 / IP |
| `/api/seasons/anime` | — | — | 30 次 / 60 秒 / IP |
| `/api/anime/groups` | — | — | 30 次 / 60 秒 / IP |
| `DELETE /api/releases/{releaseId}` | — | — | 30 次 / 60 秒 / API Key |
| `GET /api/releases/{releaseId}/deletion` | — | — | 120 次 / 60 秒 / API Key |

刪除另有認證前防濫用視窗。`pending` 回執裡的 `Retry-After` 是狀態輪詢建議；真正超限是 `429`。

<Callout type="warn">
  公開 RSS 的 `limit` 只接受單個 `1..100` 整數。非法值應用回傳 `400`，生產邊緣可能先 `403`。預設就是 100，不要傳 `limit=100`，否則可能 `308`。
</Callout>

`/rss/magnets.xml` 與 `/rss/other/*` 的 `q` / `search` 只能一個值，最多 160 UTF-8 bytes。新關鍵詞搜尋：每主題 120 次 / 10 分鐘、1000 次 / 24 小時，超限 `429`。穩定查詢不計入。

公開搜尋最多 100 頁。`/magnets?page=` 超出重新導向到第 100 頁。`/api/animes/search` 的 `cursor` 只接受 `ts_page:<頁碼>`。

過濾過嚴時條數可能少於 `limit`。

## 客戶端

- 省略 `limit` 即 100 條。
- 帶 `If-None-Match`。
- 間隔 ≥ 5 分鐘。
- 不要對同一 URL 並發。
- 不要間隔 &lt; 1 分鐘。
