---
title: Subtitle group catalogue
description: GET /api/subtitle-groups — public group list. Cache name → slug before building RSS URLs.
---

Returns `slug`, display name, and stats for visible groups. Call once at startup, cache locally, then build RSS URLs.

<ApiEndpoint method="GET" path="/api/subtitle-groups" auth="public">
No auth.
</ApiEndpoint>

<Callout type="info">
  The catalogue rarely changes. Most polls with `If-None-Match` return 304.
</Callout>

Third parties use `slug`. Do not hard-code `organizationId`. Full fields: [API reference](/docs/open-api/reference).

```http title="Request"
GET https://anibt.net/api/subtitle-groups
Accept: application/json
```

```bash title="Pick slugs"
curl -s https://anibt.net/api/subtitle-groups \
  | jq '.data[] | {name, slug}'
```
