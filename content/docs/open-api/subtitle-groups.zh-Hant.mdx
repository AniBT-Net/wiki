---
title: 字幕組目錄
description: GET /api/subtitle-groups —— 公開字幕組列表。拼 RSS 前先拉一份做 name → slug。
---

回傳可見字幕組的 `slug`、展示名與統計。啟動時調一次，本地快取後再拼 RSS。

<ApiEndpoint method="GET" path="/api/subtitle-groups" auth="公開">
無需鑑權。
</ApiEndpoint>

<Callout type="info">
  資料很少變。帶 `If-None-Match` 時多數會 304。
</Callout>

第三方用 `slug`，不要硬編碼 `organizationId`。完整欄位見 [API 參考](/docs/open-api/reference)。

```http title="請求"
GET https://anibt.net/api/subtitle-groups
Accept: application/json
```

```bash title="挑出 slug"
curl -s https://anibt.net/api/subtitle-groups \
  | jq '.data[] | {name, slug}'
```
