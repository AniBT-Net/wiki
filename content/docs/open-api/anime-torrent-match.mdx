title: 种子标题匹配番剧
description: POST /api/animes/torrent-match —— 解析发布标题与种子内部名，并用可解释的多语言证据匹配站内番剧。
---

`/api/animes/torrent-match` 默认是公开、无需鉴权的番剧识别端点；只有请求组内
scoped binding 时需要登录。Canonical 接口是
`POST` v3：它保留原始发布标题与 torrent internal name，先生成结构化 AST，再执行
独立的 exact / strict recall / fuzzy recall 分支，最后返回可机器处理的自动、人工、
非番剧、unsupported 或不可用决定。

<Callout type="info">
  生产运行时只读取 AniBT 已入库的数据和内部 Typesense 索引，不抓取 Anime Garden、Nyaa、TMDB、TVDB 或其他外站，也不使用外站 `subjectId`。Anime Garden 只用于离线测试语料。
</Callout>

## POST v3 请求

```http title="HTTP"
POST https://anibt.net/api/animes/torrent-match
Content-Type: application/json
```

```bash title="发布标题 + torrent 内部名"
curl -sS 'https://anibt.net/api/animes/torrent-match' \
  -H 'Content-Type: application/json' \
  --data @- <<'JSON'
{
  "rawTitle": "[LoliHouse] 孤独摇滚！ / Bocchi the Rock! - 01 [WebRip 1080p HEVC-10bit AAC][简繁内封字幕]",
  "torrentName": "[LoliHouse] Bocchi the Rock! [01][1080p].mkv",
  "publishedAt": 1664640000000,
  "limit": 10
}
JSON
```

## 匹配与自动授权边界

- 发布标题与 torrent name 分开解析；相同检索只执行一次，但两个输入仍分别参与一致性判断。
- 中文、繁中、日文、罗马字、英文、紧凑多语拼接、全角斜线、反斜线和 script boundary 都可形成标题 hypothesis。
- 自动授权来源仅允许 BGM / bgm.tv、bangumi-data、本站人工全局 alias，以及当前已鉴权字幕组内唯一 active scoped binding；弱站点线索和派生 stem 只能支持召回或消歧。
- TMDB / TVDB、外部数字 ID、官网 slug、fuzzy、typo、prefix、infix、split/join 和文本分数都不能独立授权自动发布。
- Season / Cour / Part / Sequence / Format、显式年份、开播窗口和已知 TV 集数会在候选阶段执行 veto。显式 Season 使用季内集数；没有 Season 时，只有同一作品族、时间 cohort 和累计集数窗口均唯一，才会用 `EP25` 等绝对集数安全提升续作。
- 类似 `[Title][24][1080p]` 的 bracket 结构会把 `[24]` 识别为集数；`[Title][1080p][24][AAC]` 中的 `[24]` 仍按帧率元数据处理，避免全局误解数字标题或 FPS。
- `2024年版`、`(2024)` 等明确版本年份只有在目标候选自身首播年精确等于 2024 时，才能参与自动结构淘汰；上传年份或模糊年份不能代替该证据。
- 当上季官方总集数包含一个 SP、字幕组连续编号只计算正片时，matcher 可在 family 完整、后季排名第一、双方 recall-only、发布时间明显支持后季且目标唯一的前提下，把跨季窗口安全前移一集。单集 `24` 与精确整季范围 `24-46` 使用同一修正窗口；真正多季合集仍为 `unsupported`。
- 任一 exact / recall / 全局候选 overflow、search cutoff、lookup 二次复核失败、hydrate 缺失、generation / projection 不一致都会令 `candidateSetComplete=false`，禁止 `auto`。
- 独立 PV / CM、MAD / AMV、游戏视频、演唱会、真人剧、音乐专辑、舞台/朗读剧、公告、壁纸或字体包可返回 `non_anime`；OVA / OAD / ONA / SP / MOVIE 仍属于动画内容。
- 多番剧、多季或 `S1+S2+OVA` 合集返回 `unsupported`，不会强行挑一个 subject。

<Callout type="info">
  当前生产 generation 为 `match_v3_20260716_2112`：8,621 个候选番剧、223,778 条别名、24 个 scoped bindings。固定离线语料中，2024–2026 番剧自动匹配为 9,091 / 9,781（92.9455%）；排除后续单独处理合集的 VCB 后为 8,744 / 9,339（93.6289%）。这是自动决策覆盖率，不是外部真值准确率。
</Callout>

## 决策种类

| `decision.kind` | 调用方行为 |
| --------------- | ---------- |
| `auto` | 可以采用 `decision.animeId`；该 ID 也必须存在于 `candidates`。 |
| `manual` | 展示 `candidates` 给用户确认，不得自动发布到某个番剧。 |
| `none` | 没有候选，进入手动搜索或待匹配。 |
| `non_anime` | 高置信非番剧内容，不进入番剧发布流程。 |
| `unsupported` | 单番剧发布契约无法安全表达，例如多标题或多季合集。 |
| `unavailable` | 必要检索或投影不可用；fail closed，稍后重试。 |

常见 `decision.reason`：

- `single_branch_identity_unique` / `multi_branch_identity_unique`：可信 identity 分支唯一且一致。
- `scoped_binding_active`：当前字幕组的项目 binding 已激活，且仍通过候选投影、结构 veto、冲突与完整性检查。
- `scoped_binding_conflict`：组内 binding 与当前强标题证据冲突，保留人工确认。
- `projection_gap`：一个强语言分支缺少可信投影；有候选也保留人工确认。
- `input_title_conflict` / `branch_conflict`：发布标题、torrent name 或多语言分支指向不同番剧。
- `modifier_conflict` / `candidate_veto`：季度、Part、格式、年份、时间或集数冲突。
- `search_incomplete`：候选集不完整，任何 overflow / cutoff / generation mismatch 都会走这里。
- `low_evidence` / `no_candidates` / `search_unavailable`：证据不足、无候选或检索不可用。

<Callout type="warn">
  `candidates` 是有界证据列表，不是自动授权字段。集数、季度与 veto 可能让最终
  `decision.animeId` 不等于原始分数最高的 `candidates[0]`；调用方应在候选中找到与
  `decision.animeId` 相同的条目。高 `matchScore`、Typesense `textMatch`、strict/fuzzy
  recall 或单一标题命中都不能代替 `decision.kind="auto"`。
</Callout>

## 限流和错误

| 项目 | POST v3 |
| ---- | ------- |
| 请求体 | JSON，最大 32 KiB；超出返回 `413 PAYLOAD_TOO_LARGE` |
| Schema 错误 | `422 VALIDATION_ERROR` |
| `groupId` 无会话或非成员 | `403 FORBIDDEN` |
| 非法 JSON | `400 INVALID_JSON` |
| 速率限制 | 默认 180 次 / 60 秒 / IP；返回 `429 RATE_LIMIT_EXCEEDED` |
| 缓存 | `Cache-Control: no-store`，同时禁止 CDN / Cloudflare 缓存 |
| 方法 | 只允许 `POST, OPTIONS`；GET 返回 JSON `405 METHOD_NOT_ALLOWED`，`Allow: POST, OPTIONS` |
| CORS | `POST, OPTIONS` |

发布端不必先单独调用本接口：未提供显式番剧 ID 时，
[`/api/releases/publish`](/docs/open-api/releases-publish) 会在 Web 服务端直接运行同一
matcher。只有 `auto` 会直接绑定；`manual / none / unavailable / unsupported / non_anime`
都会保留待匹配或由调用方处理。
