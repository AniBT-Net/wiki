公开识别端点。传入 `groupId` 时必须登录且属于该组。

<ApiEndpoint method="POST" path="/api/animes/torrent-match" auth="公开">
GET 返回 `405 METHOD_NOT_ALLOWED`。
</ApiEndpoint>

<Callout type="warn">
  不要把调用方伪造的匹配结果传给发布接口。未带番剧 ID 时，发布接口会在服务端跑同一 matcher。
</Callout>

## 请求

<TypeTable
  type={{
    rawTitle: { type: 'string', required: true, description: '发布标题原文，1–1000 字符' },
    torrentName: { type: 'string', description: 'torrent 内部名，1–1000 字符。与 rawTitle 指向不同番剧时禁止自动绑定' },
    publishedAt: { type: 'integer', description: '发布时间，毫秒' },
    groupId: { type: 'string', description: '字幕组 ID，最多 200 字符。传入则需会话且属于该组，否则 403' },
    limit: { type: 'integer', default: '10', description: '候选数，上限 50。缩小 limit 不会放宽自动绑定门槛' },
  }}
/>

公开路由 `diagnostics=true` 返回 `403`。请求体上限 32 KiB。不缓存。

完整字段见 [接口参考](/docs/open-api/reference)。

```bash title="发布标题 + torrent 内部名"
curl -sS 'https://anibt.net/api/animes/torrent-match' \
  -H 'Content-Type: application/json' \
  --data @- <<'JSON'
{
  "rawTitle": "[LoliHouse] 孤独摇滚！ / Bocchi the Rock! - 01 [WebRip 1080p HEVC-10bit AAC][简繁内封字幕]",
  "torrentName": "[LoliHouse] Bocchi the Rock! [01][1080p].mkv",
  "publishedAt": 1664640000000,
  "limit": 10
}
JSON
```

## `decision.kind`

| `decision.kind` | 调用方行为 |
| --- | --- |
| `auto` | 可用 `decision.animeId`，且必须出现在 `candidates` |
| `manual` | 展示候选，不得自动绑定 |
| `none` | 无候选 |
| `non_anime` | 非番剧 |
| `unsupported` | 合集等无法用单番剧表达 |
| `unavailable` | 检索不可用，稍后重试 |

`candidates` 不是授权字段。高 `matchScore` 不能代替 `decision.kind="auto"`。

| HTTP | 处理 |
| --- | --- |
| 400 | 非法 JSON |
| 403 | `groupId` 无会话或非成员；或公开路由传了 `diagnostics=true` |
| 413 | 请求体超过 32 KiB |
| 422 | 校验未通过 |
| 429 | 180 次 / 60 秒 / IP，按 `Retry-After` 退避 |
