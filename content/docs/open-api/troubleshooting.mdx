在接入 AniBT 开放 API 或配置 RSS 自动化脚本时，如遇到异常响应或数据不符合预期，可参考本指南快速定位排查。

<Callout type="info">
  **快速定位秘诀**：所有非 2xx 的 API 响应均会附带 `requestId` 字段（响应头中亦有 `X-Request-ID`）。向平台管理员报告问题时，附带该 ID 能在系统日志中秒级定位原因。
</Callout>

## 常用排错调试命令

在排查问题时，建议先使用 `curl` 隔离排查，排除客户端软件自身的配置干扰：

<Tabs items={['检查 RSS 响应', '查询字幕组 Slug', '核验 API Key 身份']}>
  <Tab value="检查 RSS 响应">
    直接查看返回的最新番剧标题与发布时间戳：

    ```bash title="快速抓取 RSS 内容摘要"
    curl -s 'https://anibt.net/rss/anime.xml?bgmId=543360&limit=3' \
      | grep -E '<title>|<pubDate>|<enclosure'
    ```
  </Tab>

  <Tab value="查询字幕组 Slug">
    获取全站字幕组的标准 `slug` 标识列表：

    ```bash title="列出字幕组名称与对应 slug"
    curl -s https://anibt.net/api/subtitle-groups \
      | jq '.data[] | {name, slug}'
    ```
  </Tab>

  <Tab value="核验 API Key 身份">
    自检当前 API Key 绑定的字幕组名称、所属 slug 与具备的权限 scopes：

    ```bash title="自检 API Key 身份"
    curl -s https://anibt.net/api/subtitle-groups/me \
      -H "Authorization: Bearer <YOUR_API_KEY>" \
      | jq .
    ```
  </Tab>
</Tabs>
