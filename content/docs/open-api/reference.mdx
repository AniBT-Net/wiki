<Callout type="warn">
  **生产 Base URL**：`https://anibt.net`。请始终使用文档和 OpenAPI 规范中列出的路径。字幕组 API Key 拥有写操作与删除权限，请妥善保管，切勿硬编码提交至公开仓库或客户端代码中。
</Callout>

## 统一错误响应结构

所有写操作与非 2xx 的 JSON 响应均遵循统一的错误结构，便于程序解析与重试判定：

```json title="标准 JSON 错误格式"
{
  "ok": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Torrent file is missing in multipart request",
    "reason": "TORRENT_REQUIRED",
    "retryable": false,
    "requestId": "req_01j7abc123456789"
  }
}
```

- **`code`**：粗粒度错误类别（如 `BAD_REQUEST`、`UNAUTHORIZED`、`FORBIDDEN`、`VALIDATION_ERROR`、`RATE_LIMITED`）。
- **`reason`**：机器可读的精确错误原因（如 `EMPTY_RELEASE_CONTENT`、`TORRENT_REQUIRED`）。
- **`retryable`**：布尔值，指示当前错误是否可通过延时重试恢复（例如限流为 `true`，参数错误为 `false`）。
- **`requestId`**：当前请求的全局唯一追踪标识，同时会通过响应头 `X-Request-ID` 返回。在向管理员反馈问题时请务必附带此 ID。
