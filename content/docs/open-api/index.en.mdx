The production base URL is https://anibt.net. Group API keys, personal RSS tokens, and login sessions serve different endpoints and are not interchangeable. Parse each endpoint’s envelope, nullable fields, and error format as documented.

The machine-readable contract is [/openapi.yaml](/openapi.yaml). Endpoint pages show request fields and response examples. Title matching is anonymous unless groupId is supplied, which requires a session and group membership.
