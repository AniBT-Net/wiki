AniBT exposes **RSS** (subscribe) and **JSON** (programmatic reads). Public reads are anonymous, follow each endpoint's cache contract, and support **HTTP 304**. Publish, delete, and `/me` require a subtitle-group API Key and are not cached.

<Callout type="warn">
  The production base URL is `https://anibt.net`. Use only the main-site paths listed in these docs.
</Callout>

Auth and error codes are in [API conventions](/docs/open-api/reference). Each endpoint page has Try-it. Machine-readable spec: [openapi.yaml](/openapi.yaml).

qBittorrent / Sonarr / FlexGet need no extra RSS setup. Caching, rate limits, and troubleshooting stay on their own pages.

## Stability

- Paths and query parameters do not change incompatibly; new parameters are additive.
- Keep `slug` stable once published.
- Internal primary keys are not part of the public contract; always use `slug`.
