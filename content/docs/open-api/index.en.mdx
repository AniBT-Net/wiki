AniBT exposes **RSS** (subscribe) and **JSON** (programmatic reads). Public reads are anonymous and support **HTTP 304** per each route’s cache contract. Publish, delete, and `/me` require a group API key and are not cached.

<Callout type="warn">
  Production base URL is `https://anibt.net`. Use only the main-site paths listed in the docs.
</Callout>

Methods, parameters, and responses: [API reference](/docs/open-api/reference).

qBittorrent / Sonarr / FlexGet need no extra RSS setup. Caching, limits, and troubleshooting stay on their own pages.

## Stability

- Paths and query parameters will not change incompatibly; new parameters are additive.
- Published `slug` values are kept stable when possible.
- Internal primary keys are not part of the public contract; always use `slug`.
