          其他类发布必须指定 category，不关联番剧。

          multipart 必须上传 torrent，title 省略时使用种子内部名；JSON 必须提供 title 和属于当前字幕组的
          torrentStorageId。

          成功发布返回 { ok: true, result: { releaseId, revision, torrentObjectId? }
          }。发布回执不包含 groupId、groupName、groupSlug、animeId 或 fileSize；发布前用 GET
          同一路径核验身份。

          notes 最多 50000 字符。JSON 请求上限默认 1 MiB，multipart 默认 8 MiB。

          Nyaa 需要字幕组白名单和有效分类，种子必须包含 http://nyaa.tracker.wf:7777/announce。Nyaa
          代发应使用 multipart，确保从上传种子提取 tracker。

          Nyaa 的结构化 sitePublish.nyaa 仅用于 JSON；multipart 使用
          nyaa、nyaaCategory、nyaaComplete 等独立字段。

          200 表示本站发布已写入，不保证外站同步或下游读取已经完成。

          当前发布请求达到限额时返回 500 UPLOAD_FAILED；应停止高频提交并退避，不能把未知错误当作成功。
