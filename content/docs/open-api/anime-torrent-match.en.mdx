---
title: Match a torrent title to anime
description: POST /api/animes/torrent-match — parse a title and return auto / manual (and other) decisions.
---

Public matcher. Passing `groupId` requires a login session in that group.

<ApiEndpoint method="POST" path="/api/animes/torrent-match" auth="public">
GET returns `405 METHOD_NOT_ALLOWED`.
</ApiEndpoint>

<Callout type="warn">
  Do not send a caller-forged match to the publish API. If no anime ID is provided, publish runs the same matcher on the server.
</Callout>

## Request

<TypeTable
  type={{
    rawTitle: { type: 'string', required: true, description: 'Release title as-is, 1–1000 characters' },
    torrentName: { type: 'string', description: 'Torrent internal name, 1–1000 characters. Auto-bind is forbidden if it points at a different anime than rawTitle' },
    publishedAt: { type: 'integer', description: 'Publish time, milliseconds' },
    groupId: { type: 'string', description: 'Group ID, max 200 characters. Requires a session in that group, else 403' },
    limit: { type: 'integer', default: '10', description: 'Candidate count, max 50. A smaller limit does not lower the auto-bind bar' },
  }}
/>

Public routes return `403` for `diagnostics=true`. Body max 32 KiB. Not cached.

Full fields: [API reference](/docs/open-api/reference).

```bash title="Release title + torrent internal name"
curl -sS 'https://anibt.net/api/animes/torrent-match' \
  -H 'Content-Type: application/json' \
  --data @- <<'JSON'
{
  "rawTitle": "[LoliHouse] 孤独摇滚！ / Bocchi the Rock! - 01 [WebRip 1080p HEVC-10bit AAC][简繁内封字幕]",
  "torrentName": "[LoliHouse] Bocchi the Rock! [01][1080p].mkv",
  "publishedAt": 1664640000000,
  "limit": 10
}
JSON
```

## `decision.kind`

| `decision.kind` | Caller action |
| --- | --- |
| `auto` | Use `decision.animeId`; it must also appear in `candidates` |
| `manual` | Show candidates; do not auto-bind |
| `none` | No candidates |
| `non_anime` | Not anime |
| `unsupported` | Batch / multi-title that a single anime cannot express |
| `unavailable` | Search unavailable; retry later |

`candidates` is not an authorization field. A high `matchScore` does not replace `decision.kind="auto"`.

| HTTP | What to do |
| --- | --- |
| 400 | Invalid JSON |
| 403 | `groupId` without a session or membership; or `diagnostics=true` on the public route |
| 413 | Body over 32 KiB |
| 422 | Validation failed |
| 429 | 180 req / 60 s / IP; back off with `Retry-After` |
