---
title: Match a torrent title to anime
description: GET /api/animes/torrent-match — match Chinese, Japanese, English, romaji, and season-aware torrent titles to AniBT anime.
---

`/api/animes/torrent-match` is a public, unauthenticated anime-identification endpoint. Publish UIs and subtitle-group automation can use it to turn a parsed torrent title into ranked AniBT anime candidates and decide whether automatic binding is authorized.

<Callout type="info">
  Production reads only AniBT's imported Bangumi Data, bgm.tv source snapshots, anime master data, and `animeAliases`. It performs no runtime crawl and calls no OpenCC or transliteration service.
</Callout>

## Request

```txt title="URL"
GET https://anibt.net/api/animes/torrent-match?query=<title>&seasonYear=<year>&limit=<n>
```

```bash title="Multilingual title"
curl -sS -G 'https://anibt.net/api/animes/torrent-match' \
  --data-urlencode 'query=本好きの下剋上 / Ascendance of a Bookworm S04' \
  --data 'limit=10'
```

## Matching data and safety boundaries

- Primary titles, Bangumi Data / bgm.tv titles, and trusted site evidence may
  establish anime-level Season / Cour / Part / Sequence / Format consensus.
- Imported `animeAliases`, including TVDB / TMDB-derived aliases, still participate
  in recall, exact-collision detection, and global disambiguation. They do not create
  anime-level modifier consensus by themselves, preventing series-level aliases from
  making older seasons, specials, or sequels inherit the wrong season marker.
- Paired `～subtitle～` text in canonical titles is folded only through a bounded,
  structured stem rule. This supports forms such as `无职转生 3期` without stripping
  ordinary movie subtitles or unqualified titles down to a bare franchise name.
- Multilingual title lists retain the full query and split only on whitespace-surrounded
  ` / ` or ` ／ `. Intrinsic slashes such as `Fate/stay night` are preserved. Long exact
  title lists are sent in a request body and are not constrained by Typesense's
  4,000-character GET query-string limit.

## Decision fields

<TypeTable
  type={{
    'shouldAutoSelect': {
      description: 'The only authorization signal for automatic binding. A first-ranked candidate or high matchScore is not enough.',
      type: 'boolean',
    },
    'bestMatch / bestMatchId': {
      description: 'Authorized anime when shouldAutoSelect is true; null when manual confirmation is required.',
      type: 'object | null / string | null',
    },
    'confidence': {
      description: 'high / medium / low / none. Intended for UI presentation; it does not replace shouldAutoSelect.',
      type: 'enum',
    },
    'decisionReason': {
      description: 'Machine-readable final decision reason.',
      type: 'enum',
    },
    'exactAnimeCount': {
      description: 'Distinct animeIds participating in the final exact / structured gate. -1 means exact retrieval exceeded the safe bound and requires manual review.',
      type: 'integer',
    },
    'vetoCategory': {
      description: 'Machine-readable auto-selection veto; null when there is no veto.',
      type: 'string | null',
    },
    'evidenceSummary': {
      description: 'Bounded per-candidate explanation: source, alias, match class, and structured modifiers. The endpoint never returns the complete alias set.',
      type: 'object',
    },
  }}
/>

| `decisionReason` | Meaning |
| ---------------- | ------- |
| `exact_unique` | One globally unique authorizing exact match. |
| `structured_unique` | Season / Cour / Part / Sequence / Format agrees and is globally unique. |
| `corroborated_weak_unique` | Two independent source families corroborate one weak candidate. |
| `ambiguous_exact` | Multiple anime share the exact title or season-stripped base. |
| `modifier_conflict` | Query and candidate modifiers conflict. |
| `variant_modifier_conflict` | Multilingual title segments contain conflicting modifiers. |
| `exact_overflow` | Exact retrieval exceeded the safe bound. |
| `low_evidence` | Candidates exist, but evidence cannot authorize automatic binding. |
| `candidate_unavailable` | The unique alias candidate could not be hydrated from the public `animes` index. |
| `no_candidates` / `empty_query` | No candidate / empty query. |

<Callout type="warn">
  Recall, Typesense text score, `seasonYear`, and one official-site slug cannot authorize binding by themselves. Always follow `shouldAutoSelect`; when false, present `matches` for confirmation.
</Callout>

## Cache, rate limit, and errors

| Item | Value |
| ---- | ----- |
| `Cache-Control` | `public, max-age=0, s-maxage=60`; no SWR or stale-if-error |
| ETag | Supports `If-None-Match`; unchanged responses return `304 Not Modified` |
| Rate limit | Default 180 requests / 60 seconds / IP |
| `400` | Invalid parameters |
| `429` | `RATE_LIMIT_EXCEEDED`; back off using `Retry-After` / `retryAfterMs` |
| `503` | `SEARCH_UNAVAILABLE`; no Convex fallback |

Publish automation may call this endpoint first. Pass the matched ID to
[`/api/releases/publish`](/docs/open-api/releases-publish) only when
`shouldAutoSelect=true`; otherwise keep a manual confirmation step.
