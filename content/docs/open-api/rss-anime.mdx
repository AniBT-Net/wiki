主订阅入口。`bgmId` 与 `groupSlug` 至少提供一个。

<ApiEndpoint method="GET" path="/rss/anime.xml" auth="公开">
兼容 Mikan 的 `bangumiId`、`subgroupid`。
</ApiEndpoint>

<Callout type="warn">
  `limit` 默认 100，范围 1–100。重复、为空、前导零或非整数：应用 `400`，生产边缘可能先 `403`。与默认值等价的写法会 `308` 到规范 URL，跟随跳转。
</Callout>

不带 `limit`、Tag 或搜索条件，且同时指定已收录 `bgmId` 与 `groupSlug` 的规范
anime-pair RSS 属于 fixed feed。每次客户端请求都会核对当前发布版本；未变化时
可用 `ETag` 返回 `304`，不会读取 Cloudflare 的旧对象。带 `limit`、Tag、搜索或
其他过滤条件的 URL 仍使用原有动态 RSS 处理。

完整参数见 [接口参考](/docs/open-api/reference)。

```txt title="示例"
https://anibt.net/rss/anime.xml?bgmId=543360&groupSlug=kirara-fantasia&resolution=1080p
```

Tag 可重复或逗号分隔：`?resolution=1080p&resolution=720p` 与 `?resolution=1080p,720p` 等价。

## Mikan

把主机换成 `anibt.net`，参数原样工作：

```txt title="兼容写法"
https://anibt.net/rss/anime.xml?bangumiId=3921&subgroupid=615
```

新代码用 `bgmId` 与 `groupSlug`。
