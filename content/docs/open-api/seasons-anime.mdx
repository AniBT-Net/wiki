          `scope.kind` 区分 season、query、bgmId；全库 query 的 `requestedSeason` 为
          null，不代表首条结果的季度。

          季度浏览最多 200 条，query 最多 50 条；`total` 是本次返回数，`truncated` 表示仍有结果。完整翻页请用
          /api/animes/search。

          每部作品携带自己的年季与首播精度。季度分类不改变实际首播日期；未知值为 null。

          `weekday`：0=周日 … 6=周六，按 Asia/Shanghai；null 为未排播。`rating` 为
          0–10，无有效来源评分时为 5.0，真实 0 保留。

          速率限制默认 30 次 / 60 秒 / IP。支持 GET、HEAD、OPTIONS；条件请求仍可能消耗限流额度。
