写入番剧资源。正式发布与 preview 都要求 `releases:publish`。

<ApiEndpoint method="POST" path="/api/releases/publish" auth="鉴权 · releases:publish">
推荐 multipart 上传 `.torrent`；或 JSON 传磁力。
</ApiEndpoint>

<Callout type="warn">
  Key 不要写进客户端、仓库或 issue。CI 用 secret 注入。`200` 表示主记录已写入，不表示 RSS / 搜索 / 页面已可见。
</Callout>

完整字段见 [接口参考](/docs/open-api/reference)。

## 身份自检

GET 同一路径，不写库，不要求 publish scope。批量发布前确认 `groupSlug` 与 `scopes`。

```bash title="whoami"
curl -X GET 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>'
```

## 发布

<Tabs items={['multipart（推荐）', 'JSON']}>
  <Tab value="multipart（推荐）">
    ```bash title="上传种子"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'animeIdType=anilist' \
      -F 'animeId=170942' \
      -F 'title=[字幕组] 葬送的芙莉莲 - 01 [1080p].mkv' \
      -F 'episodeKey=01' \
      -F 'resolution=1080p' \
      -F 'language=CHS' -F 'language=JP' \
      -F 'subtitle=EXTERNAL' \
      -F 'format=MKV' \
      -F 'torrent=@/path/to/release.torrent'
    ```
  </Tab>
  <Tab value="JSON">
    ```bash title="JSON 磁力"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -H 'Content-Type: application/json' \
      --data @- <<'JSON'
    {
      "animeIdType": "mal",
      "animeId": "52991",
      "title": "[字幕组] 葬送的芙莉莲 - 01 [1080p].mkv",
      "magnetBase64": "magnet:?xt=urn:btih:...",
      "episodeKey": "01",
      "resolution": "1080p",
      "language": ["CHS", "JP"],
      "subtitle": "EXTERNAL",
      "format": "MKV",
      "fileSize": 734003200
    }
    JSON
    ```
  </Tab>
</Tabs>

## 约束

- JSON 必填 `title`；multipart 未传时可用种子内部名。
- multipart 必填 `torrent`。JSON 必填 `magnetBase64`（原始 magnet 或 Base64）。
- 无 torrent 时正式发布必须 `fileSize > 0`，否则 `422` / `EMPTY_RELEASE_CONTENT`。
- `notes`：Markdown + 原始 HTML，最多 50000 字符，页面直接渲染。
- `preview=true`：预览链接 10 分钟过期，不进入公开列表。
- 未带番剧 ID 时服务端跑同一 matcher；不要传伪造的匹配结果。只有 `auto` 才直接绑定。
- 未传分辨率等字段时，默认 `resolution=1080p`、`format=MKV`、`subtitle=INTERNAL`、`language=["CHS"]`、`version=v1`；最终 `format=MP4` 时字幕默认更倾向 `EMBEDDED`。
- 同版本已存在返回 `409`，换 `version`。

## Nyaa 代发

<Callout type="warn">
  仅白名单字幕组。发布超分资源者无法申请。规则见 [Nyaa 代发](/docs/nyaa-proxy)。必须 multipart 上传 `.torrent`，且种子含 `http://nyaa.tracker.wf:7777/announce`。
</Callout>

```bash title="AniBT + Nyaa"
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'torrent=@release.torrent' \
  -F 'title=[字幕组] 作品名 - 01 [1080p][CHS]' \
  -F 'animeIdType=mal' \
  -F 'animeId=58514' \
  -F 'nyaa=true' \
  -F 'nyaaCategory=1_3'
```

也可用 `sitePublish.nyaa.enabled` / `sitePublish.nyaa.category` 等结构化字段。只传 `nyaaCategory` 等 Nyaa 字段时，服务端视为启用。

### Nyaa 代发字段和分类

| 表单字段 | JSON 结构化字段 | 必填 | 说明 |
| --- | --- | --- | --- |
| `nyaa` | `sitePublish.nyaa.enabled` | 否 | `true` 表示请求代发 |
| `nyaaCategory` | `sitePublish.nyaa.category` | 启用时必填 | 下表代码，中文动画字幕常用 `1_3` |
| `nyaaComplete` | `sitePublish.nyaa.complete` | 否 | Complete 标记。默认 `false` |
| `nyaaRemake` | `sitePublish.nyaa.remake` | 否 | Remake 标记。默认 `false` |
| `nyaaDescription` | `sitePublish.nyaa.description` | 否 | 提交到 Nyaa 的 Markdown，最多 20000 字符。不传则用 `notes`，同样受 20000 上限 |
| `nyaaInformation` | `sitePublish.nyaa.information` | 否 | information，最多 500 字符 |

| 代码 | Nyaa 分类 | 什么时候用 |
| --- | --- | --- |
| `1_1` | Anime - AMV | 动画音乐视频、剪辑、MAD/AMV |
| `1_2` | Anime - English-translated | 英文翻译动画字幕 |
| `1_3` | Anime - Non-English-translated | 非英文翻译动画字幕。中文简体、繁体、双语中文字幕通常选这个 |
| `1_4` | Anime - Raw | 动画 RAW，无翻译字幕 |
| `2_1` | Audio - Lossless | 无损音频，例如 FLAC、WAV |
| `2_2` | Audio - Lossy | 有损音频，例如 MP3、AAC、Opus |
| `3_1` | Literature - English-translated | 英文翻译漫画、轻小说、书籍 |
| `3_2` | Literature - Non-English-translated | 非英文翻译漫画、轻小说、书籍。中文漫画/小说通常选这个 |
| `3_3` | Literature - Raw | 未翻译漫画、轻小说、书籍原文 |
| `4_1` | Live Action - English-translated | 英文翻译真人影视 |
| `4_2` | Live Action - Idol/Promotional Video | 偶像、宣传视频、PV 类真人资源 |
| `4_3` | Live Action - Non-English-translated | 非英文翻译真人影视 |
| `4_4` | Live Action - Raw | 真人影视 RAW |
| `5_1` | Pictures - Graphics | CG、画集、插画、扫描图 |
| `5_2` | Pictures - Photos | 照片写真 |
| `6_1` | Software - Applications | 应用软件 |
| `6_2` | Software - Games | 游戏 |

## 失败

| HTTP | 处理 |
| --- | --- |
| 400 | 检查 `title` / 番剧标识 / `.torrent` |
| 401 | 检查 Bearer / `X-API-Key`；失效则重新生成 |
| 403 | 改用含 `releases:publish` 的 Key |
| 409 | 换 `version`，不要原样重试 |
| 413 | 种子过大 |
| 422 | `EMPTY_RELEASE_CONTENT` 等校验失败 |
| 429 / 503 | 按 `Retry-After` 退避 |
