          番剧发布必须指定 animeIdType 与 animeId，不按标题匹配番剧。

          animeId 按来源规范化：接受全角数字、前导零和该来源站点的番剧链接（bgm.tv / bangumi.tv /
          chii.in、myanimelist.net、anidb.net、anilist.co）。已合并的旧 BGM ID
          发布到合并后的番剧。发布只解析站内已收录的番剧，不会新收录。

          bgm 的 animeId 不是 ID 时返回 422；mal、anidb、anilist 的 animeId 不是
          ID、站内没有，或只有被管理员隐藏、被 bgm.tv 标记为 NSFW 的番剧持有该 ID 时返回 404；同一个外部 ID
          对应多部公开番剧时返回 422（Anime identifier is ambiguous），请改用 bgm ID。

          multipart 必须上传 torrent，title 省略时使用种子内部名；JSON 必须提供 title 和属于当前字幕组的
          torrentStorageId。JSON 还必须提供 magnetBase64。

          成功发布返回 { ok: true, result: { releaseId, revision, torrentObjectId? }
          }。发布回执不包含 groupId、groupName、groupSlug、animeId 或 fileSize；发布前用 GET
          同一路径核验身份。

          preview=true 返回顶层 previewUrl、previewToken、expiresAt 和 Key 身份信息，10
          分钟后过期；不创建公开发布。

          未显式提供的集数、画质、语言、字幕、格式和版本先从标题、再从种子内部名推断；无法推断集数时需传 episode 或 episodeKey。

          notes 最多 50000 字符。JSON 请求上限默认 1 MiB，multipart 默认 8 MiB，单个 .torrent
          文件最多 5 MiB。

          Nyaa 需要字幕组白名单和有效分类，种子必须包含 http://nyaa.tracker.wf:7777/announce。Nyaa
          代发应使用 multipart，确保从上传种子提取 tracker。

          Nyaa 的结构化 sitePublish.nyaa 仅用于 JSON；multipart 使用
          nyaa、nyaaCategory、nyaaComplete 等独立字段。

          200 表示本站发布已写入，不保证外站同步或下游读取已经完成。

          发布请求达到限额时返回 429 RATE_LIMIT_EXCEEDED；限流服务暂不可用时返回 503
          SERVICE_UNAVAILABLE。两者均带 Retry-After（秒），按该时间等待后重试，请求不会进入发布流程。
