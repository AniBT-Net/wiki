AniBT 是面向动漫的公共 BitTorrent 追踪器。

- **字幕组**：申请入驻 → 站点同步 → Tracker → 发布。
- **用户 / 开发者**：匿名用 RSS 和 JSON；个人订阅或发布需要账号。
