**AniBT** 是面向动漫的公共 BitTorrent 追踪器，主要服务字幕组发布与跟番消费。本 Wiki 覆盖站内发布、外站同步、公开 API、账号与周边工具；读者按用途选路径即可。

两条主线：

- **字幕组**：申请入驻 → 配置站点同步 → 制种时使用官方 Tracker → 用 API 或网页发布。
- **用户 / 开发者**：匿名使用 RSS 与 JSON；需要个人订阅或发布权限时再注册账号。
