## 註冊

1. 填寫郵箱並完成人機驗證，取得 6 位驗證碼（10 分鐘有效）。
2. 填寫暱稱、密碼和驗證碼。
3. 驗證成功後登記密碼。若這一步中斷，在同一分頁重試，不要再用已消耗的驗證碼。

已註冊郵箱也會顯示傳送成功，但不會再發註冊驗證碼。使用登入或找回密碼。

驗證碼、CAPTCHA 和第三方登入回呼均為一次性。不要重複重新整理回呼頁。

## 登入

| 方式 | 說明 |
| --- | --- |
| 郵箱密碼 | 郵箱 + 密碼 + 人機驗證。連續失敗會限流。 |
| 第三方 | 登入頁展示目前已啟用的入口。失敗後回到登入頁重新發起。 |
| 忘記密碼 | 使用登入頁入口。郵件由後台傳送，短暫延遲不代表失敗。 |

站點不提供 TOTP / 二次驗證。
