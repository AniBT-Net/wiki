---
title: 申请入驻
description: 用注册邮箱发邮件申请字幕组发布权限。
---

发布权限不自助开通。用 **AniBT 注册邮箱** 发到 [support@anibt.net](mailto:support@anibt.net)，主题：`字幕组入驻申请 - <组名>`。

## 邮件内容

- **组名**
- **slug**：稳定英文标识，例如 `sakura-sub`。开通后会出现在公开 URL 中，不宜更改。
- **简介**：作品类型、活跃情况。
- **联系方式**：可反向联系到字幕组的渠道。
- **身份证明（任选一项）**：其它 BT 站账号、公开频道管理员证明，或等价材料。

尚未注册时，先完成 [账号](/docs/account-auth)。

通常几个工作日内回复。一周无回复时检查垃圾邮件后可再发一次。

开通后会绑定 slug、发放 API Key，字幕组出现在站内列表和 RSS。接着配置 [站点同步](/docs/site-sync)、[Tracker](/docs/tracker)、[发布 API](/docs/open-api/reference)。
