AniBT Tracker 只服务 AniBT 站内发布并已加入白名单的种子。公开地址保持固定：

```txt title="AniBT Tracker"
https://tracker.anibt.net/announce
```

<Callout type="info">
  地址公开不代表任意种子都能使用。Tracker 最终按 v1 `info_hash` 检查 AniBT 的
  append-only 白名单；外部发布且未被 AniBT 收录的 hash 会返回 `not whitelisted`。
</Callout>

## 发布与下载

- 通过 AniBT 网页或 [`/api/releases/publish`](/docs/open-api/releases-publish) 发布时，
  站点会自动把固定 Tracker 写入 magnet。
- 从 AniBT 的 `.torrent` 下载接口取得种子时，站点会在不改变 infohash 的前提下，
  把历史 signed/重复 AniBT 地址规范为唯一固定地址。
- 其他第三方 tracker 会保留。建议种子仍包含 1–2 个可靠的公开 tracker，避免只依赖
  单一服务。
- 通用 remote torrent 代理返回上游原始 torrent bytes，不注入 AniBT Tracker。

既有 AniBT 种子仍可继续使用固定 `/announce`，不需要更换地址或重新下载数据；
Tracker 字段位于 torrent `info` dictionary 之外，规范化不会改变 infohash。

## 已关闭的入口

- `https://tracker.anibt.net/announce/v1/*`
- `https://tracker.anibt.net/scrape`
- 公网 `/api/*`
- UDP announce

Tracker 统计通过站内服务访问 Tailscale-only 管理 API，不依赖公网 scrape。
