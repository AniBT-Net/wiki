AniBT 為通過審核的優質字幕組提供「Nyaa 平台代發」服務，幫助團隊解決因網路環境受限或海外帳號門檻無法穩定分發資源的問題。

<Callout type="warn">
  **品質紅線**：嚴禁任何利用 AI 超解析度模型放大、畫質劣化、低碼率重編碼的資源申請代發。一經發現存在濫用或違規分發，平台將永久吊銷該字幕組的代發資格。
</Callout>

## 白名單申請條件

字幕組需滿足以下條件之一，由團隊負責人向 [support@anibt.net](mailto:support@anibt.net) 提交申請：

1. **常規申請**：在 AniBT 累計正常釋出滿 10 次且無違規記錄。
2. **免除釋出次數申請**：新入駐字幕組若急需海外分發，可在郵件中附帶在動漫花園、蜜柑計畫或其他知名 BT 站的近期釋出記錄截圖，以及自製片源的製作證據。

## 釋出前製種要求

代發會調整種子的 Tracker 列表，將 Nyaa Tracker 放在首位；種子的 info 字典與 infohash 保持不變。製種時需符合以下要求：

<Steps>
  <Step>
    ### 種子必須包含 Nyaa 官方 Tracker
    製種時，種子檔案中的 `announce` 或 `announce-list` 必須包含以下位址：

    ```txt title="Nyaa 官方 Tracker"
    http://nyaa.tracker.wf:7777/announce
    ```

    若種子中缺少該 Tracker，釋出請求會被平台安全屏障直接拒絕。
  </Step>

  <Step>
    ### 明確選擇 Nyaa 分類
    提交釋出時必須指定合規的分類代碼。對於絕大多數中文翻譯的日本動畫資源，請選擇 `1_3`（Anime - Non-English-translated）。常用分類代碼見下方表格。
  </Step>

  <Step>
    ### 釋出說明字數規範
    Nyaa 限制單篇釋出說明長度不超過 20,000 字元。系統預設使用本站填寫的 Notes，若本站說明較長，可在釋出介面單獨填寫一份精簡版 Nyaa 說明。
  </Step>
</Steps>

## 釋出操作方式

<Tabs items={['網頁控制台釋出', 'API 自動化釋出']}>
  <Tab value="網頁控制台釋出">
    白名單字幕組成員開啟 `/groups/<slug>/publish`，頁面中會自動出現「代發至 Nyaa」選項：

    1. 勾選 **代發至 Nyaa**。
    2. 下拉式選單選擇對應的分類（如 `1_3 - Non-English-translated`）。
    3. 根據需要勾選 `Complete`（完結歸檔合集）或 `Remake`（修復重壓版）。
    4. 提交釋出即可。
  </Tab>

  <Tab value="API 自動化釋出">
    呼叫 `POST /api/releases/publish` 時，必須使用 `multipart/form-data` 格式上傳原始 `.torrent` 檔案，並攜帶代發參數：

    ```bash title="API 攜帶 Nyaa 代發範例"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'torrent=@release.torrent' \
      -F 'title=[字幕組] 動畫名稱 - 01 [1080p][CHS]' \
      -F 'animeIdType=bgm' \
      -F 'animeId=12345' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=1_3'
    ```
  </Tab>
</Tabs>
