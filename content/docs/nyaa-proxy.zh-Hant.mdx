---
title: Nyaa 代發
description: 白名單字幕組可在 AniBT 釋出時，由平台代為向 Nyaa 提交同一資源。
---

Nyaa 代發面向已加入白名單的字幕組：在 AniBT 釋出資源時，可同步請求將同一條資源提交到 Nyaa。

平台 Nyaa 帳號由管理員在後台維護。字幕組只需通過白名單，並在釋出時提交符合要求的種子與參數。

<Callout type="warn">
  <strong className="text-red-600 dark:text-red-400">發佈超分資源者無法申請白名單。</strong>

  在本站或其它 BT 站累計發佈次數須達到 10 次及以上。發佈次數未滿 10 次但希望發佈至 Nyaa 時，可按情況單獨申請白名單，提交內容將經過人工審核。

  （*須提交資源為本人自製的相關圖片，以及 BT 發佈記錄截圖。）
</Callout>

Nyaa 分類須使用官方分類代碼。完整分類表、欄位別名與 API 參數含義見 [釋出資源 API 的 Nyaa 代發欄位](/zh-Hant/docs/open-api/releases-publish#nyaa-代發欄位和分類)。

## 釋出方式

<Tabs items={['網頁釋出', 'API 釋出']}>
  <Tab value="網頁釋出">
    <Steps>
      <Step>
        ### 製作帶 Nyaa tracker 的種子

        在種子的 tracker 列表中加入：

        ```txt title="Nyaa tracker"
        http://nyaa.tracker.wf:7777/announce
        ```
      </Step>

      <Step>
        ### 開啟字幕組釋出頁

        進入 `/groups/<slug>/publish`。字幕組已加入白名單時，頁面會顯示 **Nyaa 發佈** 區塊。
      </Step>

      <Step>
        ### 開啟代發並選擇分類

        開啟代發開關，選擇 Nyaa 分類。說明可繼承本站 notes，也可單獨填寫 Markdown。
      </Step>
    </Steps>
  </Tab>

  <Tab value="API 釋出">
    API 釋出頁位於 `/groups/<slug>/publish?tab=api`，API Key 在 `/groups/<slug>/api-keys` 建立。

    ```bash title="Nyaa 代發 multipart 請求"
    curl -X POST 'https://anibt.net/api/releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'torrent=@release.torrent' \
      -F 'title=[字幕組] 作品名 - 01 [1080p][CHS]' \
      -F 'animeIdType=mal' \
      -F 'animeId=58514' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=1_3' \
      -F 'nyaaComplete=false' \
      -F 'nyaaRemake=false' \
      -F 'nyaaDescription=可選：覆蓋提交到 Nyaa 的 Markdown 說明'
    ```

    未傳 `nyaaDescription` 時，Nyaa 說明繼承本站釋出說明 `notes`。無論自訂還是繼承，提交到 Nyaa 的說明都不能超過 20000 字；本站 `notes` 仍可更長，但超限時須單獨填寫較短的 `nyaaDescription`。`nyaaCategory` 完整可選值見 [釋出資源 API](/zh-Hant/docs/open-api/releases-publish#nyaa-代發欄位和分類)。

    其他類資源使用同一組參數，僅端點與基礎欄位不同：

    ```bash title="其他類資源 Nyaa 代發"
    curl -X POST 'https://anibt.net/api/other-releases/publish' \
      -H 'Authorization: Bearer <YOUR_API_KEY>' \
      -F 'category=manga' \
      -F 'title=Example Manga Vol.01' \
      -F 'torrent=@release.torrent' \
      -F 'nyaa=true' \
      -F 'nyaaCategory=3_2' \
      -F 'nyaaComplete=false' \
      -F 'nyaaRemake=false' \
      -F 'nyaaDescription=可選：覆蓋提交到 Nyaa 的 Markdown 說明'
    ```

    其他類資源完整參數見 [釋出其他類資源 API](/zh-Hant/docs/open-api/other-releases-publish#nyaa-代發)。
  </Tab>
</Tabs>

## 常見失敗原因

| 錯誤 | 處理 |
| --- | --- |
| 未加入白名單 | 聯絡管理員申請白名單，並按本頁要求提交釋出記錄證明。 |
| 缺少 Nyaa tracker | 重新製作種子，加入 `http://nyaa.tracker.wf:7777/announce`。 |
| 未選擇 Nyaa 分類 | 在釋出頁或 API 參數中傳入 `nyaaCategory`。 |
| Nyaa 說明超過 20000 字 | 縮短本站簡介，或改用自訂 Nyaa 說明 / 傳入較短的 `nyaaDescription`。整段 MediaInfo 通常會超限。 |
| 提交的是 JSON 而不是 torrent 檔案 | Nyaa 代發需要服務端校驗實際 torrent bytes，請使用 multipart 上傳 `.torrent`。 |

介面欄位詳見 [釋出資源 API](/zh-Hant/docs/open-api/releases-publish) 與 [釋出其他類資源 API](/zh-Hant/docs/open-api/other-releases-publish)。自備帳號同步見 [Nyaa 同步](/zh-Hant/docs/site-sync/nyaa)。
