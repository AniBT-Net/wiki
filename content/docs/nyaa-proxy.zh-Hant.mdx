title: Nyaa 代發
description: 白名單字幕組可在本站釋出時由平台提交到 Nyaa。
---

平台使用站點 Nyaa 帳號代發。字幕組需在白名單內。**釋出超分資源者不能申請。**

累計釋出滿 10 次可申請。未滿 10 次可單獨申請，須提交自製資源圖片和 BT 釋出紀錄截圖。

## 前提

- 字幕組已加入白名單，否則釋出頁無開關，API 會拒絕。
- `.torrent` 的 announce 必須包含 `http://nyaa.tracker.wf:7777/announce`。代發不改種子。
- 每次必須選 Nyaa 分類。中文動畫字幕常用 `1_3`。
- 提交到 Nyaa 的說明最多 20000 字。預設用本站 `notes`，也可單獨填寫。本站 `notes` 仍可更長。

分類代碼見 [釋出資源](/docs/open-api/releases-publish#nyaa-代發欄位和分類)。

## 釋出

網頁：`/groups/<slug>/publish`，開啟 Nyaa 代發並選分類。

API：`nyaa=true`，`nyaaCategory` 必填。須 multipart 上傳種子。

```bash
curl -X POST 'https://anibt.net/api/releases/publish' \
  -H 'Authorization: Bearer <YOUR_API_KEY>' \
  -F 'torrent=@release.torrent' \
  -F 'title=[字幕組] 作品名 - 01 [1080p][CHS]' \
  -F 'nyaa=true' \
  -F 'nyaaCategory=1_3'
```

其他類資源用 `/api/other-releases/publish`，同樣參數。

## 與 Nyaa 同步的區別

| | 同步 | 代發 |
| --- | --- | --- |
| 帳號 | 字幕組自己的 Nyaa 帳密 | 平台帳號 |
| 入口 | [站點同步](/docs/site-sync/nyaa) | 本頁 |
| 條件 | 自備帳號 | 白名單 + Nyaa tracker |
